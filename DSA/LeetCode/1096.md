# 1096. Brace Expansion II 🔴

**Topics:** String, Recursion, Set, Parsing

## Intuition

Think of the expression as a set of choices that we need to combine.

For example:

```text
{a,b}{c,d}
```

The first part gives us:

```text
a or b
```

The second part gives us:

```text
c or d
```

So we need every possible combination:

```text
ac
ad
bc
bd
```

There are two important operations:

* `,` means **union**. It combines all possible words.
* Writing expressions next to each other means **concatenation**. It combines every word from the left with every word from the right.

Because braces can contain other braces, we can solve the problem naturally with **recursive parsing**.

The code separates the parsing into three levels:

```text
_union()
    |
    +-- _concat()
            |
            +-- _piece()
                    |
                    +-- letter
                    |
                    +-- {...}
```

Each function handles one specific part of the grammar.

## Approach

We use **recursive descent parsing** with three helper functions:

### `_union()`

Handles comma-separated expressions.

For:

```text
{a,b,c}
```

it calculates:

```text
{a} ∪ {b} ∪ {c}
```

The operator `|=` performs set union:

```python
pieces |= more
```

This also automatically removes duplicates.

---

### `_concat()`

Handles expressions that appear next to each other.

For:

```text
{a,b}{c,d}
```

the first piece is:

```text
{"a", "b"}
```

and the second piece is:

```text
{"c", "d"}
```

We generate every combination:

```text
a + c = ac
a + d = ad
b + c = bc
b + d = bd
```

The nested loops implement this Cartesian product:

```python
for left in combined:
    for right in nxt:
        tmp.add(left + right)
```

We start with:

```python
combined = {""}
```

The empty string acts as a neutral starting point. Concatenating anything with `""` leaves it unchanged.

---

### `_piece()`

Handles the smallest unit of the expression.

There are two possibilities.

#### A letter

For:

```text
a
```

we return:

```python
{"a"}
```

#### A nested expression

For:

```text
{a,b}
```

we:

1. Skip `{`.
2. Recursively call `_union()`.
3. Skip `}`.
4. Return the resulting set.

This allows the same logic to handle arbitrarily nested braces.

---

## Example Walkthrough

Consider:

```text
{a,b}{c,{d,e}}
```

### Step 1: First `_piece()`

We encounter:

```text
{a,b}
```

`_piece()` sees `{`, so it calls `_union()` recursively.

The inner expression produces:

```text
{"a", "b"}
```

---

### Step 2: Second `_piece()`

Now we process:

```text
{c,{d,e}}
```

Inside this expression we have:

```text
c
```

and:

```text
{d,e}
```

The nested expression produces:

```text
{"d", "e"}
```

So the outer union becomes:

```text
{"c", "d", "e"}
```

---

### Step 3: Concatenate

Now `_concat()` combines:

```text
{"a", "b"}
```

with:

```text
{"c", "d", "e"}
```

Every possible combination is generated:

```text
ac
ad
ae
bc
bd
be
```

So we get:

```text
{"ac", "ad", "ae", "bc", "bd", "be"}
```

---

### Step 4: Sort

Finally:

```python
return sorted(letters)
```

converts the set into the required sorted list:

```text
["ac", "ad", "ae", "bc", "bd", "be"]
```

## Code

```python
class Solution:
    def braceExpansionII(self, expression: str) -> list[str]:
        self.s = expression
        self.pos = 0

        letters = self._union()
        return sorted(letters)

    def _union(self):
        pieces = self._concat()

        while self.pos < len(self.s) and self.s[self.pos] == ',':
            self.pos += 1
            more = self._concat()
            pieces |= more

        return pieces

    def _concat(self):
        combined = {""}

        while self.pos < len(self.s) and self.s[self.pos] not in ',}':
            nxt = self._piece()

            tmp = set()

            for left in combined:
                for right in nxt:
                    tmp.add(left + right)

            combined = tmp

        return combined

    def _piece(self):
        if self.s[self.pos] == '{':
            self.pos += 1

            inner = self._union()

            self.pos += 1  # skip closing brace
            return inner

        c = self.s[self.pos]
        self.pos += 1

        return {c}
```

## Complexity

Let $K$ be the number of distinct words produced and $L$ be the maximum length of a generated word.

The number of possible results can be exponential, so the output itself can dominate the complexity.

The concatenation step can generate up to all combinations between two sets:

$$
O(|A| \times |B|)
$$

Across the entire expression, the practical complexity is output-sensitive and can be expressed as roughly:

$$
O(N + K \cdot L)
$$

where $N$ is the expression length.

The sets storing generated words require:

$$
O(K \cdot L)
$$

space.

## Edge Cases

### 1. Single letter

```text
a
```

`_piece()` directly returns:

```text
{"a"}
```

Final result:

```text
["a"]
```

### 2. Nested braces

```text
{{a,b},c}
```

The recursive call to `_union()` handles the inner expression first.

The final set is:

```text
{"a", "b", "c"}
```

### 3. Duplicate results

Consider:

```text
{{a,z},a{b,c},{ab,z}}
```

Different parts can generate the same word.

Because the implementation uses sets:

```python
pieces |= more
```

duplicates are automatically removed.

The final result is:

```text
["a", "ab", "ac", "z"]
```

### 4. Consecutive expressions

For:

```text
{a,b}{c,d}{e,f}
```

`_concat()` repeatedly combines each piece with the current `combined` set.

This produces all possible combinations of the three groups.

## Lessons

* Recursive descent is useful when a problem has nested structures.
* Break a grammar into small parsing functions instead of handling everything in one loop.
* Use a **set** when duplicate results should automatically disappear.
* Comma-separated expressions represent **union**.
* Adjacent expressions represent **Cartesian-product concatenation**.
* `combined = {""}` is a useful technique when repeatedly building concatenated results.
* A shared pointer like `self.pos` lets every recursive function continue parsing from exactly where the previous function stopped.
