# 1190. Reverse Substrings Between Each Pair of Parentheses 🟡

**Topics:** String, Stack, Recursion

## Intuition

Imagine putting words inside nested boxes.

When you open a box, you wait until you reach its closing bracket. Then you reverse everything inside that box.

For example:

```text
(u(love)i)
```

First, reverse the innermost part:

```text
(u(evol)i)
```

Then reverse everything inside the outer parentheses:

```text
iloveu
```

A **stack** is a natural fit because the most recently opened parenthesis must be handled first.

This follows the same general idea of tracking nested structures, where the most recent unfinished section is processed first. 

## Approach

We use a **stack of strings**.

1. Start with one empty string on the stack.
2. For every character:

   * If it is `(`, start a new empty string by pushing onto the stack.
   * If it is a letter, append it to the current string.
   * If it is `)`, the current string represents everything inside this pair of parentheses.
3. Reverse that string.
4. Pop it and append the reversed string to the previous level.
5. At the end, the bottom of the stack contains the answer.

The important idea is:

> Every `(` creates a new level, and every `)` finishes that level.

### Why does reversing when we see `)` work?

Because parentheses are balanced and nested.

Consider:

```text
(ed(et(oc))el)
```

When we reach the innermost `)`:

```text
oc
```

becomes:

```text
co
```

Then the next closing parenthesis processes:

```text
etco
```

and turns it into:

```text
octe
```

The outer level can then continue processing.

## Example Walkthrough

Input:

```text
s = "(u(love)i)"
```

### Step 1: Read `(`

Start a new level:

```text
["", ""]
```

### Step 2: Read `u`

```text
["", "u"]
```

### Step 3: Read `(love)`

The inner `(` creates another level:

```text
["", "u", ""]
```

Read `love`:

```text
["", "u", "love"]
```

At `)`:

```text
"love" -> "evol"
```

Append it to the previous level:

```text
["", "uevol"]
```

### Step 4: Read `i`

```text
["", "uevoli"]
```

### Step 5: Final `)`

Reverse the current string:

```text
"uevoli" -> "iloveu"
```

Final result:

```text
"iloveu"
```

## Code

```python
class Solution:
    def reverseParentheses(self, s: str) -> str:

        stack = [""]

        for ch in s:
            if ch=="(":
                stack.append("")

            elif ch==")":
                current = stack.pop()[::-1]
                stack[-1] += current

            else:
                stack[-1] += ch

        return stack[0]
```

## Complexity

Let $n$ be the length of the string.

Each character is processed while traversing the string, but reversing substrings can cause characters to be processed multiple times in nested cases.

### Time Complexity

$$
O(n^2)
$$

in the worst case due to repeated string reversal and concatenation.

### Space Complexity

$$
O(n)
$$

The stack and stored strings can contain up to $n$ characters.

## Edge Cases

### 1. One pair of parentheses

```text
s = "(abcd)"
```

The content is simply reversed:

```text
"dcba"
```

### 2. Nested parentheses

```text
s = "(u(love)i)"
```

The inner substring is processed first, followed by the outer substring:

```text
"iloveu"
```

### 3. No parentheses

```text
s = "abc"
```

Nothing needs to be reversed:

```text
"abc"
```

## Lessons

* A **stack** is useful whenever a problem contains nested structures.
* `(` means **start a new level**.
* `)` means **finish the current level**.
* The most recently opened parenthesis is always closed first, which is exactly the **LIFO** behavior of a stack.
* Python's `[::-1]` provides a simple way to reverse a string.
* When processing nested structures, think in terms of **levels** rather than trying to handle everything at once.
