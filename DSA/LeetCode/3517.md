# 3517. Smallest Palindromic Rearrangement I 🟡

**Topics:** String, Greedy, Counting

## Intuition

Think of building a palindrome like constructing a bridge from both ends toward the center.

Every character used on the left side must have an identical character on the right side. Since the given string is already guaranteed to be a palindrome, every character appears an even number of times except possibly one character, which belongs in the center.

To make the palindrome **lexicographically smallest**, we should place the smallest characters as early as possible. That means we first build the **left half** using characters in alphabetical order, then mirror it to form the right half.


## Approach

We use **character frequency counting**.

1. Count how many times each character appears.
2. Traverse the characters in sorted order.
3. For each character:

   * If its count is odd, store it as the center character.
   * Add `count // 2` copies to the left half.
4. Reverse the left half to create the right half.
5. Combine everything as:

```text
left_half + center_char + right_half
```

Since the left half is built in alphabetical order, the final palindrome is the smallest possible in lexicographical order.


## Example Walkthrough

**Input**

```text
s = "babab"
```

### Step 1: Count frequencies

```text
a → 2
b → 3
```

### Step 2: Build the left half

* `'a'` contributes `1` copy.
* `'b'` contributes `1` copy.

```text
left_half = "ab"
```

### Step 3: Find the center

`'b'` has an odd frequency.

```text
center_char = "b"
```

### Step 4: Mirror the left half

```text
right_half = "ba"
```

### Final palindrome

```text
"ab" + "b" + "ba"
= "abbba"
```


## Code

```python
from collections import Counter
class Solution:
    def smallestPalindrome(self, s: str) -> str:
        
        char_counts = Counter(s)

        half_chars=[]
        center_char=""

        for ch in sorted(char_counts.keys()):
            cnt = char_counts[ch]

            if cnt%2 == 1:
                center_char = ch
            
            pairs = cnt//2
            
            if pairs>0:
                half_chars.append(ch*pairs)

        left_half = "".join(half_chars)
        right_half = left_half[::-1]

        return left_half + center_char + right_half
```


## Complexity

**Time Complexity**

$$
O(n)
$$

* Counting characters takes $O(n)$.
* Sorting the distinct lowercase letters takes at most $O(26 \log 26)$, which is constant.
* Building the answer takes $O(n)$.

Overall:

$$
O(n)
$$


**Space Complexity**

$$
O(n)
$$

The frequency map and the resulting palindrome require additional space proportional to the input size.


## Edge Cases

1. **Single character**

```text
s = "z"
```

Output:

```text
"z"
```


2. **All characters are the same**

```text
s = "aaaaa"
```

Output:

```text
"aaaaa"
```


3. **No center character**

```text
s = "daccad"
```

All character counts are even, so the center remains empty.

Output:

```text
"acddca"
```


## Lessons

* For palindrome rearrangement problems, only one half of the palindrome needs to be constructed explicitly.
* Frequency counting is a simple and efficient way to determine how many copies of each character belong on each side.
* Processing characters in sorted order guarantees the lexicographically smallest result.
* Mirroring the left half is a common technique for constructing palindromes efficiently.
