# 3016. Minimum Number of Pushes to Type Word II 🟡

**Topics:** Greedy, Hash Table, Sorting, String

## Intuition

Imagine you are arranging books on **8 shelves**, but this time some books are borrowed much more often than others.

To save the most effort, you would place the **most frequently used books** on the easiest-to-reach spots. Less frequently used books can be placed farther away because they are accessed less often.

This problem follows the same idea.

Each key (2 to 9) has positions that require:

* 1 push for the first letter
* 2 pushes for the second letter
* 3 pushes for the third letter
* and so on.

Unlike Part I, letters may appear multiple times. Therefore, assigning a frequently used letter to a cheaper position saves more pushes than assigning a rarely used letter there.

So our greedy strategy is simple:

* Count how often every letter appears.
* Sort the frequencies from highest to lowest.
* Give the cheapest positions to the most frequent letters.


## Approach

First, count the frequency of every character using `Counter`.

```python
freq = Counter(word)
```

Next, sort these frequencies in descending order.

```python
counts = sorted(freq.values(), reverse=True)
```

Now assign letters one by one.

Since there are **8 keys**, the first 8 letters receive positions requiring **1 push**, the next 8 require **2 pushes**, and so on.

For the `idx`-th assigned letter:

```python
presses = idx // 8 + 1
```

Multiply this push cost by the letter's frequency because every occurrence of that letter requires the same number of pushes.

```python
total += presses * cnt
```

Finally, return the accumulated total.

This greedy assignment is optimal because every cheaper position is always given to the letter that saves the most pushes.

## Code

```python
from collections import Counter
class Solution:
    def minimumPushes(self, word: str) -> int:
        freq = Counter(word)
        counts = sorted(freq.values(), reverse=True)

        total=0
        idx=0

        for cnt in counts:
            presses = idx // 8+1
            total += presses*cnt
            idx += 1

        return total
```


## Complexity

**Time Complexity**

* Counting frequencies: $O(n)$
* Sorting at most 26 frequencies: $O(26 \log 26)$, which is effectively constant.

Overall:

$$
O(n)
$$

**Space Complexity**

$$
O(1)
$$

The frequency table contains at most 26 lowercase English letters.


## Edge Cases

1. **Only one distinct letter**

```text
word = "aaaaaa"
```

The letter gets a 1-push position.

Answer:

```text
6
```


2. **Exactly eight distinct letters**

```text
word = "abcdefgh"
```

Every letter gets a 1-push position.

Answer:

```text
8
```


3. **More than eight distinct letters**

```text
word = "abcdefghijklmnopqrstuvwxyz"
```

The first eight most frequent letters receive 1-push positions, the next eight receive 2-push positions, and so on. Since every letter appears once, only the position levels determine the answer.


## Lessons

* When some items appear more often than others, assign the **lowest costs to the highest frequencies**.
* Sorting frequencies is a common greedy pattern for minimizing weighted costs.
* The expression

```python
idx // 8 + 1
```

efficiently determines the push cost for each assignment level.

* Always look for opportunities where pairing the **largest values with the smallest costs** leads to an optimal greedy solution.
