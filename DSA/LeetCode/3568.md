# 3568. Minimum Moves to Clean the Classroom 🟡

**Topics:** Breadth-First Search, Bitmask, State Space Search, Grid

## Intuition

Imagine the classroom as a maze.

The student has a limited number of steps they can take before running out of energy. Some cells contain litter that needs to be collected, while `R` cells completely restore the student's energy.

The tricky part is that **being at the same cell does not always mean being in the same situation**.

For example:

```text
(row=2, col=3, energy=5, mask=001)
```

is different from:

```text
(row=2, col=3, energy=2, mask=001)
```

because the student has different amounts of energy.

It is also different from:

```text
(row=2, col=3, energy=5, mask=101)
```

because different litter has been collected.

So we represent the student's complete situation using:

```text
(row, col, energy, mask)
```

Since every move costs exactly `1`, **BFS** lets us find the minimum number of moves.

The `mask` uses bits to remember which litter cells have already been collected.


## Approach

We combine three ideas:

1. **BFS** for minimum moves.
2. **Bitmask** for tracking collected litter.
3. **Visited states** to avoid processing the same situation repeatedly.

### 1. Find the starting position and litter

We scan the classroom:

```python
if ch == 'S':
    start = (r, c)

elif ch == 'L':
    lit_idx[(r, c)] = len(lit_idx)
```

Each litter gets a unique bit position.

For example, with three litter cells:

```text
L0 -> bit 0
L1 -> bit 1
L2 -> bit 2
```

If we have collected `L0` and `L2`:

```text
101
```

So:

```text
mask = 5
```


### 2. Create the target mask

If there are `k` litter cells, every bit needs to eventually become `1`.

We calculate:

```python
full = (1 << len(lit_idx)) - 1
```

For 3 litter cells:

```text
1 << 3 = 1000
1000 - 1 = 0111
```

Therefore:

```text
full = 111
```

When:

```python
mask == full
```

all litter has been collected.


### 3. BFS state

The queue stores:

```python
(row, col, energy_left, mask)
```

Initially:

```python
q = deque([
    (start[0], start[1], energy, 0)
])
```

The student starts with:

* starting position
* full energy
* no litter collected

The `seen` set stores exactly the same state:

```python
seen = {
    (start[0], start[1], energy, 0)
}
```

This prevents us from repeatedly exploring an identical situation.


### 4. Try all four directions

For every state, we try:

```python
dirs = [
    (1, 0),
    (-1, 0),
    (0, 1),
    (0, -1)
]
```

That represents:

```text
down
up
right
left
```

We first make sure the new position is inside the classroom.

Then we ignore obstacles:

```python
if tile == 'X':
    continue
```


### 5. Spend one energy

Every movement costs exactly one energy:

```python
left = eng - 1
```

If energy becomes negative:

```python
if left < 0:
    continue
```

we cannot make that move.

Notice that `0` energy is allowed temporarily. This matters because the student can move onto an `R` cell with their last unit of energy and then receive a full reset.


### 6. Collect litter using a bitmask

If we move onto a litter cell:

```python
if tile == 'L':
    nmask |= 1 << lit_idx[(nr, nc)]
```

Suppose the current mask is:

```text
001
```

and we collect litter `L2`:

```text
001
100
101
```

So the new mask becomes:

```text
101
```

The `|` operation is useful because it keeps previously collected litter marked.


### 7. Reset energy at `R`

If the new cell is a reset area:

```python
elif tile == 'R':
    left = energy
```

The movement to `R` costs one energy first.

After reaching `R`, the energy is restored to the original maximum.

For example:

```text
Current energy = 1

Move to R
1 -> 0

Reset
0 -> energy
```

So the student can continue from the reset cell with full energy.


### 8. Add unseen states

We combine everything into:

```python
nxt = (nr, nc, left, nmask)
```

If we have already seen this exact state, we skip it:

```python
if nxt in seen:
    continue
```

Otherwise:

```python
seen.add(nxt)
q.append(nxt)
```


## Why BFS Works

Every move has exactly the same cost:

```text
1 move
```

Therefore, BFS explores the states level by level.

For example:

```text
steps = 0
    ↓
all states reachable in 0 moves

steps = 1
    ↓
all states reachable in 1 move

steps = 2
    ↓
all states reachable in 2 moves

...
```

So the first time we encounter:

```python
mask == full
```

we know that this is the **minimum number of moves**.


## Example Walkthrough

Consider:

```text
classroom = [
    "LS",
    "RL"
]

energy = 4
```

The grid is:

```text
L S
R L
```

Assign:

```text
L0 = (0, 0)
L1 = (1, 1)
```

Therefore:

```text
full = 11
```

### Initial state

```text
position = (0, 1)
energy   = 4
mask     = 00
steps    = 0
```


### Move 1

Move left:

```text
(0,1) -> (0,0)
```

This is `L0`.

Energy:

```text
4 -> 3
```

Mask:

```text
00 -> 01
```

State:

```text
(0,0,3,01)
```


### Move 2

Move down:

```text
(0,0) -> (1,0)
```

This is `R`.

Energy first becomes:


```text
(1,0) -> (1,1)
```

This is `L1`.

Mask:

```text

```

Now:

```python
mask == full
```

So we return:

```text
3
```


## Code

```python
from collections import deque
from typing import List

class Solution:
    def minMoves(self, classroom: List[str], energy: int) -> int:
        rows, cols = len(classroom), len(classroom[0])

        start=None
        lit_idx = {}

        for r in range(rows):
            for c in range(cols):
                ch = classroom[r][c]

                if ch == 'S':
                    start = (r,c)

                elif ch == 'L':
                    lit_idx[(r,c)] = len(lit_idx)

        if not lit_idx:
            return 0

        full = (1 << len(lit_idx)) - 1
        dirs = [(1,0), (-1,0), (0,1), (0,-1)]

        q = deque([(start[0], start[1], energy, 0)])
        seen = {(start[0], start[1], energy, 0)}
        steps=0

        while q:
            for _ in range(len(q)):
                r, c, eng, mask = q.popleft()

                if mask == full:
                    return steps

                for dr, dc in dirs:
                    nr, nc = r + dr, c + dc

                    if nr < 0 or nr >= rows or nc < 0 or nc >= cols:
                        continue
                    tile = classroom[nr][nc]

                    if tile == 'X':
                        continue

                    left = eng - 1
                    if left < 0:
                        continue

                    nmask = mask
                    if tile == 'L':
                        nmask |= 1 << lit_idx[(nr, nc)]

                    elif tile == 'R':
                        left = energy

                    nxt = (nr,nc,left,nmask)
                    if nxt in seen:
                        continue
                    seen.add(nxt)
                    q.append(nxt)

            steps += 1

        return -1
```

## Complexity

Let:

* $m$ = number of rows
* $n$ = number of columns
* $E$ = maximum energy
* $L$ = number of litter cells

There are at most:

$$
m \times n \times E \times 2^L
$$

possible states.

Each state has at most 4 transitions.

### Time Complexity

$$
O(mnE2^L)
$$

### Space Complexity

$$
O(mnE2^L)
$$

The important reason this remains manageable is that:

$$
L \leq 10
$$

so:

$$
2^L \leq 1024
$$


## Edge Cases

### 1. No litter

```text
["S"]
```

There is nothing to collect.

```text
Answer = 0
```

Your code handles this with:

```python
if not lit_idx:
    return 0
```


### 2. Litter is unreachable

```text
["SXL"]
```

The obstacle blocks the only path.

Eventually the BFS queue becomes empty:

```python
return -1
```


### 3. Energy reaches zero

Having:

```text
eng = 0
```

does not immediately mean failure.

The student can still be standing on a reset cell and reset their energy.

The important check is whether they have enough energy to **make the next move**.


### 4. Multiple reset visits

An `R` cell can be used repeatedly.

That is why we do not maintain something like:

```python
used_reset = True
```

Instead, the current energy is part of the BFS state.


## Lessons

* When BFS has additional conditions, put those conditions into the **state**.
* Here the complete state is:

```text
(row, col, energy, mask)
```

* **Bitmasking** is an excellent technique when the number of special items is small.
* The expression:

```python
(1 << L) - 1
```

creates a mask where all `L` bits are `1`.

* Use:

```python
mask |= 1 << index
```

to mark an item as collected.

* BFS is the right choice when every move has equal cost and we need the minimum number of moves.
* The `seen` set must include **all state information**, not just `(row, col)`.
* A powerful general pattern to remember is:

```text
Grid + BFS + State + Bitmask
```

This same pattern can appear in problems involving keys, switches, collectibles, checkpoints, or other small sets of objectives.
