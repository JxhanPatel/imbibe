## 462. Minimum Moves to Equal Array Elements II 🟡

**Topics:** Array, Math, Sorting, Quickselect


### Intuition

Imagine you and your friends are standing on a long straight street, and you want to gather at one person's house to hang out. Everyone has to walk a certain distance. To make the **total walking distance** as small as possible for everyone combined, where should you meet?

If you meet at the extreme ends of the street, one person has to walk the entire length. If you pick the **median** (the exact middle person when everyone is lined up in order), any step you take to the left or right balances out equally. Mathematically, the sum of absolute deviations is always minimized at the median.


### Approach

1. **Sort the Array:** Sort `nums` in non-decreasing order so that elements are arranged sequentially along our number line.
2. **Find the Median:** Locate the middle element at index `n // 2`.
3. **Calculate Total Moves:** Iterate through the sorted array and sum the absolute differences between each element and the median value.


### Example Walkthrough

Consider `nums = [1, 10, 2, 9]`.

* **Step 1 (Sort):** The sorted array is `[1, 2, 9, 10]`.
* **Step 2 (Find Median):** The length is $n = 4$, so the middle index is `4 // 2 = 2`. The element at index 2 is `9`.
* **Step 3 (Compute Distances):**
* Distance for `1`: $\vert{}1 - 9\vert{} = 8$
* Distance for `2`: $\vert{}2 - 9\vert{} = 7$
* Distance for `9`: $\vert{}9 - 9\vert{} = 0$
* Distance for `10`: $\vert{}10 - 9\vert{} = 1$


* **Total Moves:** $8 + 7 + 0 + 1 = 16$.


### Code

```python
def minMoves2(nums):
    nums.sort()
    mid = nums[len(nums) // 2]
    return sum(abs(x - mid) for x in nums)

```


### Complexity Analysis

* **Time Complexity:** $O(n \log n)$ due to the sorting step. Computing the absolute differences takes $O(n)$ time.
* **Space Complexity:** $O(1)$ or $O(\log n)$ auxiliary space depending on Python's internal sorting implementation (Timsort).


### Edge Cases

* **Single Element Array (`nums = [5]`):** The median is 5, and the total distance is $\vert{}5 - 5\vert{} = 0$.
* **All Elements Equal (`nums = [3, 3, 3]`):** The median is 3, and all absolute differences are 0, returning `0`.
* **Negative Numbers (`nums = [-5, 1, 5]`):** Sorted order is `[-5, 1, 5]`, median is `1`. Distances are $\vert{}-5 - 1\vert{} + \vert{}1 - 1\vert{} + \vert{}5 - 1\vert{} = 6 + 0 + 4 = 10$.


### Lessons

* Whenever a problem asks to minimize the sum of absolute differences $\sum \vert{}x_i - c\vert{}$, the optimal constant choice for $c$ is always the **median**.
* Contrast this with minimizing the sum of squared differences $\sum (x_i - c)^2$, where the optimal choice is the **mean** (average).
* Sorting is the cleanest and most reliable approach for interviews, though Quickselect can achieve $O(n)$ average time if strict linear time is required.
