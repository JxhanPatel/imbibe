# 1807. Evaluate the Bracket Pairs of a String 🟡

**Topics:** Hash Table, String

## Intuition

Imagine you have a dictionary containing keys and their values:

```text
name -> bob
age  -> two
```

The string contains some of these keys inside brackets:

```text
(name)is(age)yearsold
```

Whenever we encounter a bracket pair, we extract the key and look it up in our dictionary.

* If the key exists, we replace the bracket pair with its value.
* If the key does not exist, we replace it with `?`.
* Characters outside brackets are copied directly to the result.

So the main idea is simple:

**Build a lookup dictionary, then scan the string and evaluate each bracket pair.**

## Approach

We use a **hash map and a single scan** through the string.

### 1. Build the lookup dictionary

```python
lookup = {k: v for k, v in knowledge}
```

This converts the `knowledge` list into a dictionary.

For example:

```text
[["name", "bob"], ["age", "two"]]
```

becomes:

```text
{
    "name": "bob",
    "age": "two"
}
```

This allows us to quickly find the value of any key.

### 2. Scan the string

We use `idx` to move through the string.

If the current character is not `'('`, it is a normal character, so we add it directly to `out`.

```python
if ch != '(':
    out.append(ch)
    idx += 1
    continue
```

### 3. Find the closing bracket

When we encounter `'('`, we start another pointer `end` just after it.

```python
end = idx + 1

while s[end] != ')':
    end += 1
```

Since there are no nested brackets, we can simply move forward until we find `')'`.

### 4. Extract the key

The characters between `idx` and `end` form the key:

```python
key = s[idx + 1:end]
```

For:

```text
(name)
```

we get:

```text
name
```

### 5. Look up the value

```python
out.append(lookup.get(key, '?'))
```

If the key exists, its value is added.

If it does not exist, `?` is added.

### 6. Skip the processed bracket pair

After processing `(key)`, we do not need to process those characters again.

```python
idx = end + 1
```

This moves `idx` directly to the character after `')'`.

## Example Walkthrough

**Input:**

```text
s = "(name)is(age)yearsold"

knowledge = [
    ["name", "bob"],
    ["age", "two"]
]
```

### Step 1: Create lookup

```text

age  -> two
```

### Step 2: Process `(name)`

The key is:

```text

```

Lookup gives:

```text

```

Result:

```text
bob
```

### Step 3: Process `is`

These are normal characters, so they are copied directly.

Result:

```text

```

### Step 4: Process `(age)`

The key is:

```text

```

```text

```

```text

```

```text

```

Final result:

```text

```

## Code

```python
class Solution:
    def evaluate(self, s: str, knowledge: list[list[str]]) -> str:
        lookup = {k: v for k, v in knowledge}

        out=[]
        n = len(s)
        idx=0

        while idx < n:
            ch = s[idx]

            if ch != '(':
                out.append(ch)
                idx += 1
                continue

            end = idx+1
            while s[end] != ')':
                end += 1

            key = s[idx+1:end]
            out.append(lookup.get(key, '?'))

            idx = end+1

        return ''.join(out)
```

## Complexity

Let:

* $n$ = length of `s`
* $k$ = number of entries in `knowledge`

Building the dictionary takes:

$$
O(k)
$$

The string is scanned once overall:

$$
O(n)
$$

Therefore, the total time complexity is:

$$
O(n + k)
$$

The lookup dictionary requires:

$$
O(k)
$$

space.

The output requires up to:

$$
O(n)
$$

space.

So the total auxiliary space is:

$$
O(n + k)
$$

## Edge Cases

### 1. Unknown key

```text
s = "hi(name)"
knowledge = [["a", "b"]]
```

`name` is not present in the dictionary.

```text
Output: "hi?"
```

### 2. Same key appears multiple times

```text
s = "(a)(a)(a)aaa"
knowledge = [["a", "yes"]]
```

Every `(a)` is evaluated independently.

```text
Output: "yesyesyesaaa"
```

The standalone `a` characters are not evaluated.

### 3. Empty knowledge

```text
s = "(hello)"
knowledge = []
```

There is no value for `hello`.

```text
Output: "?"
```

### 4. No bracket pairs

```text
s = "hello"
knowledge = [["a", "b"]]
```

There is nothing to evaluate.

```text
Output: "hello"
```

## Lessons

* Use a **dictionary** when you need fast key-to-value lookups.
* Use an index to scan and parse strings efficiently.
* When a section of the string has been completely processed, jump past it instead of processing it again.
* `dict.get(key, default)` is useful when a missing key has a specific fallback value.
* Building the result in a list and using `''.join()` at the end is an efficient way to construct strings.
* This problem combines two common patterns: **string parsing + hash map lookup**.
