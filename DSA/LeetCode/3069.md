# 3069. Distribute Elements Into Two Arrays I 🟢

**Topics:** Array, Simulation

## Intuition

Imagine you have two baskets, `arr1` and `arr2`.

You place the first number into the first basket and the second number into the second basket. After that, every new number looks only at the most recent item in both baskets.

* If the last item in `arr1` is larger, put the new number into `arr1`.
* Otherwise, put it into `arr2`.

The important detail is that we do not need to compare every element. We only care about the last element of each array.

This makes the problem a simple simulation.  

## Approach

1. Initialize `arr1` with `nums[0]`.
2. Initialize `arr2` with `nums[1]`.
3. Starting from index `2`, process each remaining number.
4. Compare:

   ```python
   arr1[-1] > arr2[-1]
   ```
5. If true, append the current number to `arr1`.
6. Otherwise, append it to `arr2`.
7. Finally, concatenate both arrays.

Since the problem guarantees at least three elements, both arrays will always have an initial element before we start comparing.

## Example Walkthrough

**Input:**

```text
nums = [5,4,3,8]
```

### Initial state

The first element goes into `arr1`:

```text
arr1 = [5]
```

The second element goes into `arr2`:

```text
arr2 = [4]
```

### Process `3`

Compare the last elements:

```text
5 > 4
```

This is true, so append `3` to `arr1`:

```text
arr1 = [5,3]
arr2 = [4]
```

### Process `8`

Compare the last elements:

```text
3 > 4
```

This is false, so append `8` to `arr2`:

```text
arr1 = [5,3]
arr2 = [4,8]
```

### Concatenate

```text
result = arr1 + arr2
       = [5,3] + [4,8]
       = [5,3,4,8]
```

**Output:**

```text
[5,3,4,8]
```

## Code

```python
from typing import List

class Solution:
    def resultArray(self, nums: List[int]) -> List[int]:
        arr1 = [nums[0]]
        arr2 = [nums[1]]

        for i in range(2, len(nums)):
            num=nums[i]

            if arr1[-1] > arr2[-1]:
                arr1.append(num)
            
            else:
                arr2.append(num)

        return arr1+arr2
```

## Complexity

We process each element once:

$$
O(n)
$$

Appending to a Python list is amortized $O(1)$, so the overall time complexity is:

$$
O(n)
$$

**Space Complexity:**

$$
O(n)
$$

We use `arr1` and `arr2` to store all `n` elements.

## Edge Cases

### 1. Minimum length

```text
nums = [2,1,3]
```

Initial arrays:

```text
arr1 = [2]
arr2 = [1]
```

Since:

```text
2 > 1
```

`3` goes into `arr1`.

Result:

```text
[2,3,1]
```

### 2. Last element of `arr1` is smaller

```text
nums = [1,5,3]
```

Since:

```text
1 > 5
```

is false, `3` goes into `arr2`.

Result:

```text
[1,5,3]
```

### 3. Alternating destinations

```text
nums = [5,4,3,8]
```

`3` goes to `arr1`, then `8` goes to `arr2`.

This shows that the destination can change at every operation depending on the current last elements.

## Lessons

* Some array problems are just direct simulations of the rules given.
* Read the conditions carefully and identify exactly which values affect each decision.
* Here, only `arr1[-1]` and `arr2[-1]` matter.
* When the problem asks you to repeatedly follow a process, maintaining the required state is often enough.
* Do not overcomplicate an Easy problem when a straightforward simulation solves it in $O(n)$.
