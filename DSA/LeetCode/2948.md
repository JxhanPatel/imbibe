# 2948. Make Lexicographically Smallest Array by Swapping Elements 🟡

**Topics:** Sorting, Greedy, Union-Find, Array

## Intuition

Imagine you have a group of people who are allowed to exchange their positions.

Two people can directly swap if their values differ by at most `limit`.

Here is the important part: **indirect swapping is also possible**.

Suppose:

```text
limit = 3

values = [1, 4, 7]
```

* `1` can swap with `4`
* `4` can swap with `7`
* `1` cannot directly swap with `7`

But `1` can still eventually reach the position of `7`:

```text
1 <-> 4 <-> 7
```

So the real question is not:

> Which individual pairs can swap?

It is:

> Which values belong to the same connected group through valid swaps?

Once we find these groups, **all values inside one group can be rearranged among their original positions**.

To make the array lexicographically smallest, we should put the **smallest available value at the smallest index** within each group.

## Approach

We can solve this using **sorting + connected components**.

### Step 1: Sort the values

Create pairs containing the value and its original index:

```text
nums = [1, 5, 3, 9, 8]

pairs = [
    (1, 0),
    (5, 1),
    (3, 2),
    (9, 3),
    (8, 4)
]
```

Sort them by value:

```text
(1,0), (3,2), (5,1), (8,4), (9,3)
```


### Step 2: Find groups

After sorting, look at neighboring values.

If:

```text
current_value - previous_value <= limit
```

then they can belong to the same connected component.

For example:

```text
limit = 2

1, 3, 5
```

The gaps are:

```text
3 - 1 = 2
5 - 3 = 2
```

So all three belong to the same group.

But:

```text
5, 8
```

has:

```text
8 - 5 = 3
```

so that starts a new group.

For this problem, sorting lets us identify the components without explicitly performing every possible swap.


### Step 3: Rearrange each group

For every group, we have:

* the original indices
* the values belonging to those indices

Sort both.

Then assign the smallest value to the smallest index.

For example:

```text
indices = [1, 2]
values  = [5, 3]
```

Sort them:

```text
indices = [1, 2]
values  = [3, 5]
```

Assign:

```text
ans[1] = 3
ans[2] = 5
```

This gives the lexicographically smallest arrangement.


## Example Walkthrough

Consider:

```text
nums = [1, 5, 3, 9, 8]
limit = 2
```

### Step 1: Sort `(value, index)`

```text
(1,0)
(3,2)
(5,1)
(8,4)
(9,3)
```

### Step 2: Find groups

For the first group:

```text
1 -> 3 -> 5
```

The gaps are:

```text
3 - 1 = 2
5 - 3 = 2
```

Both are within the limit.

So:

```text
values = [1,3,5]
indices = [0,2,1]
```

Sort the indices:

```text
indices = [0,1,2]
```

Assign the values:

```text
index 0 -> 1
index 1 -> 3
index 2 -> 5
```

The array becomes:

```text
[1,3,5,9,8]
```


The second group is:

```text
8 -> 9
```

because:

```text
9 - 8 = 1 <= 2
```

Their indices are:

```text
8 -> index 4
9 -> index 3
```

Sort indices:

```text
[3,4]
```

Assign values:

```text
index 3 -> 8
index 4 -> 9
```

Final result:

```text
[1,3,5,8,9]
```


## Code

```python
class Solution:
    def lexicographicallySmallestArray(self, nums: List[int], limit: int) -> List[int]:
        
        n = len(nums)
        val_idx = sorted((v, i) for i, v in enumerate(nums))

        result = nums[:]
        i=0

        while i < n:
            j=i

            while j+1 < n and val_idx[j+1][0] - val_idx[j][0] <= limit:
                j += 1

            group = val_idx[i:j+1]
            orig_positions = sorted(idx for _, idx in group)

            for pos, (v, _) in zip(orig_positions, group):
                result[pos] = v

            i = j+1

        return result
```

## Why does this work?

The key observation is the **chain effect**.

Suppose:

```text
a <= b <= c
```

and:

```text
b - a <= limit
c - b <= limit
```

Even if:

```text
c - a > limit
```

`a` can still move through `b` and eventually reach the position of `c`.

Therefore, a group is formed whenever consecutive sorted values have a gap of at most `limit`.

Inside one such group, the values can effectively be permuted among the group's original positions.

To minimize the array lexicographically, the optimal choice is obvious:

```text
smallest value -> smallest index
second smallest -> second smallest index
...
```


## Complexity

Sorting the `(value, index)` pairs takes:

$$
O(n \log n)
$$

Sorting the indices inside all groups takes at most:

$$
O(n \log n)
$$

The overall complexity is therefore:

$$
O(n \log n)
$$

Space complexity:

$$
O(n)
$$

for the sorted pairs, answer array, and temporary group data.


## Edge Cases

### 1. No values can connect

```text
nums = [1, 10, 20]
limit = 2
```

Every gap is greater than `2`.

No swaps are possible.

Output:

```text
[1,10,20]
```


### 2. Everything belongs to one group

```text
nums = [4,2,3,1]
limit = 10
```

Every value can connect to the others.

Therefore, we can completely sort the array:

```text
[1,2,3,4]
```


### 3. Indirect connection

```text
nums = [1,7,4]
limit = 3
```

Sorted values:

```text
1,4,7
```

We have:

```text
4 - 1 = 3
7 - 4 = 3
```

So all three belong to the same group, even though:

```text
7 - 1 = 6 > 3
```

This is the most important idea in the problem.


## Lessons

* When swaps are allowed based on a condition, think about **connected components**.
* Directly incompatible elements can still be connected through intermediate elements.
* Sorting can reveal connected groups when the condition depends on the difference between values.
* Once a group is identified, putting its smallest values at its smallest indices produces the lexicographically smallest result.
* A useful pattern to remember is:

```text
Sort values
    ↓
Find connected groups
    ↓
Collect indices of each group
    ↓
Sort indices
    ↓
Assign smallest values to smallest indices
```

This is a nice example of combining a **greedy idea with sorting and connectivity**.
