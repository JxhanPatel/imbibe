# 836. Rectangle Overlap 🟢

**Topics:** Geometry, Math

## Intuition

Imagine two rectangular sheets of paper placed on a table.

They **overlap** only if they share some actual area.

If they only touch along an edge or at one corner, they do **not** overlap.

The easiest way to think about this is to check whether there is a positive-width intersection:

* The rectangles must overlap horizontally.
* The rectangles must overlap vertically.

If both are true, their intersection has positive area.

## Approach

For each rectangle:

```text
[x1, y1, x2, y2]
```

* `x1` = left edge
* `y1` = bottom edge
* `x2` = right edge
* `y2` = top edge

For the rectangles to overlap horizontally:

```python
max(x1_1, x1_2) < min(x2_1, x2_2)
```

This means the left side of the intersection is strictly before its right side.

For the rectangles to overlap vertically:

```python
max(y1_1, y1_2) < min(y2_1, y2_2)
```

This means the bottom of the intersection is strictly below its top.

Both conditions must be true.

The strict `<` is important. If we used `<=`, rectangles that only touch at an edge would incorrectly count as overlapping.

## Example Walkthrough

**Input**

```text
rec1 = [0,0,2,2]
rec2 = [1,1,3,3]
```

### Step 1: Check horizontal overlap

Rectangle 1:

```text
x range = [0, 2]
```

Rectangle 2:

```text
x range = [1, 3]
```

Their common x-range is:

```text
[1, 2]
```

Since `1 < 2`, there is horizontal overlap.

### Step 2: Check vertical overlap

Rectangle 1:

```text
y range = [0, 2]
```

Rectangle 2:

```text
y range = [1, 3]
```

Their common y-range is:

```text
[1, 2]
```

Since `1 < 2`, there is vertical overlap.

Both dimensions overlap, so the rectangles have positive area in common.

**Output**

```text
True
```

## Code

```python
class Solution:
    def isRectangleOverlap(self, rec1: List[int], rec2: List[int]) -> bool:
        x_overlap = max(rec1[0], rec2[0]) < min(rec1[2], rec2[2])
        y_overlap = max(rec1[1], rec2[1]) < min(rec1[3], rec2[3])
        return x_overlap and y_overlap
```

## Complexity

There are only a constant number of comparisons and arithmetic operations.

**Time Complexity**

$$
O(1)
$$

**Space Complexity**

$$
O(1)
$$

## Edge Cases

### 1. Rectangles touch at an edge

```text
rec1 = [0,0,1,1]
rec2 = [1,0,2,1]
```

The right edge of `rec1` is exactly the left edge of `rec2`.

There is no positive-width intersection.

```text
False
```

### 2. Rectangles touch at a corner

```text
rec1 = [0,0,1,1]
rec2 = [1,1,2,2]
```

They share only the point `(1,1)`.

A point has zero area, so:

```text
False
```

### 3. One rectangle is completely inside another

```text
rec1 = [0,0,5,5]
rec2 = [1,1,2,2]
```

There is positive intersection area.

```text
True
```

## Lessons

* Rectangle intersection can be reduced to checking overlap on the **x-axis and y-axis**.
* Both dimensions must overlap for the rectangles to have positive area.
* Use strict `<` rather than `<=` because touching edges or corners do not count.
* A useful general pattern is:

```python
max(left_edges) < min(right_edges)
```

This same interval-overlap idea appears in many geometry and scheduling problems.
