# 2058. Find the Minimum and Maximum Number of Nodes Between Critical Points 🟡

**Topics:** Linked List, Two Pointers

## Intuition

Imagine walking along a path and looking at every point together with the points immediately before and after it.

A node is a **critical point** when it forms either:

* a **peak**: its value is greater than both neighbors.
* a **valley**: its value is smaller than both neighbors.

For example:

```text
5 -> 3 -> 1 -> 2 -> 5 -> 1 -> 2
          ^              ^    ^
        valley          peak valley
```

The main thing we need is the **positions of the critical points**.

Instead of storing all of them, we only need to remember:

* `first`: the first critical point.
* `prev_crit`: the most recent critical point.
* `min_gap`: the smallest distance found so far.

This lets us solve the problem in one traversal using $O(1)$ extra space.

## Approach

We use three pointers:

```python
prev, curr = head, head.next
```

Here:

* `prev` is the node before `curr`.
* `curr` is the node we are checking.
* `curr.next` is the node after `curr`.

This gives us all three values needed to determine whether `curr` is a critical point.

### 1. Handle lists that are too short

A critical point needs both a previous and a next node.

Therefore, a list with fewer than three nodes cannot contain a critical point.

```python
if not head or not head.next or not head.next.next:
    return [-1,-1]
```

### 2. Track positions

We start at index `1` because `curr` starts at the second node.

```python
i = 1
```

We also initialize:

```python
first = prev_crit = -1
min_gap = float("inf")
```

* `first` stores the first critical point.
* `prev_crit` stores the previous critical point.
* `min_gap` stores the minimum distance between critical points.

### 3. Check whether `curr` is critical

A local maximum:

```python
curr.val > prev.val and curr.val > curr.next.val
```

A local minimum:

```python
curr.val < prev.val and curr.val < curr.next.val
```

Your code combines both conditions:

```python
if (curr.val > prev.val and curr.val > curr.next.val) or (curr.val < prev.val and curr.val < curr.next.val):
```

### 4. Store the first critical point

When we encounter the first critical point:

```python
if first < 0:
    first = i
```

We don't calculate a distance yet because there is no previous critical point.

### 5. Calculate the minimum distance

For every critical point after the first one:

```python
elif prev_crit > 0:
    min_gap = min(min_gap, i - prev_crit)
```

The distance between two consecutive critical points is:

```text
current position - previous critical position
```

We keep the smallest one.

Then:

```python
prev_crit = i
```

updates the most recent critical point.

### 6. Move through the list

After checking the current node:

```python
prev, curr = curr, curr.next
i += 1
```

So both pointers move forward by one position.

### 7. Calculate the maximum distance

After traversal, if we found at least two critical points:

```python
prev_crit - first
```

gives the distance between the first and last critical points.

This is the maximum possible distance.

If there was only one critical point:

```python
if prev_crit == first:
    return [-1, -1]
```

we return `[-1, -1]`.

## Example Walkthrough

Consider:

```text
head = [5,3,1,2,5,1,2]
```

Positions:

```text
Index:  0  1  2  3  4  5  6
Value:  5  3  1  2  5  1  2
```

### Position 2

Value is `1`.

Neighbors:

```text
3 -> 1 -> 2
```

Since:

```text
1 < 3
1 < 2
```

it is a local minimum.

```text
first = 2
prev_crit = 2
```

### Position 4

Value is `5`.

Neighbors:

```text
2 -> 5 -> 1
```

Since:

```text
5 > 2
5 > 1
```

it is a local maximum.

Calculate the gap:

```text
4 - 2 = 2
```

So:

```text
min_gap = 2
prev_crit = 4
```

### Position 5

Value is `1`.

Neighbors:

```text
5 -> 1 -> 2
```

Since:

```text
1 < 5
1 < 2
```

it is another local minimum.

Calculate:

```text
5 - 4 = 1
```

Update:

```text
min_gap = 1
prev_crit = 5
```

### Final calculation

First critical point:

```text
first = 2
```

Last critical point:

```text
prev_crit = 5
```

Therefore:

```text
max distance = 5 - 2 = 3
```

Final result:

```text
[1, 3]
```

## Code

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def nodesBetweenCriticalPoints(self, head: Optional[ListNode]) -> List[int]:
        
        if not head or not head.next or not head.next.next:
            return [-1,-1]

        prev, curr = head, head.next
        i=1

        first = prev_crit = -1
        min_gap = float("inf")

        while curr.next:
            if (curr.val > prev.val and curr.val > curr.next.val) or (curr.val < prev.val and curr.val < curr.next.val):
                if first < 0:
                    first = i

                elif prev_crit > 0:
                    min_gap = min(min_gap, i - prev_crit)
                prev_crit = i
                
            prev, curr = curr, curr.next
            i += 1

        if prev_crit == first:
            return [-1, -1]

        return [min_gap, prev_crit - first]
```

## Complexity

The linked list is traversed only once.

**Time Complexity**

$$
O(n)
$$

**Space Complexity**

$$
O(1)
$$

We only maintain a few pointers and variables regardless of the size of the linked list.

## Edge Cases

### 1. Fewer than three nodes

```text
head = [3,1]
```

No node has both a previous and next node.

```text
[-1, -1]
```

### 2. Only one critical point

```text
head = [1,3,2,2]
```

Only `3` is a critical point.

Since we need two critical points:

```text
[-1, -1]
```

### 3. Equal neighboring values

```text
head = [1,3,3,2]
```

The first `3` is not a critical point because:

```text
3 > 1
3 > 3  # False
```

The comparison must be **strict**.

### 4. Exactly two critical points

```text
head = [1,3,2,4,1]
```

Critical points:

```text
index 1 -> local maximum
index 3 -> local maximum
```

Both distances are:

```text
3 - 1 = 2
```

Result:

```text
[2, 2]
```

## Lessons

* A critical point can be identified by looking at exactly **three consecutive nodes**.
* `prev`, `curr`, and `curr.next` are enough to detect local maxima and minima.
* You don't need to store every critical point.
* Keep only the **first** and **previous** critical point.
* The minimum distance comes from **consecutive critical points**.
* The maximum distance comes from the **first and last critical points**.
* This is a useful linked-list pattern when you need to compare neighboring nodes while keeping constant space.

The core pattern is:

```text
first critical point
        ↓
   previous critical point
        ↓
   current critical point

minimum → current - previous
maximum → last - first
```
