# 3727. Maximum Alternating Sum of Squares 🟡


Topics: Greedy, Sorting, Arrays, Mathematics

## Intuition

Imagine you have two groups of numbers: one group adds points to your score, while the other subtracts points.

The alternating score follows this pattern:

$$ a_0^2-a_1^2+a_2^2-a_3^2+\cdots $$

Numbers at even indices contribute positively, while numbers at odd indices contribute negatively.

Since squaring makes every number non-negative, we can focus on the squares of the numbers, regardless of whether the original numbers are positive or negative.

To maximize the score, we should:

- Place the largest squares in positions that add to the score.
- Place the smallest squares in positions that subtract from the score.

Think of it like putting your biggest rewards in the positive slots and your smallest costs in the negative slots.

## Approach

We will use a greedy strategy with sorting.

1. Square every number in `nums`.
2. Sort the squared values in ascending order.
3. Subtract the sum of the smaller half from the sum of the larger half.

Why does this work?

Let the squared values in sorted order be:

$$ b_0 \le b_1 \le \cdots \le b\_{n-1} $$

Every even-indexed position contributes positively, and every odd-indexed position contributes negatively.

Therefore, we should assign the largest values to positive positions and the smallest values to negative positions.

For an array of length $n$, the number of positive positions is:

$$ \left\lceil \frac{n}{2} \right\rceil $$

The number of negative positions is:

$$ \left\lfloor \frac{n}{2} \right\rfloor $$

After sorting, the optimal score is the sum of the largest $\lceil n/2 \rceil$ squared values minus the sum of the remaining values.

## Example Walkthrough

Input

```
nums = [1, 2, 3]
```

### Step 1: Square the numbers

```
[1, 4, 9]
```

### Step 2: Sort the squared values

```
[1, 4, 9]
```

There are two positive positions and one negative position.

### Step 3: Assign values optimally

Place `9` and `4` in positive positions, and `1` in the negative position.

One valid arrangement of the original numbers is:

```
[2, 1, 3]
```

Its score is:

$$ 2^2-1^2+3^2 $$

$$ =4-1+9 $$

$$ =\boxed{12} $$

Output

```
12
```

## Code

```python
class Solution:
    def maxAlternatingSum(self, nums: List[int]) -> int:
        squares = sorted(x*x for x in nums)
        mid = len(nums)//2

        return sum(squares[mid:]) - sum(squares[:mid])
```

## Complexity

Let $n$ be the length of `nums`.

Time complexity

$$ O(n\log n) $$

Squaring takes $O(n)$, sorting takes $O(n\log n)$, and calculating the sums takes $O(n)$.

Space complexity

$$ O(n) $$

The sorted list of squared values requires linear extra space.

## Edge Cases

### 1. Single element

```
nums = [5]
```

The only square contributes positively.

$$ 5^2=25 $$

Output: `25`

### 2. Negative numbers

```
nums = [-1, -2, -3]
```

Squaring removes the signs:

```
[1, 4, 9]
```

The maximum score is:

$$ 9+4-1=12 $$

Output: `12`

### 3. All elements are equal

```
nums = [2, 2, 2, 2]
```

Every square equals `4`. There are two positive and two negative positions.

$$ 4-4+4-4=0 $$

Output: `0`

### 4. Maximum constraints

```
nums = [40000, -40000]
```

The squared values are both $1{,}600{,}000{,}000$, so they cancel out.

Output: `0`

## Lessons

- Square before comparing: Negative and positive numbers with the same magnitude have identical squared values.
- Greedy assignment: Put the largest values in positive positions and the smallest values in negative positions.
- Sorting simplifies optimization: Once values are sorted, choosing the best groups becomes straightforward.
- Count matters: For odd-length arrays, there is one more positive position than negative position.
- Avoid brute force: Trying every permutation is too expensive for $n\leq 10^5$. Sorting provides an efficient solution in $O(n\log n)$.
