# 2091. Removing Minimum and Maximum From Array 🟡

## Intuition

Imagine the array is a line of people, and you need to remove two specific people: the one with the **smallest value** and the one with the **largest value**.

You can only remove people from either end of the line.

So once we know where the minimum and maximum are, there are only **three meaningful strategies**:

1. Remove both from the **front**.
2. Remove both from the **back**.
3. Remove one from the front and the other from the back.

The important observation is that we do **not** need to simulate every possible deletion. We only need to compare these three costs.

## Approach

First, find:

* `min_idx` = index of the minimum element
* `max_idx` = index of the maximum element

To make the formulas easier, ensure:

```python
min_idx < max_idx
```

If not, swap them.

Now calculate three possibilities.

### 1. Remove both from the front

We need to delete everything up to the farther element:

```text
max_idx + 1
```

### 2. Remove both from the back

We need to delete everything from the farther element to the end:

```text
n - min_idx
```

### 3. Remove one from each side

Remove the smaller index from the front and the larger index from the back:

```text
(min_idx + 1) + (n - max_idx)
```

Take the minimum of these three values.

## Example Walkthrough

Consider:

```text
nums = [2,10,7,5,4,1,8,6]
```

The minimum is `1` at index `5`.

The maximum is `10` at index `1`.

So:

```text
min_idx = 5
max_idx = 1
```

Swap them so that:

```text
min_idx = 1
max_idx = 5
```

Now calculate the three possibilities.

### Option 1: Both from the front

We need to remove through index `5`:

```text
5 + 1 = 6
```

Cost:

```text
6
```

### Option 2: Both from the back

Remove from index `1` onward:

```text
8 - 1 = 7
```

Cost:

```text
7
```

### Option 3: One from each side

Remove through index `1` from the front:

```text
1 + 1 = 2
```

Remove from index `5` to the end:

```text
8 - 5 = 3
```

Total:

```text
2 + 3 = 5
```

Therefore:

```text
answer = min(6, 7, 5)
       = 5
```

## Code

```python
class Solution:
    def minimumDeletions(self, nums: List[int]) -> int:
    
        n = len(nums)
        lo_i = nums.index(min(nums))
        hi_i = nums.index(max(nums))

        if lo_i > hi_i:
            lo_i, hi_i = hi_i, lo_i

        from_front = hi_i+1
        from_back = n - lo_i
        from_both = (lo_i+1) + (n-hi_i)

        return min(from_front, from_back, from_both)
```

## Complexity

Finding the minimum and maximum takes:

$$
O(n)
$$

Finding their indices also takes:

$$
O(n)
$$

The remaining calculations are constant time.

Overall:

$$
O(n)
$$

Space complexity:

$$
O(1)
$$

## Edge Cases

### 1. Single element

```text
nums = [101]
```

The only element is both the minimum and maximum.

We need only one deletion:

```text
answer = 1
```

### 2. Minimum and maximum are already at the ends

```text
nums = [1,2,3,4,5]
```

* Minimum is at index `0`
* Maximum is at index `4`

We can remove them with:

```text
1 + 1 = 2
```

Answer:

```text
2
```

### 3. Minimum and maximum are next to each other

```text
nums = [5,1,2,3,4]
```

Minimum is at index `1` and maximum at index `0`.

After ordering the indices:

```text
min_idx = 0
max_idx = 1
```

Remove both from the front:

```text
2 deletions
```

Answer:

```text
2
```

## Lessons

* When deletions are restricted to the **front and back**, focus on the positions of the elements you need to remove.
* Once the minimum and maximum indices are known, there are only **three relevant strategies**.
* This is a useful pattern for array problems involving removing elements from either end.
* Instead of simulating deletions, calculate the cost of each possible strategy directly.
* A good habit is to normalize indices first, such as ensuring:

```python
min_idx < max_idx
```

Then the formulas become much easier to reason about.
