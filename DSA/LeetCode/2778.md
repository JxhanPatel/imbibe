# 2778. Sum of Squares of Special Elements 🟢

Topics: Array, Math

## Intuition

Imagine you have a row of numbered lockers, and the total number of lockers is $$n$$.

Some lockers are special because their position divides the total number of lockers evenly. For example, if there are $$4$$ lockers, positions $$1$$, $$2$$, and $$4$$ are special because $$4$$ is divisible by each of these positions.

Our task is to find all special elements, square their values, and add those squares together.

## Approach

We can solve this problem with a single loop.

1. Find the length of the array, $$n$$.
2. Iterate through each element using its 1-based index.
3. Check whether $$n \bmod i = 0$$. If true, the element is special.
4. Add the square of that element to the total.
5. Return the total after processing the array.

Python uses zero-based indexing, so we use `i + 1` to get the required 1-based index.

## Example Walkthrough

Input

```
nums = [1, 2, 3, 4]
```

The array length is $$n = 4$$.

| Index $$i$$ | Element | $$4 \bmod i$$ | Special? | Square added   |
| ------------- | ------- | --------------- | -------- | -------------- |
| 1             | 1       | 0               | Yes      | $$1^2 = 1$$  |
| 2             | 2       | 0               | Yes      | $$2^2 = 4$$  |
| 3             | 3       | 1               | No       | 0              |
| 4             | 4       | 0               | Yes      | $$4^2 = 16$$ |

The final sum is:

$$ 1 + 4 + 16 = 21 $$

Output

```
21
```

## Code

```python
class Solution:
    def sumOfSquares(self, nums: List[int]) -> int:
        n = len(nums)
        total=0

        for i, num in enumerate(nums, 1):
            if n%i == 0:
                total += num * num

        return total
```

## Complexity

Time Complexity

$$ O(n) $$

We traverse the array exactly once, performing a constant-time divisibility check and square calculation for each element.

Space Complexity

$$ O(1) $$

We use only a few variables, regardless of the array size.

## Edge Cases

1. Single element
   ```
   nums = [5]
   ```
   Since $$1$$ divides $$1$$, the only element is special.

   Output: `25`
2. Array length is a prime number
   ```
   nums = [2, 3, 4, 5, 6]
   ```
   For $$n = 5$$, only positions $$1$$ and $$5$$ are special.

   Output: $$2^2 + 6^2 = 40$$
3. Every position divides the length
   ```
   nums = [1, 2, 3, 4, 5, 6]
   ```
   For $$n = 6$$, positions $$1$$, $$2$$, $$3$$, and $$6$$ are special.

   Output: $$1^2 + 2^2 + 3^2 + 6^2 = 50$$

## Lessons

- Divisibility checks: Use `n % i == 0` to determine whether an index divides the array length.
- Index conversion: `enumerate(nums, 1)` provides 1-based indices while iterating through a Python list.
- Running totals: Accumulate results directly instead of creating another list of special elements.
- Recognize simple constraints: A single traversal is sufficient when each element can be evaluated independently.
