# 2916. Subarrays Distinct Element Sum of Squares II 🔴

**Topics:** Array, Hash Table, Divide and Conquer, Segment Tree, Binary Indexed Tree

## Intuition

Imagine you are managing a growing list of items coming in one by one. Every time a new item arrives, you look at all possible starting points in your history up to the current moment to see how many unique items each subarray contains. Squaring these counts and summing them up gives a total score for that day.

If you recalculated everything from scratch for every new item, it would take far too much time as the list grows large. Notice, however, that when a new element arrives, it only changes the distinct counts for subarrays that start after its previous appearance. For all starting points before that previous appearance, the new element is a repeat, so the distinct counts remain completely unchanged.

We can visualize this as a row of lockers representing each starting index. When a new element arrives, a specific range of lockers gets its distinct count incremented by one. Because we need the sum of squared counts, a segment tree with lazy propagation helps us efficiently update ranges and query the total sum of squares in logarithmic time.

## Approach

1. **State Definition**: Let $v_i$ be the number of distinct elements in the subarray starting at index $i$ and ending at the current index $j$. We want to maintain $\sum v_i^2$ for all valid starting indices $0 \le i \le j$.
2. **Processing Each Element**: As we iterate $j$ from $0$ to $n-1$:
* Let $p$ be the last seen index of `nums[j]` (or $-1$ if it has never appeared before).
* When we include `nums[j]`, any subarray starting between $p + 1$ and $j$ now includes a new distinct element. Thus, for all $i \in [p + 1, j]$, $v_i$ increases by $1$.
* For $i \le p$, $v_i$ remains unchanged.


3. **Segment Tree Range Update**: When a value $v_i$ increments by $1$, its square $(v_i + 1)^2$ expands algebraically to $v_i^2 + 2v_i + 1$.
* This means our segment tree needs to maintain both the sum of values ($\sum v_i$) and the sum of squared values ($\sum v_i^2$) for each node, along with a lazy propagation tag for range increments.
* When applying a lazy tag $add$ to a node of length $len$, the updates are:
* $\sum v_i^2 \leftarrow \sum v_i^2 + 2 \times add \times \sum v_i + add^2 \times len$
* $\sum v_i \leftarrow \sum v_i + add \times len$




4. **Accumulating the Answer**: At each step $j$, after updating the range $[p + 1, j]$ in the segment tree, the total sum of squares for all subarrays ending at $j$ is stored at the root of the segment tree ($\sum_{i=0}^j v_i^2$). We add this value to our running total modulo $10^9 + 7$.

## Example Walkthrough

Let us trace `nums = [1, 2, 1]` step by step.

* **Step 0 ($j = 0$, element `1`):**
* Last occurrence of `1` is $-1$, so update range $[0, 0]$.
* $v_0$ becomes $1$.
* Sum of squares for subarrays ending at index $0$: $v_0^2 = 1^2 = 1$. Total sum = $1$.


* **Step 1 ($j = 1$, element `2`):**
* Last occurrence of `2` is $-1$, so update range $[0, 1]$.
* $v_0$ becomes $2$, $v_1$ becomes $1$.
* Sum of squares: $2^2 + 1^2 = 5$. Running total = $1 + 5 = 6$.


* **Step 2 ($j = 2$, element `1`):**
* Last occurrence of `1` is $0$, so update range $[0 + 1, 2] = [1, 2]$.
* $v_0$ remains $2$, $v_1$ becomes $2$, $v_2$ becomes $1$.
* Sum of squares: $2^2 + 2^2 + 1^2 = 4 + 4 + 1 = 9$. Running total = $6 + 9 = 15$.



Final answer is $15$, which matches Example 1.

## Code

```python
class SegmentTree:
    def __init__(self, n: int):
        self.n = n
        self.mod = 10**9 + 7
        self.sum_v = [0] * (4 * n)
        self.sum_v2 = [0] * (4 * n)
        self.lazy = [0] * (4 * n)

    def _push(self, node: int, length: int):
        if not self.lazy[node]:
            return
        add = self.lazy[node]
        left_len = length - length // 2
        right_len = length // 2
        
        self._apply(2 * node, add, left_len)
        self._apply(2 * node + 1, add, right_len)
        self.lazy[node] = 0

    def _apply(self, node: int, add: int, length: int):
        MOD = self.mod
        self.sum_v2[node] = (
            self.sum_v2[node] 
            + 2 * add * self.sum_v[node] 
            + add * add * length
        ) % MOD
        
        self.sum_v[node] = (self.sum_v[node] + add * length) % MOD
        self.lazy[node] = (self.lazy[node] + add) % MOD

    def update(self, node: int, l: int, r: int, ql: int, qr: int, add: int):
        if ql <= l and r <= qr:
            self._apply(node, add, r - l + 1)
            return
        
        mid = (l + r) // 2
        self._push(node, r - l + 1)
        
        if ql <= mid:
            self.update(2 * node, l, mid, ql, qr, add)
        if qr > mid:
            self.update(2 * node + 1, mid + 1, r, ql, qr, add)
            
        self.sum_v[node] = (self.sum_v[2 * node] + self.sum_v[2 * node + 1]) % MOD
        self.sum_v2[node] = (self.sum_v2[2 * node] + self.sum_v2[2 * node + 1]) % MOD


class Solution:
    def sumCounts(self, nums: list[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        tree = SegmentTree(n)
        last = {}
        total_sum = 0
        
        for j, x in enumerate(nums):
            p = last.get(x, -1)
            tree.update(1, 0, n - 1, p + 1, j, 1)
            total_sum = (total_sum + tree.sum_v2[1]) % MOD
            last[x] = j
            
        return total_sum
```

## Complexity

* **Time Complexity:** $O(n \log n)$. We iterate through the array of length $n$ once. For each element, we perform a range update on the segment tree which takes $O(\log n)$ time. Thus, the total time complexity is $O(n \log n)$.
* **Space Complexity:** $O(n)$. The segment tree arrays (`sum_v`, `sum_v2`, `lazy`) require $O(n)$ space, and the hash map `last` stores at most $n$ distinct elements.

## Edge Cases

1. **All identical elements (e.g., `[2, 2]`):**
* Each new element is a duplicate, so distinct counts remain $1$ for all subarrays. The sum of squares equals $1^2 + 1^2 + 1^2 = 3$. The algorithm correctly handles repeated updates.


2. **All distinct elements (e.g., `[1, 2, 3]`):**
* Every element is unique, so distinct counts grow progressively. The segment tree handles full range updates without overlapping previous occurrences.


3. **Single element array (e.g., `[5]`):**
* The loop runs once, updating range $[0, 0]$ and returning $1^2 = 1$.



## Lessons

* **Algebraic Expansion for Range Updates:** When updating squares in a lazy segment tree, recognizing that $(v + \Delta)^2 = v^2 + 2v\Delta + \Delta^2$ allows us to maintain both linear and quadratic sums efficiently.
* **Dynamic Range Contributions:** Tracking the last occurrence of each element transforms subarray counting problems into range update problems on starting indices.
