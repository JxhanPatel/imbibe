# 3875. Construct Uniform Parity Array I 🟢

**Topics:** Math, Parity, Array

## Intuition

At first, the problem looks like we need to carefully choose a subtraction for every element.

But the important part is to only think about **parity**.

Recall:

* `even - even = even`
* `odd - odd = even`
* `even - odd = odd`
* `odd - even = odd`

So, if we have at least one odd number, we can use it to control the parity of the other elements.

### Case 1: All numbers are even

We can simply choose every original number.

```text
[2, 4, 6] → [2, 4, 6]
```

Everything is already even.

### Case 2: There is exactly one odd number

Keep the odd number unchanged.

For every even number, subtract the odd number:

```text
even - odd = odd
```

For example:

```text
[2, 4, 7]

2 - 7 = -5  → odd
4 - 7 = -3  → odd
7          → odd
```

So everything can become odd.

### Case 3: There are at least two odd numbers

Keep the odd numbers as differences of two odd numbers:

```text
odd - odd = even
```

For example:

```text
[3, 5, 8]
```

We can make:

```text
3 - 5 = -2  → even
5 - 3 = 2   → even
8 - 3 = 5   → odd
```

That does not make everything even, so instead we should target odd parity. Keep the odd numbers and subtract an odd number from each even number:

```text
3          → odd
5          → odd
8 - 3 = 5  → odd
```

Everything becomes odd.

Therefore, **there is actually no impossible case**.

The answer is always `True`.

## Approach

We do not even need to construct `nums2`.

There is always a valid construction:

1. If all numbers are even, keep every number unchanged.
2. If at least one number is odd, choose one odd number as a reference.
3. Keep every odd number unchanged.
4. For every even number, subtract the odd reference:

   * `even - odd = odd`
5. Therefore, all resulting numbers are odd.

For `n = 1`, we simply keep the only number unchanged, so it is also valid.

Hence, the answer is always:

```python
True
```

## Example Walkthrough

Consider:

```text
nums1 = [2, 3, 6]
```

There is an odd number `3`.

Use `3` as the reference.

For the even numbers:

```text
2 - 3 = -1  → odd
6 - 3 = 3   → odd
```

Keep `3` unchanged:

```text
nums2 = [-1, 3, 3]
```

All elements are odd.

Therefore:

```text
True
```

## Edge Cases

### 1. Single element

Keep `5` unchanged.

All elements are odd, so:

### 2. All elements are even

```text

```

Keep everything unchanged:

```text
[2, 4, 8]
```

All elements are even.

Answer:

```text
True
```

```text

```

Use `9` as the reference:

```text
2 - 9 = -7
6 - 9 = -3
9     = 9
```

All are odd.

Answer:

```text
True
```

## Lessons

* In parity problems, focus on whether numbers are **odd or even**, not their actual values.
* Remember the key rules:

  * `even - odd = odd`
  * `odd - odd = even`
  * `even - even = even`
* Sometimes a problem that appears to require constructing an array reduces to proving that a valid construction **always exists**.
* When the answer is always the same, the best solution may not need to inspect the input at all.
