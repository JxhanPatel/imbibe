## 3863. Minimum Operations to Sort a String 🟡

**Topics:** String, Greedy

### Intuition

Imagine organizing a row of books on a shelf where you are allowed to rearrange any group of books except all of them at once. If the smallest book is already at the very front, or the largest is at the very back, you can sort the remaining books in a single sweep. If a key book is trapped somewhere in the middle, you might need a couple of steps to free and position it. For very short or completely locked configurations, it takes up to three steps or becomes impossible.

### Approach

1. **Check if already sorted:** If the string is already in non-descending order, zero operations are needed.
2. **Handle length two:** If the string has length two and is out of order, it is impossible to sort because any proper substring has length one, which cannot change the character order. Return `-1`.
3. **Analyze extreme characters:** Find the minimum and maximum characters in the string.
4. **One operation check:** If the first character is equal to the minimum character, or the last character is equal to the maximum character, we can sort everything except that fixed end in a single operation. Return `1`.
5. **Two operations check:** If any character in the interior (from index $1$ to $n - 2$) matches the minimum or maximum character, we can position it correctly in two operations.
6. **Default case:** For all other cases with length greater than two, the answer is `3`.

### Example Walkthrough

Let us trace `s = "dog"`:

1. The string is not sorted, and its length is $3$.
2. The minimum character is `'d'` and the maximum is `'g'`.
3. Notice that the first character `s[0]` is `'d'`, which matches the minimum character `mn`.
4. We can sort the substring from index $1$ to the end (`"og"`), transforming the string into `"dgo"`, which is fully sorted.
5. Total operations required: `1`.

### Code

```python
class Solution:
    def minOperations(self, s: str) -> int:
        if all(s[i] <= s[i + 1] for i in range(len(s) - 1)):
            return 0
        
        n = len(s)
        if n == 2:
            return -1
        
        mn = min(s)
        mx = max(s)
        
        if s[0] == mn or s[-1] == mx:
            return 1
            
        if any(c==mn or c==mx for c in s[1:-1]):
            return 2
            
        return 3

```

### Complexity

* **Time Complexity:** $O(n)$ where $n$ is the length of the string, because finding the minimum and maximum elements and checking order take linear time.
* **Space Complexity:** $O(1)$ auxiliary space beyond standard character references.

### Edge Cases

* **Already sorted strings:** Returns `0` immediately.
* **Two-character unsorted strings (e.g., `"gf"`):** Returns `-1` because no proper substring can alter their relative order.
* **Strings with extremes at boundaries:** Strings where the minimum is at the start or maximum is at the end return `1`.

### Lessons

* Substring sorting restrictions often simplify when we analyze the positions of global minimum and maximum elements.
* Bounding the answer through strategic case analysis avoids unnecessary simulations and guarantees an efficient linear-time solution.
