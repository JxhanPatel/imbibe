# 1254: Number of Closed Islands 🟡

**Topics:** Depth-First Search, Breadth-First Search, Matrix, Array

## Intuition

Imagine you are exploring an archipelago of islands in a vast ocean. Each island is made of land ($0$), and the surrounding sea is water ($1$). A closed island is a lake island that is completely enclosed by water, meaning no part of it touches the outer boundary of the map.

If an island touches the edge of the map, it spills out into the open ocean and is not closed. To solve this, think of it like castle defense: first, we scout the outer walls (the boundaries of the grid). Any land touching the border is unsafe because it connects to the outside world, so we sink it by converting border-connected $0$s into $1$s. Once all border-connected land is eliminated, every remaining isolated patch of land is guaranteed to be a fully enclosed closed island.

## Approach

1. **Boundary Flood Fill:** Iterate over all cells on the outer edges of the grid (first row, last row, first column, last column). If we encounter a $0$, perform a Depth-First Search to visit and convert all connected $0$s into $1$s. This removes any open land touching the grid boundary.
2. **Count Closed Islands:** Iterate through the entire grid cell by cell. Whenever we find a $0$, it represents the starting cell of a valid closed island. We increment our counter and use DFS to sink this entire island by turning its $0$s into $1$s so we do not count it twice.
3. **Return Count:** Return the total count of closed islands found.

## Example Walkthrough

Consider a small $3 \times 3$ grid:

```python
grid = [
    [1, 1, 1],
    [1, 0, 1],
    [1, 1, 1]
]

```

* **Step 1 (Boundary Check):** We check the outer border. There are no $0$s on the boundary.
* **Step 2 (Island Count):** We scan the interior and find a $0$ at position $(1, 1)$.
* **Step 3 (DFS / Sinking):** We increment our island count to $1$, and sink the connected land at $(1, 1)$ by turning it into $1$.
* **Result:** Total closed islands equal $1$.

## Code

```python
class Solution:
    def closedIsland(self, grid: list[list[int]]) -> int:

        rows, cols = len(grid), len(grid[0])
        
        def sink(r, c):
            if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] == 1:
                return

            grid[r][c] = 1
            sink(r+1, c)
            sink(r-1, c)
            sink(r, c+1)
            sink(r, c-1)
        
        for r in range(rows):
            for c in range(cols):
                if (r == 0 or r == rows - 1 or c == 0 or c == cols-1) and grid[r][c] == 0:
                    sink(r,c)
                    
        islands=0
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 0:
                    islands += 1
                    sink(r, c)
                    
        return islands
```

## Complexity

* **Time Complexity:** $O(m \times n)$ where $m$ is the number of rows and $n$ is the number of columns. Each cell in the grid is visited a constant number of times during the DFS traversals.
* **Space Complexity:** $O(m \times n)$ in the worst-case scenario due to the recursive call stack during DFS when the grid is filled entirely with land.

## Edge Cases

* **All Water:** The grid contains only $1$s. Expected output is $0$.
* **All Land:** All land touches the boundary, so the border-clearing phase sinks everything. Expected output is $0$.
* **Single Cell Grid:** A $1 \times 1$ grid. If it is $1$, output is $0$. If it is $0$, it touches the boundary and gets sunk, so output is $0$.

## Lessons

* **Boundary Reduction Trick:** Problems asking for enclosed components can often be simplified by starting your traversal from the boundary inwards rather than checking every interior cell first.
* **In-Place Modification:** Modifying the input grid directly by marking visited cells avoids the need for an auxiliary visited matrix, optimizing space.
