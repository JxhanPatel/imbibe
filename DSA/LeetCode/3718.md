# 3718. Smallest Missing Multiple of K 🟢

**Topics:** Array, Hash Table, Simulation

## Intuition

Imagine checking numbered parking spots reserved for multiples of `k`.

If `k = 2`, the spots we care about are:

```text
2, 4, 6, 8, 10, ...
```

We only need to start from the first positive multiple and keep checking one by one.

* Is `2` present?
* Is `4` present?
* Is `6` present?
* Is `8` present?
* Is `10` present?

The moment we find a multiple that does not exist in `nums`, that must be the answer because we checked every smaller positive multiple first.

Using a `set` makes these presence checks very fast.

## Approach

1. Convert `nums` into a `set`.
2. Start with the smallest positive multiple:

```python
multiple = k
```

3. While `multiple` exists in the set, move to the next multiple:

```python
multiple += k
```

4. As soon as a multiple is missing, return it.

## Example Walkthrough

**Input**

```text
nums = [8,2,3,4,6]
k = 2
```

Convert `nums` into a set:

```text
{2,3,4,6,8}
```

Now check multiples of `2`:

| Multiple | Present? | Action      |
| -------- | -------- | ----------- |
| 2        | Yes      | Continue    |
| 4        | Yes      | Continue    |
| 6        | Yes      | Continue    |
| 8        | Yes      | Continue    |
| 10       | No       | Return `10` |

**Output**

```text
10
```

## Code

```python
class Solution:
    def missingMultiple(self, nums: List[int], k: int) -> int:
        vals = set(nums)
        cand=k
        
        while cand in vals:
            cand += k
        return cand
```

## Complexity

Let $n$ be the length of `nums`.

Creating the set takes:

$$
O(n)
$$

If we check $m$ multiples before finding the answer, the total time is:

$$
O(n + m)
$$

Since `nums.length <= 100`, we can also view this as effectively linear for the given constraints.

**Space Complexity:**

$$
O(n)
$$

for storing the set.

## Edge Cases

1. **The first multiple is missing**

```text
nums = [1,4,7,10,15]
k = 5
```

`5` is missing immediately.

Answer:

```text
5
```

2. **All multiples up to some point are present**

```text
nums = [3,6,9,12]
k = 3
```

The next missing multiple is:

```text
15
```

3. **`k` is larger than every value in `nums`**

```text
nums = [1,2,3]
k = 10
```

`10` is not present.

Answer:

```text
10
```

## Lessons

* A `set` is useful when you repeatedly need to check whether a value exists.
* When searching for the smallest missing value in an ordered sequence, check candidates in increasing order.
* You do not need to sort the array because set membership gives fast lookups.
* The first missing value encountered is automatically the smallest answer because we check multiples from smallest to largest.
