# 3723. Maximize Sum of Squares of Digits 🟡

**Topics:** Greedy, Math, Strings

## Intuition

Imagine you have a fixed sum that you need to distribute across a certain number of digit positions. Each position can hold a digit from `0` to `9`, and your goal is to maximize the sum of the squares of those digits.

The key observation is that **larger digits contribute disproportionately more to the score**. For example, $9^2 = 81$, while $4^2 + 5^2 = 41$.

Therefore, we should use as many `9`s as possible, followed by the remaining sum as a single digit. Any unused positions are filled with zeros.

This also produces the maximum integer because the largest digits appear first.

## Approach

We use a **greedy strategy** to construct the answer efficiently.

1. **Check feasibility:** If `total_sum` exceeds `9 * num` or is negative, return an empty string.
2. **Count the nines:** Use `divmod(total_sum, 9)` to calculate how many complete `9`s fit into the sum and the remainder left over.
3. **Build the result:** Initialize `res` with the required number of `9`s.
4. **Add the remainder:** If the remainder is greater than zero, append it as the next digit.
5. **Fill remaining positions:** Calculate the number of unused positions and fill them with zeros.
6. **Return the answer:** Join the list of digits into a string.

The `divmod()` function makes the greedy calculation concise by returning both the quotient and remainder in one operation.

## Example Walkthrough

**Input**

```text
num = 5
total_sum = 23
```

### Step 1: Check feasibility

The maximum possible digit sum is:

$$
9 \times 5 = 45
$$

Since $23 \leq 45$, a valid number is possible.

### Step 2: Calculate the number of nines

```python
nines_count, rem = divmod(23, 9)
```

This gives:

```text
nines_count = 2
rem = 5
```

We can use two `9`s, with a remaining sum of `5`.

### Step 3: Build the result

```python
res = ["9", "9"]
```

Since the remainder is positive, append `"5"`:

```text
res = ["9", "9", "5"]
```

### Step 4: Fill the remaining positions

There are five positions in total, and three have been used.

```python
zeros_count = 5 - 3
```

Therefore, `zeros_count = 2`, so we append two zeros.

```text
res = ["9", "9", "5", "0", "0"]
```

**Output**

```text
"99500"
```

Its digit sum is $9 + 9 + 5 = 23$, and its score is:

$$
9^2 + 9^2 + 5^2 = 187
$$

## Code

```python
class Solution:
    def maxSumOfSquares(self, num: int, total_sum: int) -> str:
        if total_sum > 9*num or total_sum < 0:
            return ""

        nines_count, rem = divmod(total_sum, 9)
        
        res = ["9"] * nines_count
        
        if rem>0:
            res.append(str(rem))
            
        zeros_count = num - len(res)

        if zeros_count > 0:
            res.extend(["0"] * zeros_count)
            
        return "".join(res)
```

## Complexity

Let $n = \text{num}$.

**Time Complexity**

$$
O(n)
$$

Creating the list of digits, filling unused positions with zeros, and joining the result take linear time in the length of the answer.

**Space Complexity**

$$
O(n)
$$

The `res` list stores up to `num` digits, and the returned string also contains `num` characters.

## Edge Cases

### 1. Sum exceeds the maximum possible

```text
num = 2
total_sum = 19
```

The maximum sum for two digits is $18$.

Output:

```text
""
```

### 2. Sum is exactly divisible by nine

```text
num = 3
total_sum = 18
```

Two nines use the entire sum, and the remaining position is filled with zero.

Output:

```text
"990"
```

### 3. Sum is smaller than nine

```text
num = 4
total_sum = 5
```

No nines are needed. The remainder becomes the first digit, followed by zeros.

Output:

```text
"5000"
```

### 4. Sum is zero

```text
num = 3
total_sum = 0
```

No nines or remainder digits are added, so all positions are filled with zeros.

Output:

```text
"000"
```

Although zero is outside the original problem's constraints, the implementation handles it correctly.

## Lessons

- **Greedy strategy:** Use the largest possible digit first to maximize the sum of squares.
- **`divmod()` trick:** Calculate the number of complete groups of nine and the leftover sum in one operation.
- **String construction:** Build digits in a list and use `"".join()` for efficient output.
- **Fixed-length numbers:** Always fill unused positions with zeros to ensure the result has exactly `num` digits.
- **Feasibility checks:** A number with `num` digits can have a maximum digit sum of $9 \times num$.
