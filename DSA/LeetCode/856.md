# 856. Score of Parentheses 🟡

**Topics:** Stack, String

## Intuition

Think of every opening parenthesis `(` as entering a new room.

While you are inside that room, you calculate its score. When you encounter `)`, you finish that room and bring its score back to the previous room.

There are two important rules:

* `()` contributes `1`.
* `(A)` doubles the score of `A`.
* Separate groups like `()()` are simply added together.

A stack is a natural fit because parentheses are nested in **last-in, first-out** order.

## Approach

We use a **stack of scores**.

1. Start with `0` on the stack for the outermost level.
2. When we see `(`, push `0` to start a new nested group.
3. When we see `)`:

   * Remove the score of the current group.
   * If that score is `0`, the group was `()`, so its value is `1`.
   * Otherwise, its value is `2 * score`.
   * Add this value to the previous level.
4. The remaining value on the stack is the answer.

This directly follows the rules of the problem.



## Example Walkthrough

Consider:

```text
s = "(())"
```

### Step 1

Start with:

```text
stack = [0]
```

See `(`:

```text
stack = [0, 0]
```

We have entered a new group.

### Step 2

See another `(`:

```text
stack = [0, 0, 0]
```

### Step 3

See `)`.

The top value is `0`, meaning we found `()`.

Its score is `1`.

```text
stack = [0, 0]
```

### Step 4

See the final `)`.

The inner group has score `1`, so `(A)` gives:

```text
2 * 1 = 2
```

Add it to the outer level:

```text
stack = [2]
```

Therefore:

```text
Output = 2
```

## Code

```python
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        stack=[0]

        for ch in s:
            if ch == '(':
                stack.append(0)

            else:
                score = stack.pop()

                score = max(1, 2*score)

                stack[-1] += score

        return stack[0]
```

The key line is:

```python
score = max(1, 2 * score)
```

It handles both cases:

```text
()    -> max(1, 0) = 1
(A)   -> max(1, 2 * A) = 2 * A
```

The stack approach follows the nested structure of the parentheses, which is the core pattern to recognize here. 

## Complexity

Let $n$ be the length of the string.

**Time Complexity:**

$$
O(n)
$$

We process every parenthesis once.

**Space Complexity:**

$$
O(n)
$$

In the worst case, all parentheses can be nested, so the stack can contain $O(n)$ elements.

## Edge Cases

### 1. Simple pair

```text
s = "()"
```

```text
Output = 1
```

### 2. Deeply nested

```text
s = "((()))"
```

Calculation:

```text
()       = 1
(())     = 2
((()))   = 4
```

```text
Output = 4
```

### 3. Separate groups

```text
s = "()()()"
```

Each pair contributes `1`:

```text
1 + 1 + 1 = 3
```

```text
Output = 3
```

## Lessons

* Parentheses with **nested structure** are a strong signal for using a stack.
* Treat each `(` as starting a new calculation level.
* When `)` closes a level, convert its inner score using the problem's rules.
* `()` is a special base case with score `1`.
* Nested parentheses multiply the inner score by `2`.
* Separate balanced groups are added together.
* A useful pattern to remember is **push on opening, calculate on closing**. This is the same general stack idea used in many bracket and expression problems.
