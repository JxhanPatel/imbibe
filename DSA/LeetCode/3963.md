# 3963. Create Grid With Exactly One Path 🟢

**Topics:** Matrix, Constructive

## Intuition

Imagine you are designing a maze where visitors must follow one exact route from the entrance at the top-left to the exit at the bottom-right. Instead of building a complex labyrinth, you can block off every room in the building with walls and construct a single open hallway along the perimeter. By opening up the entire top row and the rightmost column, any traveler starting at the top-left has only one possible direction to move initially and zero alternative branches, forcing them to traverse the exact border corridor straight to the destination.

## Approach

1. Initialize an $m \times n$ grid filled entirely with obstacle cells (`#`).
2. Set every cell in the first row ($row = 0$) to a free cell (`.`). This creates a horizontal runway across the top.
3. Set every cell in the last column ($col = n - 1$) to a free cell (`.`). This creates a vertical drop down the rightmost edge.
4. Since movement is restricted to right and down, a traveler starts at $(0, 0)$, moves right along the top row until hitting the rightmost column, and then moves straight down to $(m - 1, n - 1)$. Because all other interior cells remain obstacles, no alternative paths can exist.
5. Convert each row into a string and return the resulting grid.

Path: $(0,0) \to (0,1) \to (0,2) \to (1,2)$.
Every other cell is an obstacle, so this is the unique valid path.



## Code

```python
class Solution:
    def createGrid(self, m: int, n: int) -> list[str]:
        g = [['#' for _ in range(n)] for _ in range(m)]

        for j in range(n):
            g[0][j] = '.'

        for i in range(m):
            g[i][n - 1] = '.'
            
        return [''.join(r) for r in g]

```

## Complexity

* **Time Complexity:** $O(m \times n)$ because we initialize and update every cell in the $m \times n$ grid.
* **Space Complexity:** $O(m \times n)$ to store the grid structure and return the list of strings.

## Edge Cases

* **Single cell ($m = 1, n = 1$):** Returns `["."]`, where the start and end are the same cell with zero moves needed.
* **Single row ($m = 1, n = n$):** Returns a single string of all free cells, creating a straight horizontal path.
* **Maximum constraints ($m = 25, n = 25$):** Executes in a fraction of a millisecond well within memory and time limits.

## Lessons

* Constructive problems often become trivial when you establish a rigid baseline (like filling the grid with obstacles) and carve out the minimal viable pathway.
* Leveraging grid boundaries naturally restricts movement degrees of freedom, preventing branching paths without requiring complex backtracking or graph searches.
