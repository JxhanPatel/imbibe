# 2124. Check if All A's Appears Before All B's 🟢

**Topics:** String

## Intuition

Think of a string made of `'a'` and `'b'` like a line of people waiting in two groups: early birds (`'a'`) and night owls (`'b'`). Once the first night owl (`'b'`) shows up in line, no early bird (`'a'`) should appear after them. If you spot an `'a'` after a `'b'`, the order is broken.

## Approach

We can track whether we have seen any `'b'` yet as we scan the string from left to right.

1. Keep a boolean flag `seen_b` initialized to `False`.
2. Loop through each character `ch` in `s`:
* If `ch == 'b'`, set `seen_b = True`.
* If `ch == 'a'` and `seen_b` is already `True`, we found an `'a'` after a `'b'`, so return `False`.


3. If we finish the loop without finding an `'a'` after a `'b'`, return `True`.

## Example Walkthrough

Suppose `s = "aaabbb"`:

* Index 0 (`'a'`): `seen_b` is `False`, nothing broken. `seen_b` stays `False`.
* Index 1 (`'a'`): `seen_b` is `False`, nothing broken. `seen_b` stays `False`.
* Index 2 (`'a'`): `seen_b` is `False`, nothing broken. `seen_b` stays `False`.
* Index 3 (`'b'`): `seen_b` becomes `True`.
* Index 4 (`'b'`): `seen_b` is `True`, `'b'` after `'b'` is fine.
* Index 5 (`'b'`): `seen_b` is `True`, `'b'` after `'b'` is fine.

End of string reached, so we return `True`.

## Code


```python
class Solution:
    def checkString(self, s: str) -> bool:
        b_zone = False

        for c in s:
            if c=="b":
                b_zone = True

            else:
                if b_zone:
                    return False
        return True
```

## Complexity

* **Time Complexity:** $O(n)$, where $n$ is the length of `s`. We inspect each character at most once.
* **Space Complexity:** $O(1)$, because we only store a single boolean variable regardless of input size.

## Edge Cases

* **All `'a'` characters:** `s = "aaa"` -> `True`. No `'b'` ever appears, so no `'a'` comes after a `'b'`.
* **All `'b'` characters:** `s = "bbb"` -> `True`. There are no `'a'` characters to violate the condition.
* **Single character:** `s = "a"` or `s = "b"` -> `True`. A string of length 1 cannot have an `'a'` after a `'b'`.

## Lessons

* **State tracking beats extra passes:** A simple boolean flag can capture ordering rules in one scan without sorting or extra data structures.
* **Check the complement condition:** Instead of checking every pair of `'a'` and `'b'` indices, asking "does an `'a'` ever follow a `'b'`?" simplifies the problem into a single rule.
