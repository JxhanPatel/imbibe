# 1520. Maximum Number of Non-Overlapping Substrings 🔴

**Topics:** String, Greedy, Intervals

## Intuition

Think of every character as having a **range** in the string.

For example, if `a` appears at positions `0` and `7`, then any valid substring containing `a` must include the entire range:

```text
[0, 7]
```

Now imagine we start with one character's first and last occurrence.

While looking inside that range, we may find other characters. If one of those characters appears later outside our current range, we must expand the range to include it.

For example:

```text
s = "adefaddaccc"
```

Starting with `a`:

```text
a -> [0, 7]
```

The range contains `d`, `e`, and `f`.

Their occurrences are already inside `[0, 7]`, so:

```text
"adefadda"
```

is a valid candidate.

But starting from `d` gives:

```text
d -> [1, 5]
```

Inside this range we encounter `a`.

However, `a` also appears at position `0`, which is outside the range.

So `[1, 5]` cannot be a valid substring.

Once we find all valid ranges, the problem becomes:

> Choose the maximum number of non-overlapping intervals.

For that, we sort candidates by their ending position and greedily choose the earliest-ending interval.


## Approach

We use three main steps.

### 1. Find the first and last occurrence of every character

We maintain two arrays:

```python
first_seen = [n] * 26
last_seen = [-1] * 26
```

For every character:

```text
first_seen[c] = first position of c
last_seen[c]  = last position of c
```

For:

```text
s = "adefaddaccc"
```

we get:

```text
a -> [0, 7]
d -> [1, 5]
e -> [2, 2]
f -> [3, 3]
c -> [8, 10]
```


### 2. Build valid candidate intervals

For every character that exists in the string, we start with:

```python
lo = first_seen[c]
hi = last_seen[c]
```

Then we scan from `lo` to `hi`.

```python
while j <= hi:
```

For every character we encounter, we check its first occurrence.

```python
if first_seen[cur] < lo:
    ok = False
    break
```

This means the current interval contains a character whose earlier occurrence lies outside the interval.

Therefore, the interval cannot be valid.

Otherwise, we expand the interval when necessary:

```python
if last_seen[cur] > hi:
    hi = last_seen[cur]
```

This is important because the substring must contain **all occurrences** of every character inside it.

Once the scan finishes successfully, we store:

```python
candidates.append((lo, hi))
```


### 3. Greedily select non-overlapping intervals

Now every candidate is represented as:

```text
(lo, hi)
```

We sort them by their ending position:

```python
candidates.sort(key=lambda pair: pair[1])
```

Then we greedily choose an interval whenever it does not overlap the previously selected one:

```python
if lo <= last_end:
    continue
```

Otherwise:

```python
res.append(s[lo:hi + 1])
last_end = hi
```

Why sort by the ending position?

Because an interval that finishes earlier leaves more space for the remaining intervals.

So choosing the earliest-ending valid interval allows us to maximize the number of non-overlapping substrings.


## Example Walkthrough

Consider:

```text
s = "adefaddaccc"
```

### Step 1: First and last occurrences

```text
a -> [0, 7]
d -> [1, 5]
e -> [2, 2]
f -> [3, 3]
c -> [8, 10]
```


### Step 2: Generate candidates

For `a`:

```text
lo = 0
hi = 7
```

Everything inside `[0, 7]` has all of its occurrences inside the range.

So:

```text
[0, 7] -> "adefadda"
```

is valid.

For `d`:

```text
lo = 1
hi = 5
```

We encounter `a`, but:

```text
first_seen[a] = 0
```

and:

```text
0 < 1
```

So this candidate is invalid.

For `e`:

```text
[2, 2] -> "e"
```

valid.

For `f`:

```text
[3, 3] -> "f"
```

valid.

For `c`:

```text
[8, 10] -> "ccc"
```

valid.

Candidates:

```text
[0, 7] -> "adefadda"
[2, 2] -> "e"
[3, 3] -> "f"
[8, 10] -> "ccc"
```


### Step 3: Sort by ending position

The candidates become:

```text
[2, 2]
[3, 3]
[0, 7]
[8, 10]
```

Now select greedily.

First:

```text
[2, 2] -> "e"
```

Then:

```text
[3, 3] -> "f"
```

`[0, 7]` overlaps with the already selected intervals, so we skip it.

Finally:

```text
[8, 10] -> "ccc"
```

The result is:

```text
["e", "f", "ccc"]
```


## Code

```python
class Solution:
    def maxNumOfSubstrings(self, s: str) -> list[str]:
        n = len(s)
        first_seen = [n]*26
        last_seen = [-1]*26

        for i, ch in enumerate(s):
            idx = ord(ch) - ord('a')

            if i < first_seen[idx]:
                first_seen[idx] = i
            last_seen[idx] = i

        candidates=[]

        for c in range(26):
            if last_seen[c] == -1:
                continue

            lo, hi = first_seen[c], last_seen[c]
            ok = True
            j=lo

            while j <= hi:
                cur = ord(s[j]) - ord('a')

                if first_seen[cur] < lo:
                    ok = False
                    break

                if last_seen[cur] > hi:
                    hi = last_seen[cur]
                j += 1

            if ok:
                candidates.append((lo, hi))

        candidates.sort(key=lambda pair: pair[1])

        res=[]
        last_end = -1
        
        for lo, hi in candidates:
            if lo <= last_end:
                continue
            res.append(s[lo:hi + 1])
            last_end = hi

        return res
```


## Complexity

There are only **26 lowercase English characters**.

Finding the first and last occurrences takes:

$$
O(n)
$$

We consider at most 26 candidate intervals.

Each candidate may scan part of the string, but because the alphabet size is fixed at 26, the total work remains linear with respect to the input size.

Sorting at most 26 candidates takes:

$$
O(26 \log 26)
$$

which is constant.

Therefore, the overall time complexity is:

$$
O(n)
$$

Space complexity:

$$
O(1)
$$

The arrays contain only 26 elements, and the number of candidates is at most 26.

The returned substrings themselves are output space and are not counted as auxiliary space.


## Edge Cases

### 1. Every character appears once

```text
s = "abcdef"
```

Each character can form its own substring:

```text
["a", "b", "c", "d", "e", "f"]
```


### 2. Only one character

```text
s = "aaaaa"
```

The entire string must be selected:

```text
["aaaaa"]
```

We cannot split it because every substring containing `a` must contain all occurrences of `a`.


### 3. Nested candidates

```text
s = "abbaccd"
```

Some valid candidates are:

```text
"abba"
"bb"
"cc"
"d"
```

The greedy process selects:

```text
["bb", "cc", "d"]
```

This gives the maximum number of substrings while also keeping their total length minimal.


## Lessons

* When a problem says a substring must contain **all occurrences of its characters**, think about first and last positions.
* Build a range from the first occurrence of a character to its last occurrence.
* Expand the range when you discover another character whose last occurrence lies outside it.
* Reject the range if a character inside it has an occurrence before the starting position.
* Once the valid substrings become intervals, the problem turns into a classic **greedy interval selection** problem.
* Sorting by ending position is a powerful pattern for maximizing the number of non-overlapping intervals.

The key pattern is:

```text
First / Last Occurrences
          ↓
Expand Intervals
          ↓
Valid Candidates
          ↓
Sort by End
          ↓
Greedy Selection
```
