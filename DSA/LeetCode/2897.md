# 2897. Apply Operations on Array to Maximize Sum of Squares 🔴

**Topics:** Array, Bit Manipulation, Greedy

## Intuition

Imagine you have several boxes containing bits. You can redistribute these bits between boxes using bitwise AND and OR operations without losing any set bits.

For example:

```text
6 = 110
5 = 101
```

Applying AND and OR gives:

```text
6 & 5 = 100 = 4
6 | 5 = 111 = 7
```

The numbers change from `[6, 5]` to `[4, 7]`, but the total count of each set bit remains unchanged.

Since the goal is to maximize the sum of squares, we want to concentrate as many available bits as possible into each of the `k` selected numbers. Larger numbers contribute disproportionately more to the answer when squared.

## Approach

We use a **greedy bit-counting strategy**.

1. **Count set bits:** For every number, examine its binary representation and count how many times each bit position is set.
2. **Construct numbers:** Build each of the `k` numbers by including every bit position whose count is still positive.
3. **Update counts:** Whenever a bit is used, decrease its count by one so it cannot be reused more times than it originally appeared.
4. **Accumulate squares:** Add the square of each constructed number to the answer, taking modulo \(10^9+7\).

The array `bit_cnt` stores the number of available set bits at each position. Since the constraints guarantee `nums[i] <= 10^9`, 30 bit positions are sufficient.

## Example Walkthrough

**Input**

```text
nums = [2, 6, 5, 8]
k = 2
```

### Step 1: Count set bits

```text
2 = 0010
6 = 0110
5 = 0101
8 = 1000
```

The resulting bit counts are:

| Bit value | Count |
|---:|---:|
| 1 | 1 |
| 2 | 2 |
| 4 | 2 |
| 8 | 1 |

### Step 2: Construct the first number

Every bit with a positive count is included.

```text
val = 1 + 2 + 4 + 8 = 15
```

After using these bits, the remaining counts are:

```text
bit 1: 0
bit 2: 1
bit 4: 1
bit 8: 0
```

The answer becomes:

$$
15^2 = 225
$$

### Step 3: Construct the second number

Only bits `2` and `4` remain available.

```text
val = 2 + 4 = 6
```

The answer becomes:

$$
225 + 6^2 = 261
$$

**Output**

```text
261
```

## Code

```python
class Solution:
    def maxSum(self, nums: List[int], k: int) -> int:
        MOD = 10**9+7
        bit_cnt = [0]*30

        for num in nums:
            b=0
            while num:
                if num & 1:
                    bit_cnt[b] += 1
                num >>= 1
                b += 1

        total = 0

        for _ in range(k):
            val = 0


            for b, c in enumerate(bit_cnt):
                if c == 0:
                    continue
                val |= 1 << b
                bit_cnt[b] -= 1
            total = (total+val*val) % MOD

        return total
```

## Complexity

Let \(n\) be the length of `nums` and \(B=30\) be the number of bit positions.

**Time Complexity**

$$
O(nB+kB)=O(n+k)
$$

Counting bits takes at most \(O(nB)\), while constructing the `k` numbers takes \(O(kB)\). Since \(B\) is fixed, the overall complexity is linear.

**Space Complexity**

$$
O(B)=O(1)
$$

The `bit_cnt` array has a fixed size of 30, regardless of the input length.

## Edge Cases

### 1. Only one number is selected

```text
nums = [2, 6, 5, 8]
k = 1
```

All available bits can be combined into `15`.

Output: `225`

### 2. All numbers contain the same bit

```text
nums = [4, 4, 4]
k = 2
```

The bit representing `4` appears three times, so each selected number can contain it.

Output: `32`

### 3. Every number is selected

```text
nums = [1, 2, 3]
k = 3
```

The available bits are distributed across three constructed numbers. The maximum sum of squares is:

$$
1^2+2^2+3^2=14
$$

Output: `14`

## Lessons

- **Bit counting:** Count available bits instead of repeatedly simulating AND and OR operations.
- **Greedy construction:** Include every available bit in each number to maximize its square.
- **Bitwise operators:** `num & 1` checks the least significant bit, `num >>= 1` shifts the number right, and `val |= 1 << b` sets bit position `b`.
- **Bit conservation:** AND and OR redistribute set bits without changing their total count at each position.
- **Fixed-width optimization:** When the maximum bit length is bounded, bit manipulation can reduce the solution to linear time.
