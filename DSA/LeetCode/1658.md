# 1658. Minimum Operations to Reduce X to Zero 🟡

**Topics:** Array, Sliding Window, Prefix Sum

## Intuition

Imagine you are removing elements only from the left or right side of an array until their sum becomes exactly `x`.

Instead of focusing on the elements we remove, think about the elements we **leave behind**.

If the total sum of the array is:

```text
total
```

and we remove elements whose sum is `x`, then the remaining elements must have sum:

```text
total - x
```

So the problem becomes:

> Find the longest contiguous subarray whose sum is `total - x`.

Why the **longest** subarray?

Because every element outside that subarray must be removed.

If the array has `n` elements and the longest valid subarray has length `best`, then:

```text
operations = n - best
```

Since all numbers are positive, we can use a sliding window to find this longest subarray efficiently.

## Approach

We use a **sliding window**.

### 1. Find the target sum

```python
target = sum(nums) - x
```

This is the sum of the elements we want to keep.

If `target < 0`, then `x` is larger than the total array sum, so it is impossible.

```python
if target < 0:
    return -1
```

If `target == 0`, we need to remove every element.

```python
if target == 0:
    return len(nums)
```

### 2. Build a sliding window

We maintain:

* `lo` as the left side of the window
* `hi` as the right side of the window
* `window_sum` as the current window sum
* `best` as the longest valid window found

For every new `nums[hi]`, add it to the window.

```python
window_sum += nums[hi]
```

If the sum becomes too large, move `lo` forward and remove elements until the window becomes valid again.

```python
while window_sum > target and lo <= hi:
    window_sum -= nums[lo]
    lo += 1
```

Whenever the window sum equals `target`, we found a valid subarray.

Its length is:

```python
hi - lo + 1
```

Update `best` with the longest one.

### 3. Convert the longest window into operations

If `best` is the length of the longest subarray we can keep:

```python
n - best
```

is the number of elements we need to remove.

If no valid subarray was found, return `-1`.

## Example Walkthrough

**Input**

```text
nums = [1, 1, 4, 2, 3]
x = 5
```

### Step 1: Calculate target

```text
total = 11

target = 11 - 5
       = 6
```

We need to find the longest subarray with sum `6`.

### Step 2: Expand the window

Start with:

```text
lo = 0
window_sum = 0
```

Add `1`:

```text
[1]
sum = 1
```

Add another `1`:

```text
[1, 1]
sum = 2
```

Add `4`:

```text
[1, 1, 4]
sum = 6
```

We found a valid window.

Its length is:

```text
3
```

So:

```text
best = 3
```

Continue expanding.

Add `2`:

```text
[1, 1, 4, 2]
sum = 8
```

The sum is greater than `6`, so shrink from the left.

Remove the first `1`:

```text
[1, 4, 2]
sum = 7
```

Still too large.

Remove another `1`:

```text
[4, 2]
sum = 6
```

This is another valid window, but its length is only `2`.

Therefore:

```text
best = 3
```

Finally:

```text
operations = n - best
           = 5 - 3
           = 2
```

So the answer is:

```text
2
```

## Code

```python
class Solution:
    def minOperations(self, nums: List[int], x: int) -> int:
        target = sum(nums) - x
        if target<0:
            return -1

        if target==0:
            return len(nums)

        n = len(nums)
        lo=0
        window_sum=0
        best = -1

        for hi in range(n):
            window_sum += nums[hi]

            while window_sum > target and lo <= hi:
                window_sum -= nums[lo]
                lo += 1

            if window_sum == target:
                best = max(best, hi-lo+1)

        return n - best if best != -1 else -1
```

## Complexity

Each element enters the sliding window once and leaves it at most once.

**Time Complexity:**

$$
O(n)
$$

**Space Complexity:**

$$
O(1)
$$

## Edge Cases

### 1. `x` is larger than the total sum

```text
nums = [1, 2, 3]
x = 10
```

```text
target = 6 - 10
       = -4
```

Impossible, so return:

```text
-1
```

### 2. `x` equals the total sum

```text
nums = [1, 2, 3]
x = 6
```

```text
target = 0
```

We need to remove every element.

Answer:

```text
3
```

### 3. No valid subarray exists

If no contiguous subarray has sum `target`, `best` remains `-1`.

The final expression handles this:

```python
return n - best if best != -1 else -1
```

## Lessons

* When removing elements from both ends, try thinking about the elements that can remain in the middle.
* Convert the problem from **minimum removals** into **maximum elements kept**.
* The key transformation is:

$$
\text{kept sum} = \text{total sum} - x
$$

* With positive numbers, a sliding window can find the longest subarray with a target sum in $O(n)$.
* `best` represents the maximum number of elements we can keep.
* Finally:

$$
\text{minimum operations} = n - \text{best}
$$
