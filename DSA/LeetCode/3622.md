# 3622. Check Divisibility by Digit Sum and Product 🟢

**Topics:** Math, Digit Manipulation

## Intuition

Imagine you take a number apart digit by digit and calculate two things:

* How much all the digits add up to.
* How much all the digits multiply together.

Then combine these two results into one value.

The question simply asks:

> Does the original number divide evenly by this combined value?

For example, with `99`:

* Digit sum = `9 + 9 = 18`
* Digit product = `9 * 9 = 81`
* Combined value = `18 + 81 = 99`

Since `99 % 99 == 0`, the answer is `True`.

So we only need to extract each digit once and keep track of its sum and product.

## Approach

We repeatedly extract the last digit using:

```python
digit = n % 10
```

Then remove that digit using:

```python
n //= 10
```

While doing this, we maintain:

* `digit_sum` for the sum of digits.
* `digit_product` for the product of digits.

Finally, check:

```python
original % (digit_sum + digit_product) == 0
```

We store the original value because `n` gets modified while extracting its digits.

## Example Walkthrough

**Input**

```text
n = 99
```

Start with:

```text
digit_sum = 0
digit_product = 1
```

### Step 1: Extract `9`

```text
digit_sum = 0 + 9 = 9
digit_product = 1 * 9 = 9
```

### Step 2: Extract `9`

```text
digit_sum = 9 + 9 = 18
digit_product = 9 * 9 = 81
```

Now:

```text
digit_sum + digit_product = 18 + 81 = 99
```

Check divisibility:

```text
99 % 99 = 0
```

Therefore:

```text
True
```

## Code

```python
class Solution:
    def checkDivisibility(self, n: int) -> bool:
        num = n
        s=0
        p=1

        while num:
            d = num%10
            s += d
            p *= d
            num //= 10

        return n % (s+p) == 0
```

## Complexity

Let $d$ be the number of digits in `n`.

**Time Complexity**

$$
O(d)
$$

We process every digit exactly once.

Since `n <= 10^6`, the number of digits is very small.

**Space Complexity**

$$
O(1)
$$

We only use a few variables regardless of the size of `n`.

## Edge Cases

1. **Single digit**

```text
n = 5
```

* Sum = `5`
* Product = `5`
* Total = `10`

`5` is not divisible by `10`.

Answer:

```text
False
```

2. **Number containing zero**

```text
n = 10
```

* Sum = `1 + 0 = 1`
* Product = `1 * 0 = 0`
* Total = `1`

Since `10 % 1 == 0`, the answer is `True`.

3. **Number where sum and product equal the number**

```text
n = 99
```

* Sum = `18`
* Product = `81`
* Total = `99`

Answer:

```text
True
```

## Lessons

* Digit problems are often solved using `% 10` and `// 10`.
* Keep the original number if you need it after digit extraction.
* Initialize a digit product to `1`, since `1` is the multiplicative identity.
* When multiple values are required from the digits, calculate them together in a single traversal.
