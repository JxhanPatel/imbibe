# 3550. Smallest Index With Digit Sum Equal to Index 🟢

**Topics:** Array, Math

## Intuition

Imagine checking seats in a row. Each seat has a number written on it, and you want to find the first seat where the sum of the digits written on the number equals the seat's index.

For example:

```text
nums = [1, 10, 11]

index:   0   1   2
value:   1  10  11
```

At index `1`, the digit sum of `10` is:

```text
1 + 0 = 1
```

Since it matches the index, we return `1`.

Because we scan from left to right, the **first match is automatically the smallest index**.

## Approach

We use a simple linear scan:

1. Visit every number together with its index.
2. Calculate the digit sum of `nums[i]`.
3. If the digit sum equals `i`, return `i`.
4. If we finish the array without finding a match, return `-1`.

To calculate the digit sum, repeatedly:

* Take the last digit using `num % 10`.
* Add it to the sum.
* Remove the last digit using `num // 10`.

For example, for `123`:

```text
123 % 10 = 3
123 // 10 = 12

12 % 10 = 2
12 // 10 = 1

1 % 10 = 1
1 // 10 = 0

sum = 3 + 2 + 1 = 6
```

## Example Walkthrough

**Input:**

```text
nums = [1, 10, 11]
```

### Index 0

```text
nums[0] = 1
digit sum = 1
```

`1 != 0`, so continue.

### Index 1

```text
nums[1] = 10
digit sum = 1 + 0 = 1
```

Now:

```text
digit sum == index
1 == 1
```

So we immediately return:

```text
1
```

## Code

```python
class Solution:
    def smallestIndex(self, nums: List[int]) -> int:
        for i, num in enumerate(nums):
            x=0

            while num:
                x += num%10
                num //= 10

            if x == i:
                return i

        return -1
```

The important part is that `enumerate()` gives us both the **index** and the **value**, so we can compare them directly.

## Complexity

Let `n` be the length of the array and `d` be the maximum number of digits in a value.

**Time Complexity:**

$$
O(n \cdot d)
$$

Since `nums[i] <= 1000`, each number has at most 4 digits, so in this problem `d` is effectively constant.

Therefore, we can also consider the practical complexity:

$$
O(n)
$$

**Space Complexity:**

$$
O(1)
$$

Only a few variables are used.

## Edge Cases

### 1. Match at index 0

```text
nums = [0]
```

The digit sum of `0` is `0`.

```text
0 == 0
```

Answer:

```text
0
```

### 2. No matching index

```text
nums = [1, 2, 3]
```

```text
index 0 -> digit sum 1
index 1 -> digit sum 2
index 2 -> digit sum 3
```

No match exists.

Answer:

```text
-1
```

### 3. First match is not the only match

```text
nums = [1, 10, 11]
```

Both index `1` and index `2` satisfy the condition:

```text
1 -> digit sum(10) = 1
2 -> digit sum(11) = 2
```

We return `1` because we scan from left to right.

## Lessons

* `enumerate()` is useful when you need both an index and its value.
* Digit sums can be calculated using `% 10` and `// 10`.
* Scanning from left to right lets us return the **smallest** valid index immediately.
* When the condition is simple and each element can be checked independently, a linear scan is often all you need.
