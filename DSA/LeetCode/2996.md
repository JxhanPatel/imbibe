# 2996. Smallest Missing Integer Greater Than Sequential Prefix Sum 🟢

**Topics:** Array, Hash Table

## Intuition

Imagine you are adding numbers while walking through an array.

You can keep adding numbers only as long as they form a consecutive sequence:

```text
1, 2, 3, 4, ...
```

As soon as the next number is not exactly `1` greater than the previous number, the sequential prefix ends.

For example:

```text
[1, 2, 3, 2, 5]
```

The sequential prefix is:

```text
[1, 2, 3]
```

Its sum is:

```text
1 + 2 + 3 = 6
```

Now we need the smallest number that is at least `6` and does not appear in the array.

The solution therefore has two simple parts:

1. Find the sum of the longest sequential prefix.
2. Starting from that sum, find the first number missing from the array.

## Approach

### 1. Find the sequential prefix sum

We start with the first element:

```python
run_sum = nums[0]
```

Then we compare every element with the previous one.

The prefix continues only when:

```python
nums[i] - nums[i - 1] == 1
```

If the difference is anything else, the sequential prefix has ended:

```python
if nums[i] - nums[i - 1] != 1:
    break
```

Whenever the sequence continues, add the current number to `run_sum`.


### 2. Store all numbers in a set

After finding the prefix sum, we create:

```python
num_set = set(nums)
```

A set allows us to quickly check whether a candidate number exists in the array.


### 3. Find the first missing number

The prefix sum is the smallest possible starting point for our answer:

```python
candidate = run_sum
```

If that number already exists in the array, increment it and check again:

```python
while candidate in num_set:
    candidate += 1
```

The loop stops at the first number that is not present.

That number is the answer.

## Example Walkthrough

Consider:

```text
nums = [3, 4, 5, 1, 12, 14, 13]
```

### Step 1: Find the sequential prefix

Start with:

```text
run_sum = 3
```

Check `4`:

```text
4 - 3 = 1
```

So the sequence continues:

```text
run_sum = 3 + 4 = 7
```

Check `5`:

```text
5 - 4 = 1
```

Again, the sequence continues:

```text
run_sum = 7 + 5 = 12
```

Check `1`:

```text
1 - 5 = -4
```

The difference is not `1`, so we stop.

The longest sequential prefix is:

```text
[3, 4, 5]
```

and:

```text
run_sum = 12
```

### Step 2: Find the missing integer

Create the set:

```text
{1, 3, 4, 5, 12, 13, 14}
```

Start:

```text
candidate = 12
```

Check each candidate:

```text
12 → exists
13 → exists
14 → exists
15 → missing
```

Therefore:

```text
answer = 15
```

## Code

```python
class Solution:
    def missingInteger(self, nums: List[int]) -> int:
        run_sum = nums[0]

        for i in range(1, len(nums)):
            if nums[i] - nums[i-1] != 1:
                break

            run_sum += nums[i]

        num_set = set(nums)
        candidate=run_sum
        
        while candidate in num_set:
            candidate += 1

        return candidate
```

## Complexity

Let `n` be the length of `nums`.

### Time Complexity

Finding the sequential prefix takes:

$$
O(n)
$$

Creating the set takes:

$$
O(n)
$$

The final search takes up to $O(n)$ iterations in the worst case.

Therefore, the overall time complexity is:

$$
O(n)
$$

### Space Complexity

The set stores the elements of `nums`:

$$
O(n)
$$

## Edge Cases

### 1. Single element

```text
nums = [5]
```

The sequential prefix contains only `5`.

```text
run_sum = 5
```

Since `5` is present, the next candidate is `6`.

```text
Output = 6
```

### 2. Sequence breaks immediately

```text
nums = [1, 3, 4, 5]
```

The sequential prefix is only:

```text
[1]
```

So:

```text
run_sum = 1
```

`1` exists, while `2` does not.

```text
Output = 2
```

### 3. Prefix sum already appears multiple times

```text
nums = [1, 2, 3, 6, 7, 8]
```

The sequential prefix is:

```text
[1, 2, 3]
```

Its sum is:

```text
6
```

Since `6` exists:

```text
6 → present
7 → present
8 → present
9 → missing
```

Therefore:

```text
Output = 9
```

## Lessons

* Use adjacent-element comparisons to detect a sequential prefix.
* Keep a running sum instead of calculating the prefix sum separately.
* Convert the array into a set when repeated membership checks are required.
* Once a lower bound for the answer is known, start from it and move upward until a missing value is found.
* This solution combines two useful patterns: **prefix traversal** and **hash-set lookup**.
