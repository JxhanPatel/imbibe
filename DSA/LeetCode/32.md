# 32. Longest Valid Parentheses 🔴

Topics: String, Dynamic Programming, Stack

## Intuition

Imagine you are checking whether parentheses in a sentence are correctly paired. Every opening parenthesis `(` needs a matching closing parenthesis `)`.

For example:

- `"()"` is valid because both parentheses match.
- `"(())"` is valid because every opening parenthesis has a matching closing parenthesis.
- `"(()"` is invalid as a whole because one opening parenthesis remains unmatched.

The challenge is to find the longest continuous substring that forms a valid parentheses sequence.

Think of invalid parentheses as boundaries. Once we encounter an unmatched closing parenthesis or finish with an unmatched opening parenthesis, we cannot include that character in a valid substring crossing that boundary.

We can solve this efficiently using a stack of indices. The stack helps us track unmatched opening parentheses and the boundaries of invalid substrings.

## Approach

We will use a stack-based approach that stores indices rather than parentheses themselves.

### 1. Initialize the stack

Start with `stack = [-1]`.

The index `-1` acts as a boundary before the string begins. This makes it easier to calculate substring lengths, including when a valid substring starts at index `0`.

Also initialize `longest = 0` to track the maximum length found.

### 2. Process each character

Traverse the string from left to right.

- If the character is `(`, push its index onto the stack because it may need a matching closing parenthesis.
- If the character is `)`, pop the stack because we have encountered a closing parenthesis.

### 3. Handle unmatched closing parentheses

After popping, if the stack becomes empty, the current closing parenthesis has no matching opening parenthesis.

Push its index onto the stack. It becomes the new boundary, preventing valid substrings from crossing this position.

### 4. Calculate valid substring lengths

If the stack is not empty after processing a closing parenthesis, we have a valid match.

The current valid substring length is:

$$
\text{length} = i - \text{stack}[-1]
$$

Here, `i` is the current index and `stack[-1]` is the index of the last unmatched opening parenthesis or the most recent invalid boundary.

Update `longest` whenever this length is larger than the previous maximum.

## Example Walkthrough

Let's trace the input:

```
s = ")()())"
```

Initially:

```
stack = [-1]longest = 0
```

| Index | Character | Stack after processing | Length found | Longest |
| ----- | --------- | ---------------------- | ------------ | ------- |
| 0     | `)`       | `[0]`                  | 0            | 0       |
| 1     | `(`       | `[0, 1]`               | 0            | 0       |
| 2     | `)`       | `[0]`                  | 2            | 2       |
| 3     | `(`       | `[0, 3]`               | 2            | 2       |
| 4     | `)`       | `[0]`                  | 4            | 4       |
| 5     | `)`       | `[5]`                  | 0            | 4       |

At index `2`, the substring `"()"` has length \\(2\\).

At index `4`, the substring `"()()"` has length \\(4\\). This becomes the maximum.

At index `5`, we encounter an unmatched closing parenthesis, so index `5` becomes the new boundary.

Output:

```
4
```

## Code

```
class Solution:    def longestValidParentheses(self, s: str) -> int:        stack = [-1]        longest = 0        for i, ch in enumerate(s):            if ch == '(':                stack.append(i)            else:                stack.pop()                if not stack:                    stack.append(i)                else:                    longest = max(longest, i - stack[-1])        return longest
```

## Complexity

Time complexity

$$
O(n)
$$

We traverse the string once, and each index is pushed onto and popped from the stack at most once.

Space complexity

$$
O(n)
$$

In the worst case, the stack can hold indices for all opening parentheses.

## Edge Cases

### 1. Empty string

```
s = ""
Output: 0
```

No characters are processed, so the result remains `0`.

### 2. Only opening parentheses

```
s = "((("
Output: 0
```

There are no closing parentheses to complete a valid pair.

### 3. Only closing parentheses

```
s = ")))"
Output: 0
```

Every closing parenthesis is unmatched and becomes a boundary.

### 4. Entire string is valid

```
s = "(())"
Output: 4
```

All four characters form one valid substring.

### 5. Multiple valid substrings separated by invalid characters

```
s = "()(()"
Output: 2
```

The longest valid substring is `"()"`. The unmatched opening parentheses prevent the later portion from forming a longer valid substring.

## Lessons

- Store indices, not just characters. Indices let us calculate substring lengths directly.
- Use a sentinel index. Initializing the stack with `-1` simplifies calculations for substrings beginning at index `0`.
- Treat unmatched closing parentheses as boundaries. A valid substring cannot cross an unmatched closing parenthesis.
- Distinguish substrings from subsequences. A substring must be continuous, so characters cannot be skipped.
- Recognize stack patterns. Stacks are useful when matching opening and closing symbols, tracking unmatched elements, and finding boundaries.

The key idea is that the stack's top always identifies the boundary needed to calculate the length of the current valid parentheses substring.
