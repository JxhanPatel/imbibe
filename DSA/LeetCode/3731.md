# 3731. Find Missing Elements 🟢

**Topics:** Array, Hash Set

## Intuition

Imagine you have a bookshelf that should contain every book numbered from **1 to 10**.

When you look at the shelf, you see:

```text
1, 2, 4, 5, 7, 8, 10
```

Instead of trying to figure out which books are present, it is easier to walk through the expected sequence from **1 to 10** and note any missing numbers.

This problem follows the same idea. Since the smallest and largest numbers of the original range are guaranteed to exist, we know exactly what the complete sequence should be. We simply check each number in that range and collect the ones that are absent.

A **hash set** lets us check whether a number exists in constant time.

## Approach

We use a **hash set** to quickly determine whether a number is present.

1. Convert the array into a set.
2. Find the smallest and largest values in the array.
3. Iterate through every integer from the smallest to the largest.
4. If a number is not present in the set, add it to the answer.
5. Return the list of missing numbers.

This avoids sorting and keeps the solution simple and efficient.

## Example Walkthrough

**Input**

```text
nums = [1,4,2,5]
```

### Step 1: Build the set

```text
seen = {1,2,4,5}
```

### Step 2: Find the range

```text
lo = 1
hi = 5
```

Expected sequence:

```text
1, 2, 3, 4, 5
```

### Step 3: Check every number

| Number | Present? | Action        |
| ------ | -------- | ------------- |
| 1      | Yes      | Skip          |
| 2      | Yes      | Skip          |
| 3      | No       | Add to answer |
| 4      | Yes      | Skip          |
| 5      | Yes      | Skip          |

Final answer:

```text
[3]
```

## Code

```python
from typing import List
class Solution:
    def findMissingElements(self, nums: List[int]) -> List[int]:
        seen = set(nums)
        lo = min(nums)
        hi = max(nums)

        gaps=[]
        for n in range(lo, hi+1):
            if n not in seen:
                gaps.append(n)

        return gaps
```

## Complexity

**Time Complexity**

* Building the hash set: $O(n)$
* Scanning the range: $O(\text{max} - \text{min})$

Overall:

$$
O(n + (\text{max} - \text{min}))
$$

**Space Complexity**

$$
O(n)
$$

The hash set stores all elements from the input array.

## Edge Cases

1. **No missing numbers**

```text
nums = [6,7,8,9]
```

Output:

```text
[]
```

2. **Multiple missing numbers**

```text
nums = [5,1]
```

Output:

```text
[2,3,4]
```

3. **Exactly one missing number**

```text
nums = [2,3,5]
```

Output:

```text
[4]
```

## Lessons

* A hash set is one of the fastest ways to perform repeated membership checks.
* When the minimum and maximum values define a complete range, iterating through that range is often the simplest solution.
* There is no need to sort the array when only presence or absence matters.
* This pattern of combining a hash set with a range traversal appears frequently in array and missing-number problems.
