## 3644. Maximum K to Sort a Permutation 🟡

**Topics:** Array, Bit Manipulation, Graph Theory, Permutations

### Intuition

Imagine a group of friends standing in a line, each holding a numbered ticket corresponding to their assigned position. Some friends are in the wrong spots and need to swap places to get into numerical order. However, there is a strict rule: two friends can only swap places if their ticket numbers share a specific set of binary features represented by the number $k$.

If we want to find the largest possible $k$ that still allows everyone to eventually reach their correct spot, what must be true? Every misplaced person must possess all the required binary features of $k$. If even a single cycle of misplaced people lacks a specific bit, we cannot use that bit in $k$. Thus, the maximum possible $k$ is simply the bitwise AND of all elements that are currently not in their correct positions.

### Approach

1. Iterate through the array and identify every element whose current position does not match its value (`nums[i] != i`).
2. Maintain a running bitwise AND of all such misplaced elements.
3. If no elements are misplaced (meaning the array is already sorted), return `0` as specified by the problem.
4. Otherwise, return the accumulated bitwise AND value.

### Example Walkthrough

Consider `nums = [0, 3, 2, 1]`:

* At index `0`: `nums[0] = 0` (correct position).
* At index `1`: `nums[1] = 3` (misplaced).
* At index `2`: `nums[2] = 2` (correct position).
* At index `3`: `nums[3] = 1` (misplaced).

The misplaced elements are `3` (binary `11`) and `1` (binary `01`).
Computing their bitwise AND: `3 & 1 = 1`.
We return `1`, which matches Example 1.

### Code

```python
def maxKToSorted(nums):
    bad_bits = -1

    for i, x in enumerate(nums):
        if x != i:
            bad_bits &= x

    return bad_bits if bad_bits != -1 else 0

```

### Complexity

* **Time Complexity:** $O(n)$ because we traverse the array of length $n$ exactly once.
* **Space Complexity:** $O(1)$ since we only use a single integer variable to accumulate the bitwise AND.

### Edge Cases

1. **Already Sorted Array:** For `nums = [0, 1, 2, 3]`, all elements are in their correct positions, so the function returns `0`.
2. **Single Element Array:** For `nums = [0]`, the array is already sorted, returning `0`.
3. **Fully Inverted Array:** For `nums = [3, 2, 1, 0]`, every element is misplaced, yielding `3 & 2 & 1 & 0 = 0`.

### Lessons

* Permutations naturally decompose into disjoint cycles, and elements in cycles of length two or greater must be rearranged.
* When a bitwise condition governs allowed operations across a set of elements, the maximum constraining value is often found by taking the bitwise AND across all items that participate in the operation.
* Initializing bitwise accumulators with `-1` in Python is a clean idiom to handle bitwise operations without needing explicit conditional branches for the first element.
