# 3345. Smallest Divisible Digit Product I 🟢

**Topics:** Math, Brute Force

## Intuition

Imagine you're testing lock combinations one by one.

For each number, you multiply all of its digits together. If that product is divisible by `t`, you've found the correct combination. Otherwise, you simply try the next number.

Since the constraints are very small (`n ≤ 100`), checking numbers one at a time is both simple and efficient. There is no need for any advanced optimization.

## Approach

We use a **brute force** approach.

1. Start with `candidate = n`.
2. For each candidate:
   - Compute the product of all its digits.
   - Check whether the product is divisible by `t`.
3. If it is divisible, return the current candidate.
4. Otherwise, increment the candidate and repeat.

To calculate the digit product:

- Extract the last digit using `% 10`.
- Multiply it into the running product.
- Remove the last digit using `// 10`.

This continues until a valid number is found.

## Example Walkthrough

**Input**

```text
n = 15
t = 3
```

### Check 15

Digits:

```text
1, 5
```

Product:

```text
1 × 5 = 5
```

Since:

```text
5 % 3 ≠ 0
```

Move to the next number.

### Check 16

Digits:

```text
1, 6
```

Product:

```text
1 × 6 = 6
```

Since:

```text
6 % 3 = 0
```

We have found the smallest valid number.

**Output**

```text
16
```

## Code

```python
class Solution:
    def smallestNumber(self, n: int, t: int) -> int:

        candidate=n

        while True:
            digits_product=1
            tmp = candidate

            while tmp:
                d = tmp%10
                digits_product *= d
                tmp//=10

            if digits_product%t == 0:
                return candidate

            candidate += 1
```

## Complexity

Let:

- `m` be the number of candidates checked.
- `k` be the number of digits in each candidate.

**Time Complexity**

$$
O(m \times k)
$$

Each candidate requires scanning all of its digits once.

Given the small constraints, this is easily fast enough.

**Space Complexity**

$$
O(1)
$$

Only a few variables are used.

## Edge Cases

1. **Number contains a zero**

```text
n = 10
t = 5
```

Digit product:

```text
1 × 0 = 0
```

Since `0` is divisible by every positive integer, the answer is `10`.

---

2. **First number is already valid**

```text
n = 16
t = 3
```

Digit product:

```text
1 × 6 = 6
```

Return `16`.

---

3. **Single-digit number**

```text
n = 7
t = 7
```

Digit product is `7`, so the answer is `7`.

## Lessons

- Small constraints often make a brute force solution the best choice.
- Extracting digits using `% 10` and `// 10` is a common pattern in digit-based problems.
- A number containing a `0` digit always has a digit product of `0`, which is divisible by any positive integer.
- When searching for the smallest valid value, checking candidates in increasing order guarantees the first valid one is the answer.
