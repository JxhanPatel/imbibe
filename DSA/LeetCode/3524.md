# 3524. Find X Value of Array I 🟡

**Topics:** Array, Dynamic Programming, Prefix Product, Modular Arithmetic

## Intuition

Imagine we are building subarrays one element at a time.

For every position, we want to know:

> How many subarrays ending here have a product with remainder `0`, `1`, ..., `k - 1`?

Instead of storing every subarray, we only store the **remainder of its product**.

For example, if `k = 3`, we only care about:

```text
0, 1, 2
```

When we add a new number `x` to an existing subarray, its product remainder changes from `r` to:

```python
r * x % k
```

This lets us update all possible subarrays in only `k` states.


## Approach

We maintain two arrays:

```python
cur
total
```

### `cur`

`cur[r]` stores the number of subarrays ending at the previous position whose product has remainder `r`.

### `total`

`total[r]` stores the number of **all subarrays seen so far** whose product has remainder `r`.

For every `x` in `nums`:

### 1. Create a new state

```python
nxt = [0] * k
```

This represents subarrays ending at the current element.

The single-element subarray `[x]` is always possible:

```python
nxt[x % k] = 1
```

### 2. Extend previous subarrays

For every remainder `r` in `cur`:

```python
nxt[r * x % k] += ways
```

If there are `ways` subarrays with product remainder `r`, appending `x` changes their remainder to:

```text
(r × x) % k
```

So all of those subarrays move to the new remainder.

### 3. Move to the next position

```python
cur = nxt
```

Now `cur` represents all subarrays ending at the current element.

### 4. Add them to the answer

```python
total = [t + c for t, c in zip(total, cur)]
```

Every subarray ending at the current position is a valid operation, so we add its count to the global result.


## Example Walkthrough

Consider:

```text
nums = [1, 2, 3]
k = 3
```

Initially:

```text
cur   = [0, 0, 0]
total = [0, 0, 0]
```

### Process `1`

The single-element subarray is:

```text
[1]
```

Its product remainder is:

```text
1 % 3 = 1
```

So:

```text
cur   = [0, 1, 0]
total = [0, 1, 0]
```


### Process `2`

Start with the new subarray:

```text
[2] → 2
```

Then extend `[1]`:

```text
[1, 2]
1 × 2 % 3 = 2
```

Therefore:

```text
cur = [0, 0, 2]
```

Both `[2]` and `[1,2]` have remainder `2`.

Update:

```text
total = [0, 1, 2]
```


### Process `3`

Start with:

```text
[3]
```

Its remainder is:

```text
3 % 3 = 0
```

Now extend the two previous subarrays:

```text
[2,3]     → 2 × 3 % 3 = 0
[1,2,3]   → 2 × 3 % 3 = 0
```

So:

```text
cur = [3, 0, 0]
```

Update:

```text
total = [3, 1, 2]
```

The final result is:

```text
[3, 1, 2]
```


## Code

```python
class Solution:
    def resultArray(self, nums: List[int], k: int) -> List[int]:
        total = [0]*k
        cur = [0]*k

        for x in nums:
            nxt = [0]*k
            nxt[x%k] = 1

            for r, ways in enumerate(cur):
                if not ways:
                    continue
                nxt[r*x % k] += ways

            cur = nxt
            total = [t+c for t, c in zip(total, cur)]

        return total
```


## Complexity

For every element, we iterate through the `k` possible remainders.

Time complexity:

$$
O(nk)
$$

Since `k <= 5`, this is effectively:

$$
O(n)
$$

Space complexity:

$$
O(k)
$$

We only maintain three arrays of size `k`.


## Edge Cases

### 1. Single element

```text
nums = [5]
k = 3
```

The only subarray is `[5]`.

```text
5 % 3 = 2
```

Result:

```text
[0, 0, 1]
```

### 2. `k = 1`

There is only one possible remainder:

```text
0
```

Every non-empty subarray contributes to `total[0]`.

### 3. Element divisible by `k`

If:

```text
x % k == 0
```

then any subarray extended with `x` gets remainder `0`:

```text
r * x % k = 0
```

So many previous subarrays can move into `cur[0]`.


## Lessons

* When a problem asks about subarray products **modulo a small `k`**, track only the possible remainders.
* `cur` represents subarrays ending at the current position.
* `total` represents all subarrays counted so far.
* Extending a subarray changes its state using:

$$
(r \times x) \bmod k
$$

* The important optimization is replacing potentially $O(n^2)$ subarrays with only `k` remainder states.
* Skipping `ways == 0` avoids unnecessary updates for remainders that currently have no subarrays.
