## 3411. Maximum Subarray With Equal Products 🟢

**Topics:** Array, Math, Number Theory, Sliding Window / Brute Force

## Intuition

Think of prime factors like building blocks that make up every number in a subarray.

When you multiply a group of numbers together (`prod`), you collect every prime factor with its total count across all elements. When you take their least common multiple (`lcm`), you only take the **highest** count of each prime factor seen in any single number. And when you take their greatest common divisor (`gcd`), you only keep the prime factors present in **every** number (with their minimum count).

For a subarray to be **product equivalent**, `prod(arr) == lcm(arr) * gcd(arr)`. Notice that for two numbers, `a * b == lcm(a, b) * gcd(a, b)` is always true. With three or more numbers, that equality holds when the numbers do not share extra overlapping prime factors that double-count or clash across `lcm` and `gcd`. Because the constraints are small (`nums.length <= 100` and `nums[i] <= 10`), we can check candidate subarrays cleanly and reliably.

## Approach

1. Fix a starting index `i` from `0` to `n - 1`.
2. Expand the ending index `j` from `i` to `n - 1`, maintaining the running product `p`, running greatest common divisor `g`, and running least common multiple `l` of the subarray `nums[i..j]`.
3. Update `g = math.gcd(g, nums[j])`, `l = math.lcm(l, nums[j])`, and `p *= nums[j]`.
4. Check if `p == l * g`. If so, update `best = max(best, j - i + 1)`.
5. Return `best` after checking all subarrays.

## Example Walkthrough

Consider `nums = [2, 3, 4, 5, 6]`:

* Start at `i = 0` (`nums[0] = 2`):
* `j = 0` (`[2]`): `p = 2`, `g = 2`, `l = 2`. `l * g = 4 != 2`.
* `j = 1` (`[2, 3]`): `p = 6`, `g = 1`, `l = 6`. `l * g = 6 == 6`, length is `2`, `best = 2`.
* `j = 2` (`[2, 3, 4]`): `p = 24`, `g = 1`, `l = 12`. `l * g = 12 != 24`.


* Start at `i = 1` (`nums[1] = 3`):
* `j = 1` (`[3]`): `p = 3`, `g = 3`, `l = 3`. `l * g = 9 != 3`.
* `j = 2` (`[3, 4]`): `p = 12`, `g = 1`, `l = 12`. `l * g = 12 == 12`, length is `2`, `best = 2`.
* `j = 3` (`[3, 4, 5]`): `p = 60`, `g = 1`, `l = 60`. `l * g = 60 == 60`, length is `3`, `best = 3`.
* `j = 4` (`[3, 4, 5, 6]`): `p = 360`, `g = 1`, `l = 60`. `l * g = 60 != 360`.



Continuing through `i = 2, 3, 4` finds no subarrays longer than `3`, so the answer is `3`.

## Code

```python
import math


class Solution:
    def maxLength(self, nums: list[int]) -> int:
        n = len(nums)
        best = 0

        for i in range(n):
            g=0
            l=1
            p=1

            for j in range(i, n):
                x = nums[j]
                g = math.gcd(g, x)
                l = math.lcm(l, x)
                p *= x

                if p == l * g:
                    best = max(best, j - i + 1)

        return best

```

## Complexity

* **Time Complexity:** $O(n^2 \log M)$, where $n$ is the length of `nums` and $M$ is the maximum element value (`M <= 10`). There are $O(n^2)$ subarrays `(i, j)`, and each `gcd` or `lcm` step takes $O(\log M)$ time.
* **Space Complexity:** $O(1)$ extra space, since only a few scalar variables are updated in place.

## Edge Cases

1. **All elements equal to `1**`, such as `nums = [1, 1, 1]`:
* For the whole array: `p = 1`, `g = 1`, `l = 1`, and `1 == 1 * 1` holds. Expected output: `3`.


2. **Minimum length array with distinct primes**, such as `nums = [2, 3]`:
* For `[2, 3]`: `p = 6`, `g = 1`, `l = 6`, so `6 == 6 * 1` holds. Expected output: `2`.


3. **Repeated prime factors breaking equality**, such as `nums = [2, 2, 2]`:
* For `[2, 2]`: `p = 4`, `g = 2`, `l = 2`, while `l * g = 4` holds, so length `2` is valid. For `[2, 2, 2]`: `p = 8`, `g = 2`, `l = 2`, `l * g = 4 != 8`. Expected output: `2`.



## Lessons

* When input sizes are small (`n <= 100`), a clean double loop with incremental state updates is easy to reason about and avoids overcomplicating the logic.
* Updating `gcd` and `lcm` incrementally as you extend the right boundary avoids recomputing them from scratch for every subarray.
* Always check how `gcd` initializes (`0` acts as the identity element for `math.gcd(0, x) == x`) and how `lcm` initializes (`1` acts as the identity element for `math.lcm(1, x) == x`).
