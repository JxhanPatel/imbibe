# 20. Valid Parentheses 🟢

**Topics:** Stack, String

## Intuition

Imagine you are checking a set of brackets written on a piece of paper.

Whenever you see an opening bracket like `(`, `[`, or `{`, you need to remember it because a matching closing bracket must come later.

The important part is that the **most recently opened bracket must be closed first**.

For example:

```text
([{}])
```

The `{` was opened most recently, so it must be closed before `[` and `(`.

This is exactly how a **stack** works:

* Add opening brackets to the stack.
* When a closing bracket appears, check the top of the stack.
* If it matches, remove it.
* If it does not match, the string is invalid.

This follows the **Last In, First Out (LIFO)** rule of a stack.

## Approach

We use a **stack** to keep track of opening brackets.

1. Create an empty stack.
2. Store the matching opening bracket for each closing bracket.
3. Traverse the string from left to right.
4. If the character is an opening bracket, push it onto the stack.
5. If it is a closing bracket:

   * The stack must not be empty.
   * The top of the stack must be its matching opening bracket.
   * Otherwise, return `False`.
   * If it matches, remove the opening bracket.
6. After processing the whole string, the stack must be empty.

If the stack is empty at the end, every opening bracket was correctly closed.

## Example Walkthrough

**Input:**

```text
s = "([])"
```

### Step 1

Read `(`:

```text
stack = ["("]
```

### Step 2

Read `[`:

```text
stack = ["(", "["]
```

### Step 3

Read `]`.

The top of the stack is `[`, which matches `]`.

```text
stack = ["("]
```

### Step 4

Read `)`.

The top of the stack is `(`, which matches `)`.

```text
stack = []
```

The stack is empty, so the string is valid.

**Output:**

```text
True
```

## Code

```python
class Solution:
    def isValid(self, s: str) -> bool:
        match = {")": "(", "]": "[", "}": "{"}
        stk=[]

        for c in s:
            if c in match.values():
                stk.append(c)
                continue
                
            if not stk or stk.pop() != match[c]:
                return False

        return len(stk) == 0
```

## Complexity

**Time Complexity**

$$
O(n)
$$

We visit each character once.

**Space Complexity**

$$
O(n)
$$

In the worst case, all characters can be opening brackets and stored in the stack.

## Edge Cases

### 1. Single pair

```text
s = "()"
```

The brackets match.

```text
True
```

### 2. Wrong order

```text
s = "([)]"
```

When `)` is encountered, the top of the stack is `[`, not `(`.

```text
False
```

### 3. Only opening brackets

```text
s = "((("
```

The stack is not empty after processing the string.

```text
False
```

### 4. Closing bracket without an opening bracket

```text
s = "]"
```

The stack is empty when `]` is encountered.

```text
False
```

## Lessons

* When a problem asks you to match things in **reverse order**, think about a **stack**.
* Opening brackets go into the stack.
* Closing brackets must match the **top** of the stack.
* `stack[-1]` lets us check the most recently added bracket without removing it.
* `stack.pop()` removes the bracket after a successful match.
* Checking `not stack` at the end ensures there are no unmatched opening brackets.
* This is a classic example of the **LIFO** pattern.
