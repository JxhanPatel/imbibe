# 1464. Maximum Product of Two Elements in an Array 🟢

**Topics:** Array, Greedy

## Intuition

Imagine you're shopping for two premium products that come with a mandatory $1 discount before calculating their combined value.

Since every chosen number is reduced by exactly `1`, the best strategy is still to pick the two largest numbers. Any smaller number would only produce a smaller final product.

So instead of checking every possible pair, we simply keep track of the two largest elements while traversing the array once.

## Approach

We use a single pass through the array.

1. Maintain two variables:

   * `largest` stores the largest number seen so far.
   * `second_largest` stores the second largest number.

2. For every number:

   * If it is greater than or equal to `largest`, update both variables.
   * Otherwise, if it is greater than `second_largest`, update only `second_largest`.

3. After the traversal, compute:

```python
(largest - 1) * (second_largest - 1)
```

This avoids sorting and finds the answer in linear time.

## Example Walkthrough

**Input**

```text
nums = [3,4,5,2]
```

### Step 1: Initialize

```text
largest = 0
second_largest = 0
```

### Step 2: Traverse

| Current Number | largest | second_largest |
| -------------- | ------- | -------------- |
| 3              | 3       | 0              |
| 4              | 4       | 3              |
| 5              | 5       | 4              |
| 2              | 5       | 4              |

### Step 3: Compute Answer

```text
(5 - 1) × (4 - 1)
= 4 × 3
= 12
```

**Output**

```text
12
```

## Code

```python
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
    
        top1=top2=0

        for n in nums:
            if n >= top1:
                top1, top2 = n, top1

            elif n > top2:
                top2 = n

        return (top1-1) * (top2-1)
```

## Complexity

**Time Complexity**

$$
O(n)
$$

We scan the array only once.

**Space Complexity**

$$
O(1)
$$

Only two extra variables are used.

## Edge Cases

1. **Only two elements**

```text
nums = [3,7]
```

The only possible pair is chosen.

Output:

```text
12
```

2. **Duplicate largest values**

```text
nums = [1,5,4,5]
```

Both `5`s should be selected.

Output:

```text
16
```

3. **Minimum allowed values**

```text
nums = [1,1]
```

Product:

```text
(1 - 1) × (1 - 1) = 0
```

Output:

```text
0
```

## Lessons

* When only the largest few elements matter, you do not always need to sort the entire array.
* Keeping track of the top two values during a single traversal is a common optimization.
* If every selected value undergoes the same transformation, first identify the optimal elements, then apply the transformation.
* Maintaining the largest and second largest values is a useful pattern that appears frequently in array problems.
