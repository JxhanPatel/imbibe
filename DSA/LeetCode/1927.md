# 1927. Sum Game 🟡

**Topics:** Math, Game Theory, String

## Intuition

Imagine the number is split into two sides of a balance scale.

* The left half has a current sum, `leftSum`.
* The right half has a current sum, `rightSum`.
* The `?` characters are empty spaces where players can choose digits from `0` to `9`.

Bob wants both sides to have exactly the same sum. Alice wants them to be different.

Instead of simulating every possible move, we only need to understand two things:

1. The current difference between the known digits.
2. The difference in the number of `?` characters on both sides.

If the total number of `?` characters is odd, Alice gets one extra move. This gives Alice an advantage, so she can force the sums to be different.

If the total is even, Bob can potentially balance the game. The extra `?` positions on one side can compensate for the current sum difference.

Each extra pair of unmatched question marks can contribute a difference of `9`. Therefore, Bob can win only if the current difference matches the exact target difference created by the unequal number of `?` characters.

## Approach

First, split `num` into two equal halves:

```python
ls = num[:n//2]
rs = num[n//2:]
```

Then scan both halves and calculate:

* `leftSum`: sum of known digits in the left half.
* `rightSum`: sum of known digits in the right half.
* `leftQ`: number of `?` characters in the left half.
* `rightQ`: number of `?` characters in the right half.

### Step 1: Check whether the total number of `?` is odd

```python
if (leftQ + rightQ) % 2 == 1:
    return True
```

If the total number of moves is odd, Alice gets one more move than Bob.

Therefore, Alice can force a win.

### Step 2: Calculate the current sum difference

```python
diff = leftSum - rightSum
```

This tells us how far apart the known sums currently are.

* Positive `diff` means the left side is larger.
* Negative `diff` means the right side is larger.

### Step 3: Calculate the target difference

```python
tar = (rightQ - leftQ) / 2 * 9
```

The difference in the number of `?` characters determines which side has more opportunities to change its sum.

The value:

$$
\frac{rightQ-leftQ}{2} \times 9
$$

represents the exact difference that Bob needs to compensate for in order to force equal final sums.

If:

$$
diff = tar
$$

Bob can force the sums to become equal.

Otherwise, Alice wins.

So:

```python
return diff != tar
```

returns `True` when Alice can win.

## Example Walkthrough

Consider:

```text
num = "?3295???"
```

The string length is `8`, so each half has length `4`.

```text
Left half:  ?329
Right half: 5???
```

### Step 1: Process the left half

```text
?329
```

Known digits:

```text
3 + 2 + 9 = 14
```

Question marks:

```text
leftQ = 1
```

Therefore:

```text
leftSum = 14
leftQ = 1
```

### Step 2: Process the right half

```text
5???
```

Known digits:

```text
rightSum = 5
```

Question marks:

```text
rightQ = 3
```

### Step 3: Check total question marks

```text
leftQ + rightQ = 1 + 3 = 4
```

The total is even, so we continue.

### Step 4: Calculate the current difference

```text
diff = leftSum - rightSum
     = 14 - 5
     = 9
```

### Step 5: Calculate the target

```text
tar = (rightQ - leftQ) / 2 * 9
    = (3 - 1) / 2 * 9
    = 1 * 9
    = 9
```

Now:

```text
diff = 9
tar  = 9
```

Since:

```text
diff == tar
```

Bob can force both halves to have equal sums.

Therefore:

```text
Output: False
```

## Code

```python
class Solution:
    def sumGame(self, num: str) -> bool:
        n = len(num)
        ls, rs = num[:n//2], num[n//2:]

        leftSum = rightSum = 0
        leftQ = rightQ = 0

        for i in ls:
            if i == '?':
                leftQ += 1

            else:
                leftSum += int(i)

        for i in rs:
            if i == '?':
                rightQ += 1

            else:
                rightSum += int(i)

        if (leftQ + rightQ) % 2 == 1:
            return True

        diff = leftSum - rightSum
        tar = (rightQ - leftQ) / 2*9

        return diff != tar
```

## Complexity

### Time Complexity

We traverse every character in the string once.

$$
O(n)
$$

### Space Complexity

Apart from the two substring slices, only a constant number of variables is used.

The auxiliary working space is:

$$
O(1)
$$

Note that in Python, `num[:n // 2]` and `num[n // 2:]` create new strings, so including those slices, the implementation uses:

$$
O(n)
$$

space.

## Edge Cases

### 1. No question marks and sums are already equal

```text
num = "5023"
```

```text
Left sum  = 5 + 0 = 5
Right sum = 2 + 3 = 5
```

No moves are available, so Bob wins.

```text
False
```

### 2. No question marks and sums are different

```text
num = "1234"
```

```text
Left sum  = 1 + 2 = 3
Right sum = 3 + 4 = 7
```

Bob cannot change anything.

Alice wins.

```text
True
```

### 3. Odd number of question marks

```text
num = "1?23"
```

There is only one `?`.

Alice gets the extra move advantage and can force the sums to be different.

```text
True
```

### 4. Equal number of question marks on both sides

If:

```text
leftQ = rightQ
```

then:

```text
tar = 0
```

For Bob to win, the known sums must already be equal.

If:

```text
leftSum != rightSum
```

Alice wins.

## Lessons

* Many game theory problems can be solved without simulating every move.
* Focus on the final condition each player wants to achieve.
* Track the difference between two competing quantities instead of their absolute values.
* An odd number of available moves often gives the first player an important extra-move advantage.
* When choices are bounded between `0` and `9`, the maximum effect of a move can often be converted into a simple mathematical condition.
* A complicated game can sometimes reduce to checking whether two calculated values are exactly equal.
