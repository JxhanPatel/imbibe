# 3903. Smallest Stable Index I 🟢

**Topics:** Array, Prefix Maximum, Suffix Minimum

## Intuition

Imagine a road of houses.

At index `i`:

* You look **from the beginning up to `i`** and find the tallest house.
* You look **from `i` to the end** and find the shortest house.
* The difference between these two values is the instability score.

We want the **first index** where:

$$
\text{maximum on the left} - \text{minimum on the right} \leq k
$$

The important part is that we need to repeatedly find:

* maximum from `0` to `i`
* minimum from `i` to `n - 1`

Since `n <= 100`, we could calculate these directly for every index. But we can do better by precomputing the suffix minimum and maintaining the prefix maximum.

## Approach

We use two pieces of information:

### 1. Suffix minimum

Create an array `suffix_min` where:

```text
suffix_min[i] = minimum value from nums[i] to nums[n - 1]
```

For example:

```text
nums = [5, 0, 1, 4]
```

The suffix minimum array is:

```text
[0, 0, 1, 4]
```

### 2. Prefix maximum

While traversing the array from left to right, maintain:

```python
prefix_max
```

At each index:

```python
prefix_max = max(prefix_max, nums[i])
```

Then the instability score is simply:

```python
score = prefix_max - suffix_min[i]
```

If:

```python
score <= k
```

we immediately return `i`.

Because we scan from left to right, the first valid index is automatically the **smallest stable index**.

## Example Walkthrough

**Input**

```text
nums = [5, 0, 1, 4]
k = 3
```

### Step 1: Build suffix minimum

Starting from the right:

```text
nums:        [5, 0, 1, 4]
suffix_min: [0, 0, 1, 4]
```

### Step 2: Scan from left to right

| Index | Prefix Max | Suffix Min | Score |
| ----: | ---------: | ---------: | ----: |
|     0 |          5 |          0 |     5 |
|     1 |          5 |          0 |     5 |
|     2 |          5 |          1 |     4 |
|     3 |          5 |          4 |     1 |

We need:

$$
score \leq k
$$

Since `k = 3`, index `3` is the first valid index.

**Output**

```text
3
```

## Code

```python
from typing import List

class Solution:
    def firstStableIndex(self, nums: list[int], k: int) -> int:

        n = len(nums)

        suf_min = [0]*n
        suf_min[n-1] = nums[n-1]

        for i in range(n-2,-1,-1):
            suf_min[i] = nums[i] if nums[i] < suf_min[i+1] else suf_min[i+1]

        running_max = nums[0]
        
        for i, val in enumerate(nums):
            if val > running_max:
                running_max = val

            if running_max - suf_min[i] <= k:
                return i

        return -1
```

## Complexity

Building the suffix minimum takes:

$$
O(n)
$$

Scanning the array takes:

$$
O(n)
$$

Therefore, the overall time complexity is:

$$
O(n)
$$

The `suffix_min` array uses:

$$
O(n)
$$

extra space.

## Edge Cases

### 1. Single element

```text
nums = [0]
k = 0
```

At index `0`:

```text
max = 0
min = 0
score = 0
```

Since `0 <= 0`, return:

```text
0
```

### 2. No stable index

```text
nums = [3, 2, 1]
k = 1
```

Every index has:

```text
score = 2
```

Since:

```text
2 > 1
```

no index is stable.

Return:

```text
-1
```

### 3. Stable index is at the beginning

```text
nums = [1, 2, 3]
k = 0
```

At index `0`:

```text
max = 1
min = 1
score = 0
```

So the answer is immediately:

```text
0
```

## Lessons

* **Prefix maximum** is useful whenever a problem asks for the maximum from the beginning up to each index.
* **Suffix minimum** is useful whenever we need the minimum from an index to the end.
* Precomputing these values turns repeated range calculations into constant-time lookups.
* Since we need the **smallest** valid index, scan from left to right and return immediately when the condition is satisfied.
* A useful pattern to remember is:

```text
prefix information + suffix information
```

This pattern appears frequently in array problems where the condition depends on both the **left side** and the **right side** of an index.
