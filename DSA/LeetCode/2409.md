# 2409. Count Days Spent Together 🟢
**Topics**: Math, String

## Intuition

Imagine two people booking overlapping hotel stays in Rome. To find how many nights they share, you do not need to check every single date individually. Instead, you look for the latest check-in date between the two of them and the earliest check-out date. The period between these two dates defines their shared window. If the latest check-in is after the earliest check-out, their trips miss each other entirely. Otherwise, the overlap span gives the exact number of days spent together.

## Approach

1. Define a helper function to convert any "MM-DD" date string into an absolute day number of the year, starting from January 1st as day 1 up to December 31st as day 365.
2. Store the number of days in each month of a non-leap year in a list.
3. Compute the absolute day numbers for all four input dates: `arriveAlice`, `leaveAlice`, `arriveBob`, and `leaveBob`.
4. Find the start of the overlap by taking the maximum arrival day between Alice and Bob.
5. Find the end of the overlap by taking the minimum leaving day between Alice and Bob.
6. If the start day is less than or equal to the end day, the number of overlapping days is `end - start + 1`. Otherwise, return `0`.

## Example Walkthrough

Let us trace Example 1 where `arriveAlice = "08-15"`, `leaveAlice = "08-18"`, `arriveBob = "08-16"`, and `leaveBob = "08-19"`.

1. Convert dates to day of the year:
* Sum of days from January to July equals $212$ days.
* `arriveAlice` ("08-15") becomes $212 + 15 = 227$.
* `leaveAlice` ("08-18") becomes $212 + 18 = 230$.
* `arriveBob` ("08-16") becomes $212 + 16 = 228$.
* `leaveBob` ("08-19") becomes $212 + 19 = 231$.


2. Find overlap bounds:
* `start = max(227, 228) = 228`
* `end = min(230, 231) = 230`


3. Calculate days:
* Since $228 \le 230$, the count is $230 - 228 + 1 = 3$ days corresponding to August 16th, 17th, and 18th.



## Code

```python
class Solution:
    def countDaysTogether(self, arriveAlice: str, leaveAlice: str, arriveBob: str, leaveBob: str) -> int:

        days = [31,28,31,30,31,30,31,31,30,31,30,31]
        
        def to_days(d):
            m, day = map(int, d.split('-'))
            return sum(days[:m-1]) + day
        
        a1, l1 = to_days(arriveAlice), to_days(leaveAlice)
        a2, l2 = to_days(arriveBob), to_days(leaveBob)
        
        start = max(a1, a2)
        end = min(l1, l2)
        
        return max(0, end-start + 1)
```

## Complexity

* **Time Complexity**: $O(1)$ because the number of months is fixed at 12, making date conversion and interval comparison execute in constant time.
* **Space Complexity**: $O(1)$ since the month days array uses a fixed amount of memory.

## Edge Cases

* **No Overlap**: Alice visits in October and Bob visits in November. The overlap start exceeds the overlap end, returning $0$.
* **Exact Same Dates**: Both arrive and leave on the exact same days. The start and end are equal, returning $1$ day.
* **Nested Intervals**: Bob's trip is entirely contained within Alice's trip. The overlap start is Bob's arrival and the overlap end is Bob's leaving.

## Lessons

* Date ranges can be mapped to linear integer coordinates like day numbers of the year to simplify range intersection problems.
* Finding the intersection of two intervals `[a, b]` and `[c, d]` is universally solved by taking `[max(a, c), min(b, d)]`. If the start exceeds the end, the intersection is empty.
