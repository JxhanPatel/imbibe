## 3970. Shortest Path With At Most K Consecutive Identical Characters 🟡

**Topics:** Graph, Shortest Path, Dijkstra's Algorithm, Dynamic Programming

### Intuition

Imagine navigating a series of checkpoints on a map where each stop stamps a specific letter onto your passport. You want to reach the final destination with the minimum total travel cost, but there is a strict rule: you cannot collect more than $k$ identical letters in a row without breaking the sequence using a different letter.

Because each node has a fixed letter assigned to it, the history of your path matters only in terms of how many consecutive identical letters you currently have at your latest stop. Instead of searching blindly, we can adapt Dijkstra's algorithm by expanding our state space. Each state is defined by the tuple `(node, streak)`, where `streak` counts how many times the current node's letter has appeared consecutively right up to this point. When moving to a neighboring node, if the neighbor shares the same letter, we increment our streak; if it has a different letter, we reset the streak to one.

### Approach

1. **State Definition:** Represent each state in our priority queue as `(dist, u, streak)`, where `dist` is the total weight accumulated to reach node `u`, and `streak` is the number of consecutive identical characters ending at node `u`.
2. **Adjacency List:** Build a standard directed graph adjacency list where each entry stores neighbors and edge weights.
3. **Priority Queue (Dijkstra):** Initialize a min-heap with `(0, 0, 1)`, since we start at node $0$ with an initial streak of $1$ (using its own label).
4. **Visited/Distance Table:** Maintain a 2D distance table `memo[u][streak]` initialized to infinity to track the minimum weight to reach every node with a specific streak.
5. **Transitions:** For each popped state `(d, u, streak)`, iterate over all outgoing edges `(v, w)`. Compare `labels[u]` and `labels[v]`:
* If `labels[u] == labels[v]`, the new streak is `ns = streak + 1`. This is valid only if `ns <= k`.
* If `labels[u] != labels[v]`, the new streak resets to `ns = 1`.
* If the new accumulated weight is smaller than the recorded `memo[v][ns]`, update the table and push the new state to the priority queue.


6. **Result:** After the priority queue empties, return the minimum distance to reach node `n - 1` across any valid streak, or `-1` if no valid path exists.

### Example Walkthrough

Consider an example with `n = 3`, edges between nodes, `labels = "aab"`, and `k = 1`.

* Node `0` has label `'a'`, node `1` has label `'a'`, and node `2` has label `'b'`.
* Starting at node `0` (`'a'`), streak = $1$, cost = $0$.
* Edge `0 -> 2` with weight `3`: node `2` has label `'b'`. Since `'a' != 'b'`, the streak resets to `1`. Total cost = $3$. This reaches node `2` with valid streak $1 \le 1$.
* Edge `0 -> 1` with weight `1`: node `1` has label `'a'`. Since `'a' == 'a'`, the new streak is $1 + 1 = 2$. However, $k = 1$, so $2 > 1$, which violates the constraint and is pruned.
* The optimal path is `0 -> 2` with total weight `3`.

### Code & Comments

```python
class Solution:
    def shortestPath(self, n: int, edges: List[List[int]], labels: str, k: int) -> int:
        graph = [[] for _ in range(n)]
        for u, v, w in edges:
            graph[u].append((v, w))
        
        inf = float('inf')

        memo = [[inf] * (k+1) for _ in range(n)]
        q = [(0,0,1)]
        memo[0][1] = 0
        
        while q:
            d, u, streak = heapq.heappop(q)
            if d > memo[u][streak]:
                continue

            if u == n-1:
                return d

            for v, w in graph[u]:
                ns = streak + 1 if labels[u] == labels[v] else 1
                if ns > k:
                    continue

                if d + w < memo[v][ns]:
                    memo[v][ns] = d+w
                    heapq.heappush(q, (memo[v][ns], v, ns))
        return -1

```

### Complexity

* **Time Complexity:** $O((V + E) k \log(V k))$, where $V$ is the number of nodes (`n`), $E$ is the number of edges, and $k$ is the maximum allowed consecutive identical characters. Each node has at most $k$ states, leading to $V \times k$ total states in the priority queue.
* **Space Complexity:** $O(V k)$ to store the 2D distance table and priority queue states across all nodes and streak values.

### Edge Cases

1. **$k = 1$ with consecutive matching labels:** When two adjacent nodes share the same label and $k = 1$, direct transitions between them are blocked, requiring alternative paths or returning `-1`.
2. **Unreachable Destination:** If no path exists from node $0$ to node $n - 1$, the priority queue will empty without reaching the target, and the function correctly returns `-1`.
3. **Single Node Graph:** If $n = 1$, the start and end nodes are the same, yielding a total cost of $0$ with streak $1$ immediately.

### Lessons

* State augmentation allows standard shortest path algorithms like Dijkstra to handle complex path constraints by incorporating history, such as consecutive character streaks, directly into the node state.
* Fixed node labels simplify state spaces because transitions depend only on the local character match between the current and neighboring nodes rather than arbitrary global history.
