# 940. Distinct Subsequences II 🔴

**Topics:** String, Dynamic Programming

## Intuition

Imagine we are building subsequences one character at a time.

Suppose we currently have `total` distinct subsequences, including the empty subsequence.

When we see a new character, every existing subsequence can either:

* Stay unchanged
* Have the new character appended to it

So the number of subsequences initially appears to **double**:

```text
total × 2
```

The problem is that repeated characters can create subsequences that we have already counted.

For example:

```text
s = "aba"
```

When we process the second `a`, simply doubling the count would count some subsequences twice.

To fix this, we remember information about the **previous occurrence of every character** using `last_seen`.

The key formula is:

```text
new total = 2 × total - duplicates
```

And `last_seen[idx]` tells us exactly how many subsequences need to be removed when the same character appears again.


## Approach

We maintain two things:

```python
total = 1
last_seen = [0] * 26
```

### `total`

`total` stores the number of distinct subsequences so far, **including the empty subsequence**.

We start with:

```text
total = 1
```

because before processing any characters, the only subsequence is:

```text
""
```


### `last_seen`

```python
last_seen = [0] * 26
```

There are 26 lowercase English letters.

For each character, `last_seen[idx]` stores the value of `total` from **before the previous occurrence** of that character.

This allows us to know how many subsequences would become duplicates when the character appears again.


## Processing Each Character

For every character:

```python
idx = ord(ch) - 97
```

This converts the character into an index from `0` to `25`.

For example:

```text
'a' → 0
'b' → 1
'c' → 2
...
'z' → 25
```

Then we calculate:

```python
doubled = total * 2 - last_seen[idx]
```

There are two parts here.

### Step 1: Double the subsequences

Every existing subsequence can produce a new subsequence by appending the current character.

So:

```python
total * 2
```

counts both the old subsequences and the new ones.


### Step 2: Remove duplicates

If this character appeared before, some of the newly created subsequences already existed.

Those duplicates are represented by:

```python
last_seen[idx]
```

So we subtract them:

```python
doubled = total * 2 - last_seen[idx]
```


### Step 3: Save the current state

Before changing `total`, we store its current value:

```python
last_seen[idx] = total
```

This is important because this is the value we need when the same character appears again.

Then update:

```python
total = doubled % MOD
```

The modulo keeps the number manageable.


## Example Walkthrough

Let's trace:

```text
s = "aba"
```

Initially:

```text
total = 1
last_seen = [0, 0, ..., 0]
```

The empty subsequence is the only subsequence.

### Process `a`

```python
idx = 0
```

Since `a` has not appeared before:

```python
doubled = 1 * 2 - 0
        = 2
```

Now:

```python
last_seen[0] = 1
total = 2
```

The subsequences are:

```text
""
"a"
```


### Process `b`

```python
idx = 1
```

Again, `b` has not appeared before:

```python
doubled = 2 * 2 - 0
        = 4
```

Update:

```python
last_seen[1] = 2
total = 4
```

The subsequences are:

```text
""
"a"
"b"
"ab"
```


### Process `a` again

Now `a` has appeared before.

We have:

```python
total = 4
last_seen[0] = 1
```

So:

```python
doubled = 4 * 2 - 1
        = 7
```

The `1` represents the duplicate subsequence contribution caused by the previous `a`.

Now:

```python
last_seen[0] = 4
total = 7
```

So there are `7` distinct subsequences **including the empty one**.

Finally:

```python
return total - 1
```

gives:

```text
7 - 1 = 6
```

The six non-empty subsequences are:

```text
"a"
"b"
"ab"
"aa"
"ba"
"aba"
```


## Code

```python
class Solution:
    def distinctSubseqII(self, s: str) -> int:
        MOD = 10**9 + 7
        total=1
        last_seen = [0]*26

        for ch in s:
            idx = ord(ch)-97
            doubled = total*2 - last_seen[idx]
            last_seen[idx] = total
            total = doubled % MOD

        return (total-1) % MOD
```

## Why `last_seen[idx] = total` Comes Before Updating `total`

This line is subtle:

```python
last_seen[idx] = total
```

We intentionally store the **old** value of `total`.

For example, when processing the first `a`:

```text
total = 1
```

So we save:

```text
last_seen[a] = 1
```

Later, when another `a` appears, that `1` tells us how many subsequences were already responsible for generating the previous group of `a`-ending subsequences.

If we stored the new `total` instead, the duplicate calculation would be incorrect.


## Complexity

Let `n` be the length of `s`.

We process every character exactly once.

### Time Complexity

$$
O(n)
$$

### Space Complexity

The `last_seen` array always contains only 26 values:

$$
O(26) = O(1)
$$

Therefore:

$$
\boxed{O(n)\text{ time and }O(1)\text{ space}}
$$


## Edge Cases

### 1. One character

```text
s = "a"
```

There are only:

```text
"a"
```

Answer:

```text
1
```


### 2. All characters are the same

```text
s = "aaa"
```

Distinct non-empty subsequences are:

```text
"a"
"aa"
"aaa"
```

Answer:

```text
3
```

`last_seen` prevents the repeated `a`s from creating duplicate counts.


### 3. All characters are different

```text
s = "abc"
```

There are:

```text
2^3 = 8
```

subsequences including the empty one.

Remove the empty subsequence:

```text
8 - 1 = 7
```

Answer:

```text
7
```


## Lessons

* When every existing state can generate a new state, look for a **doubling DP pattern**.
* Repeated characters are what make this problem difficult.
* `last_seen` is used to remember the contribution created by the previous occurrence of each character.
* The core formula is:

```text
new_total = 2 × total - last_seen[character]
```

* `total` includes the empty subsequence, so subtract `1` at the end.
* Since the string contains only lowercase English letters, an array of size `26` gives constant extra space.
* The important idea is not to generate subsequences explicitly. Instead, count them mathematically while tracking where duplicates come from.
