# 3702. Longest Subsequence With Non-Zero Bitwise XOR 🟡

**Topics:** Bit Manipulation, XOR, Array

## Intuition

Think of XOR as an operation where equal values cancel each other out:

```text
x ^ x = 0
```

We want the **longest subsequence whose XOR is non-zero**.

The first thing to check is the XOR of the entire array.

If:

```text
xor_all != 0
```

then the entire array is already a valid subsequence, so the answer must be `len(nums)`.

If the XOR of the entire array is `0`, we cannot take all elements.

However, if there is at least one non-zero element, we can remove that element. Since:

```text
0 ^ x = x
```

the XOR of the remaining elements becomes non-zero.

Therefore, we only need to remove **one element**, giving an answer of `len(nums) - 1`.

The only situation where this does not work is when **every element is zero**. Then every possible subsequence also has XOR `0`, so the answer is `0`.

## Approach

We use two passes through the array.

### Step 1: Calculate the XOR of the entire array

```python
xor_all = 0

for n in nums:
    xor_all ^= n
```

After this loop, `xor_all` contains the XOR of every element.

### Step 2: If the XOR is non-zero

```python
if xor_all != 0:
    return len(nums)
```

The entire array is valid, and no subsequence can be longer than the entire array.

### Step 3: If the XOR is zero

Now we know the entire array cannot be used.

We look for any non-zero element:

```python
for n in nums:
    if n != 0:
        return len(nums) - 1
```

Removing this element makes the remaining XOR equal to that element, which is non-zero.

### Step 4: All elements are zero

If the second loop finds nothing, every element is zero.

Therefore, no valid subsequence exists:

```python
return 0
```

## Example Walkthrough

Consider:

```text
nums = [1, 2, 3]
```

### Calculate the total XOR

```text
1 ^ 2 ^ 3
```

Since:

```text
1 ^ 2 = 3
3 ^ 3 = 0
```

we get:

```text
xor_all = 0
```

So we cannot take all three elements.

Now find a non-zero element.

The first element is:

```text
1
```

Since `1 != 0`, remove it.

Remaining subsequence:

```text
[2, 3]
```

Its XOR is:

```text
2 ^ 3 = 1
```

which is non-zero.

Therefore:

```text
answer = 3 - 1 = 2
```

## Code

```python
class Solution:
    def longestSubsequence(self, nums: List[int]) -> int:

        xor_all=0

        for n in nums:
            xor_all ^= n

        if xor_all != 0:
            return len(nums)


        for n in nums:
            if n != 0:
                return len(nums)-1

        return 0
```

## Complexity

We make at most two passes over `nums`.

**Time Complexity**

$$
O(n)
$$

**Space Complexity**

$$
O(1)
$$

We only use the `xor_all` variable and no additional data structure.

## Edge Cases

### 1. Entire array has non-zero XOR

```text
nums = [2, 3, 4]
```

```text
2 ^ 3 ^ 4 = 5
```

The entire array works.

Answer:

```text
3
```

### 2. Total XOR is zero but a non-zero element exists

```text
nums = [1, 2, 3]
```

Total XOR is `0`.

Remove `1`:

```text
2 ^ 3 = 1
```

Answer:

```text
2
```

### 3. Every element is zero

```text
nums = [0, 0, 0]
```

Every possible subsequence has XOR `0`.

Answer:

```text
0
```

## Lessons

* Always check whether the **entire array** already satisfies the condition when looking for a longest subsequence.
* XOR has two especially useful properties:

```text
x ^ x = 0
x ^ 0 = x
```

* If the total XOR is zero and there is a non-zero element, removing that one element is enough.
* The problem looks like a subsequence problem, but we never need to generate subsequences.
* Recognizing mathematical properties can turn an exponential subsequence problem into a simple $O(n)$ solution.
