# 1385: Find the Distance Value Between Two Arrays 🟢

**Topics:** Array, Two Pointers, Binary Search, Sorting


## Intuition

Imagine you are looking at a group of scouts in a camp (`arr1`) and a rival group across the valley (`arr2`). You want to count how many scouts are safely isolated, meaning no rival scout is within a danger distance of `d`. For each scout in `arr1`, you inspect every rival in `arr2`. If every rival is outside the danger range, that scout is counted as safe.


## Approach

1. Initialize a counter to keep track of valid elements in `arr1`.
2. Iterate through each element `x` in `arr1`.
3. Assume `x` is safe until proven otherwise by setting a boolean flag.
4. Check every element `y` in `arr2`. If the absolute difference `abs(x - y)` is less than or equal to `d`, `x` is too close to a rival. Mark it unsafe and break out of the inner loop early.
5. If `x` remains safe after checking all elements in `arr2`, increment the counter.
6. Return the final counter value.


## Example Walkthrough

Let us trace `arr1 = [4, 5, 8]`, `arr2 = [10, 9, 1, 8]`, and `d = 2`.

* **For `x = 4**`:
* $\vert{}4 - 10\vert{} = 6 > 2$
* $\vert{}4 - 9\vert{} = 5 > 2$
* $\vert{}4 - 1\vert{} = 3 > 2$
* $\vert{}4 - 8\vert{} = 4 > 2$
* All differences exceed `d`. Element `4` is valid. Count becomes `1`.


* **For `x = 5**`:
* $\vert{}5 - 10\vert{} = 5 > 2$
* $\vert{}5 - 9\vert{} = 4 > 2$
* $\vert{}5 - 1\vert{} = 4 > 2$
* $\vert{}5 - 8\vert{} = 3 > 2$
* All differences exceed `d`. Element `5` is valid. Count becomes `2`.


* **For `x = 8**`:
* $\vert{}8 - 10\vert{} = 2 \le 2$. This violates the condition. We stop checking and discard `8`.



Final result is `2`.


## Code

```python
class Solution:
    def findTheDistanceValue(self, arr1: list[int], arr2: list[int], d: int) -> int:
        ans=0
        
        for x in arr1:
            safe = True
        
            for y in arr2:
                if abs(x-y) <= d:
                    safe = False
                    break
        
            if safe:
                ans += 1
        return ans

```


## Complexity

* **Time Complexity:** $O(n \cdot m)$, where $n$ is the length of `arr1` and $m$ is the length of `arr2`. In the worst case, we compare every element of `arr1` with every element of `arr2`. Given the constraint that lengths are up to $500$, this requires at most $250,000$ operations, which executes instantly.
* **Space Complexity:** $O(1)$ auxiliary space, since we only use a few scalar variables for tracking.


## Edge Cases

* **`d = 0`**: Requires exact matches to be avoided. Elements are counted only if no identical element exists in `arr2`.
* **Negative numbers**: The absolute difference function `abs(x - y)` correctly handles negative values across both arrays.
* **Disjoint value ranges**: If all elements in `arr1` are sufficiently far from `arr2`, the algorithm correctly returns the full length of `arr1`.


## Lessons

* Brute force algorithms are completely viable and efficient enough when input constraints are small ($N, M \le 500$).
* Early stopping with a `break` statement optimizes inner loop execution once a condition fails.
* Sorting combined with binary search serves as a powerful alternative if constraints scale to larger sizes.
