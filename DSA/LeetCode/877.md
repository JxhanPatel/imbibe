# 877. Stone Game 🟡

**Topics:** Dynamic Programming, Game Theory, Array

## Intuition

Imagine two players picking coins from either end of a row.

Every coin you take is one your opponent can no longer choose. So the goal is not simply to grab the biggest pile now, but to make decisions that leave your opponent in a weaker position later.

Instead of tracking the total stones collected by each player, we track the **maximum score difference** the current player can achieve over the opponent.

For every subarray of piles:

* If we take the left pile, our score increases by that pile, but then the opponent gets to play optimally on the remaining piles.
* Since `diff` already represents the opponent's best possible advantage on the remaining range, we subtract it from the pile we take.
* We do the same for the right pile and choose whichever gives us the larger advantage.

This transforms a two-player game into a Dynamic Programming problem.

## Approach

Let

```text
diff[i][j]
```

represent the **maximum score difference** the current player can achieve over the opponent using piles from index `i` to `j`.

### Base Case

If there is only one pile left, the current player takes it.

```text
diff[i][i] = piles[i]
```

### Transition

For every range `[i...j]`, there are two choices.

Take the left pile:

```python
left = piles[i] - diff[i + 1][j]
```

Take the right pile:

```python
right = piles[j] - diff[i][j - 1]
```

Store the better choice.

```python
diff[i][j] = max(left, right)
```

We fill the table by increasing the length of the interval so that smaller subproblems are already solved before larger ones.

Finally,

```text
diff[0][n-1]
```

is Alice's maximum score difference over Bob.

If it is positive, Alice wins.

## Example Walkthrough

**Input**

```text
piles = [5,3,4,5]
```

### Step 1: Initialize

```
diff =
5 0 0 0
0 3 0 0
0 0 4 0
0 0 0 5
```

### Step 2: Gap = 1

```
diff[0][1] = max(5-3, 3-5) = 2
diff[1][2] = max(3-4, 4-3) = 1
diff[2][3] = max(4-5, 5-4) = 1
```

### Step 3: Gap = 2

```
diff[0][2] = max(5-1, 4-2) = 4
diff[1][3] = max(3-1, 5-1) = 4
```

### Step 4: Gap = 3

```
diff[0][3] = max(5-4, 5-4) = 1
```

Since

```text
diff[0][3] > 0
```

Alice can finish with more stones than Bob.

**Output**

```text
true
```

## Code

```python
class Solution:
    def stoneGame(self, piles: List[int]) -> bool:
        n = len(piles)
        diff = [[0]*n for _ in range(n)]

        for i in range(n):
            diff[i][i] = piles[i]

        for gap in range(1, n):
            for i in range(n-gap):
                j = i+gap
                left = piles[i] - diff[i+1][j]
                right = piles[j] - diff[i][j-1]
                diff[i][j] = left if left > right else right

        return diff[0][-1]>0
```

## Complexity

**Time Complexity**

$$
O(n^2)
$$

Every possible interval is computed once.

**Space Complexity**

$$
O(n^2)
$$

The DP table stores the best score difference for every subarray.

## Edge Cases

1. **Only two piles**

```text
piles = [2,5]
```

Alice takes `5` and wins immediately.

2. **Large values**

```text
piles = [500,1,500,1]
```

The DP still correctly evaluates the optimal sequence of moves.

3. **Minimum input size**

```text
piles = [1,2]
```

The algorithm works correctly even when there is only one decision to make.

## Lessons

* In two-player games, tracking the **score difference** is often simpler than tracking each player's score separately.
* Interval DP is a powerful technique when choices are made from both ends of an array.
* Filling the DP table by increasing interval length ensures every required subproblem has already been solved.
* The recurrence

```python
diff[i][j] = max(
    piles[i] - diff[i + 1][j],
    piles[j] - diff[i][j - 1]
)
```

is a common pattern in competitive game problems where both players play optimally.
