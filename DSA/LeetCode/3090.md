# 3090. Maximum Length Substring With Two Occurrences 🟢

**Topics:** Hash Table, Sliding Window, String

## Intuition

Imagine we are maintaining a continuous section of the string.

The rule is simple: **no character can appear more than twice inside our current section**.

We expand the section from the right using `right_ptr`. Whenever the newly added character appears more than twice, the window becomes invalid.

Instead of starting over, we move `left_ptr` forward and remove characters from the window until the newly added character appears at most twice again.

This lets us efficiently find the longest valid substring without checking every possible substring.

## Approach

We use the **sliding window** technique with a frequency map.

The important variables are:

* `char_count`: stores the frequency of each character in the current window.
* `left_ptr`: points to the beginning of the current window.
* `right_ptr`: points to the character we are currently adding.
* `max_len`: stores the longest valid window found so far.

### Step 1: Expand the window

For every `right_ptr`, get the current character:

```python
ch = s[right_ptr]
```

Then increase its frequency:

```python
char_count[ch] += 1
```

### Step 2: Check whether the window is invalid

The only character that can make the window invalid immediately is the newly added character.

If:

```python
char_count[ch] > 2
```

then that character occurs more than twice.

We shrink the window from the left:

```python
while char_count[ch] > 2:
    char_count[s[left_ptr]] -= 1
    left_ptr += 1
```

We keep doing this until `ch` appears at most twice.

### Step 3: Calculate the window length

Once the window is valid:

```python
window_len = right_ptr - left_ptr + 1
```

If it is larger than our previous answer, update `max_len`.

```python
if window_len > max_len:
    max_len = window_len
```

### Step 4: Return the answer

After processing the entire string:

```python
return max_len
```

## Example Walkthrough

Consider:

```text
s = "bcbbbcba"
```

Initially:

```text
left_ptr = 0
max_len = 0
```

### Add `b`

```text
window = "b"
b = 1
```

Length:

```text
1
```

So:

```text
max_len = 1
```

### Add `c`

```text
window = "bc"
b = 1
c = 1
```

Length:

```text
2
```

Update:

```text
max_len = 2
```

### Add `b`

```text
window = "bcb"
b = 2
c = 1
```

Valid.

```text
max_len = 3
```

### Add another `b`

Now:

```text
window = "bcbb"
b = 3
```

This violates the condition because `b` occurs three times.

We enter:

```python
while char_count[ch] > 2:
```

Remove the character at `left_ptr`:

```text
remove b
left_ptr = 1
```

Now:

```text
window = "cbb"
b = 2
```

The window is valid again.

We continue expanding and shrinking in the same way.

The longest valid window has length:

```text
4
```

So the answer is:

```text
4
```

## Code

```python
from collections import defaultdict
class Solution:
    def maximumLengthSubstring(self, s: str) -> int:
        char_count = defaultdict(int)
        left_ptr=0
        max_len=0

        for right_ptr in range(len(s)):
            ch = s[right_ptr]
            char_count[ch] += 1

            while char_count[ch]>2:
                char_count[s[left_ptr]] -= 1
                left_ptr+=1

            window_len = right_ptr-left_ptr+1
            if window_len>max_len:
                max_len = window_len

        return max_len
```

## Why Do We Only Check `char_count[ch] > 2`?

This is an important detail in the solution.

When we add:

```python
ch = s[right_ptr]
```

only `ch` has had its frequency increased.

Every other character's frequency stays exactly the same.

Therefore, if the window was valid before adding `ch`, the only possible violation is:

```python
char_count[ch] > 2
```

That is why we do not need to check every character in the dictionary.

This keeps the solution efficient.

## Complexity

Each character is added to the window once by `right_ptr`.

Each character can also be removed from the window at most once by `left_ptr`.

Therefore:

**Time Complexity**

$$
O(n)
$$

**Space Complexity**

$$
O(k)
$$

where $k$ is the number of distinct characters.

Since the problem contains only lowercase English letters:

$$
k \leq 26
$$

so practically the extra space is:

$$
O(1)
$$

## Edge Cases

### 1. All characters are the same

```text
s = "aaaa"
```

The window can contain only two `a`s.

```text
answer = 2
```

### 2. All characters are different

```text
s = "abcdef"
```

No character appears twice, so the entire string is valid.

```text
answer = 6
```

### 3. Every character appears exactly twice

```text
s = "aabbcc"
```

The entire string satisfies the condition.

```text
answer = 6
```

## Lessons

* **Sliding window** is useful for longest substring problems with constraints.
* A frequency map helps track the state of the current window.
* `right_ptr` expands the window.
* `left_ptr` shrinks the window when the constraint is violated.
* The window is always kept valid before calculating its length.
* When adding one element can only violate one specific condition, check that condition instead of scanning the entire window.
* The key pattern is:

```text
Expand → Check constraint → Shrink → Update answer
```
