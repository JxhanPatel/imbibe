# 2958. Length of Longest Subarray With at Most K Frequency 🟡

**Topics:** Hash Table, Sliding Window, Array

## Intuition

Imagine you are looking at a continuous section of an array and want to make it as long as possible.

The only rule is that **no number can appear more than `k` times** inside that section.

We can maintain a window using two pointers:

```text
lo ---------------- hi
       valid window
```

* `hi` expands the window by adding new elements.
* `lo` moves forward whenever the current window becomes invalid.
* `counts` keeps track of how many times each number appears inside the window.
* `best` stores the longest valid window found so far.

The important idea is that we do not restart the search when a frequency exceeds `k`. We simply shrink the window from the left until it becomes valid again.


## Approach

We use the **sliding window** technique with a frequency map.

### 1. Initialize the window

```python
counts = defaultdict(int)
best = 0
lo = 0
```

* `counts` stores the frequency of every number in the current window.
* `lo` is the left boundary.
* `best` stores the maximum valid length.


### 2. Expand the window

We iterate through `nums` using `hi`:

```python
for hi, num in enumerate(nums):
    counts[num] += 1
```

Every time we encounter a number, increase its frequency.

For example:

```text
nums = [1, 2, 1]
```

After processing the last `1`:

```text
counts = {
    1: 2,
    2: 1
}
```


### 3. Shrink an invalid window

If the newly added number appears more than `k` times:

```python
while counts[num] > k:
    counts[nums[lo]] -= 1
    lo += 1
```

We remove elements from the left until the frequency becomes valid again.

Notice that we only need to check:

```python
counts[num] > k
```

because the only frequency that can become invalid when adding the new element is the frequency of `num`.


### 4. Calculate the current window length

Once the window becomes valid:

```python
window_len = hi - lo + 1
```

The `+1` is important because both `lo` and `hi` are inclusive.

For example:

```text
lo = 2
hi = 5

length = 5 - 2 + 1
       = 4
```


### 5. Update the best answer

```python
if window_len > best:
    best = window_len
```

If the current valid window is longer than anything seen before, store its length.

Finally:

```python
return best
```

Consider:

```text
nums = [1,2,3,1,2,3,1,2]
k = 2
```

Initially:

```text
lo = 0
best = 0
```

### Add `1`

```text
window = [1]
```

### Add `2`

```text
window = [1,2]
counts = {1: 1, 2: 1}

best = 2
```

### Add `3`

```text
window = [1,2,3]
counts = {1: 1, 2: 1, 3: 1}
length = 3
best = 3
```

### Add another `1`

```text
window = [1,2,3,1]
counts = {1: 2, 2: 1, 3: 1}
length = 4
best = 4
```

Continue expanding:

```text
window = [1,2,3,1,2,3]
```

Every number appears exactly twice.

Therefore:

```text
best = 6
```

Now another `1` is added:

```text
window = [1,2,3,1,2,3,1]
```

Its frequency becomes:

```text
1: 3
```

Since:

```text
3 > k
```

the window is invalid.

We start moving `lo` forward:

```text
remove nums[lo] = 1
```

Now:

```text
1: 2
```

The window is valid again:

```text
[2,3,1,2,3,1]
```

Its length is still `6`.

The remaining elements cannot produce a longer valid window, so:

```text
Output = 6
```


## Code

```python
class Solution:
    def maxSubarrayLength(self, nums: List[int], k: int) -> int:
        
        counts = defaultdict(int)
        best=0
        lo=0

        for hi, num in enumerate(nums):
            counts[num] += 1

            while counts[num] > k:
                counts[nums[lo]] -= 1
                lo += 1

            window_len = hi-lo+1
            if window_len > best:
                best = window_len

        return best
```


## Complexity

Each element is added to the window once.

Each element can also be removed from the window at most once.

Therefore:

**Time Complexity**

$$
O(n)
$$

**Space Complexity**

$$
O(n)
$$

The `counts` dictionary can contain up to `n` distinct values.


## Edge Cases

### 1. All elements are identical

```text
nums = [5,5,5,5,5]
k = 2
```

Only two `5`s can exist in a valid window.

```text
Answer = 2
```

### 2. All elements are unique

```text
nums = [1,2,3,4,5]
k = 1
```

Every element satisfies the frequency restriction.

```text
Answer = 5
```

### 3. `k` is large

```text
nums = [1,2,1,3,2,1]
k = 10
```

No element can reach a frequency greater than `10`.

```text
Answer = 6
```


## Lessons

* **Sliding window** is a powerful pattern for contiguous subarray problems.
* Use a **frequency map** when the condition depends on how often values occur.
* When adding an element breaks the condition, move the left pointer instead of restarting.
* `hi - lo + 1` gives the length of an inclusive window.
* The key invariant is:

> The window from `lo` to `hi` always contains every element at most `k` times.

The overall pattern is:

```text
Expand right
      ↓
Update frequency
      ↓
Frequency > k?
   ↙       ↘
 Yes        No
  ↓          ↓
Move left   Update best
  ↓
Window valid
```

The main trick is recognizing that **both pointers only move forward**, turning what could look like an $O(n^2)$ subarray problem into an $O(n)$ solution.
