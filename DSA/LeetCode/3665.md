# 3665. Twisted Mirror Path Count 🟡

**Topics:** Dynamic Programming, Matrix, State Space Optimization

## Intuition

Think of water flowing through a grid of pipes, where each cell acts as either an open junction or a double-sided prism. Instead of tracking every single robot journey individually, we can track the volume of paths flowing into each cell from two directions: horizontally from the left and vertically from above.

When a path hits a mirror cell, it does not stop; instead, it performs a ninety-degree turn, which effectively swaps its directional flow. A horizontal flow coming from the left gets deflected downward, and a vertical flow coming from above gets deflected to the right. By maintaining running flow arrays row by row, we can compute all valid paths in linear space.

## Approach

1. **State Tracking:** We maintain two flow variables for each grid step. `down` (represented as a list `v` of size $n$) tracks paths arriving at each column from above, while `right` (represented as `h`) tracks paths arriving from the left.
2. **Row Iteration:** We process the grid row by row. At the start of each row, `h` is reset to zero because no paths enter the leftmost edge horizontally from outside the grid.
3. **Cell Processing:** For each cell in a row:
* If the cell contains a mirror (`m == 1`), the horizontal and vertical flows swap places because incoming rightward movement is turned down, and incoming downward movement is turned right.
* If the cell is empty (`m == 0`), the flows merge. The new horizontal and vertical contributions combine and accumulate into both variables, modulo $10^9 + 7$.


4. **Final Result:** After processing the entire grid, the final value at the bottom-right corner of the `down` array (`v[-1]`) gives the total number of valid unique paths.

## Example Walkthrough

Consider `grid = [[0, 1], [0, 0]]`:

* **Initialization:** `v = [1, 0]` (one path starts at the top-left corner coming from above).
* **Row 0 (`[0, 1]`):**
* Column 0 `(0, 0)` is `0`: `h = v[0] = (0 + 1) % MOD = 1`. So `h = 1, v[0] = 1`.
* Column 1 `(0, 1)` is `1` (mirror): `h, v[1] = v[1], h`. Since `v[1]` was `0` and `h` was `1`, we get `h = 0, v[1] = 1`.


* **Row 1 (`[0, 0]`):**
* Reset `h = 0`.
* Column 0 `(1, 0)` is `0`: `h = v[0] = (0 + 1) % MOD = 1`.
* Column 1 `(1, 1)` is `0`: `h = v[1] = (1 + 1) % MOD = 2`.


* **Result:** `v[-1]` returns `2`.

## Code & Comments

```python
class Solution:
    def uniquePaths(self, grid: List[List[int]]) -> int:
        MOD = 10**9+7
        v = [1] + [0] * (len(grid[0]) - 1)

        for row in grid:
            h=0

            for j, m in enumerate(row):
                if m:
                    h, v[j] = v[j], h

                else:
                    h = v[j] = (h+v[j]) % MOD
        return v[-1]
```

## Complexity

* **Time Complexity:** $O(m \cdot n)$ because we visit every cell in the $m \times n$ grid exactly once, performing constant time operations per cell.
* **Space Complexity:** $O(n)$ where $n$ is the number of columns, as we only need a single array of size $n$ to maintain the vertical flow states across rows.

## Edge Cases

* **Single Row Grid:** When $m = 1$, the vertical flow array is initialized, and horizontal flow accumulates directly across columns. Mirrors correctly redirect flow or terminate out of bounds.
* **All Mirrors:** If intermediate cells are packed with mirrors, flows bounce back and forth between horizontal and vertical channels, accurately filtering out invalid paths.
* **Minimum Grid Size ($2 \times 2$):** The algorithm handles small boundaries smoothly without index out-of-bounds exceptions.

## Lessons

* **Flow Swapping:** Recognizing that mirror reflections correspond to swapping directional components simplifies complex geometric routing into arithmetic flow updates.
* **Space Compression:** When state transitions only depend on the previous row, two-dimensional dynamic programming tables can be collapsed into one-dimensional rolling arrays to achieve optimal space efficiency.
