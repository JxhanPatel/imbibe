# 3498. Reverse Degree of a String 🟢

**Topics:** String, Math

## Intuition

Each character has a value based on its position in the **reversed alphabet**:

```text
a → 26
b → 25
c → 24
...
z → 1
```

We then multiply this value by the character's **1-indexed position** in the string.

The key observation is that we can calculate the reversed alphabet value directly using `ord()`.

For a lowercase character:

```python
123 - ord(ch)
```

works because:

```text
ord('a') = 97
123 - 97 = 26

ord('b') = 98
123 - 98 = 25

ord('z') = 122
123 - 122 = 1
```

So we do not need to create a separate alphabet mapping.


## Approach

We traverse the string once using `enumerate()`.

```python
for pos, ch in enumerate(s, 1):
```

The second argument `1` makes `enumerate()` start counting from `1` instead of `0`.

For every character:

1. Calculate its reversed alphabet value using `123 - ord(ch)`.
2. Multiply it by its position `pos`.
3. Add the result to `total`.

The formula for each character is:

$$
(123 - \text{ord}(ch)) \times pos
$$

Finally, return `total`.


## Example Walkthrough

**Input**

```text
s = "abc"
```

Because `enumerate(s, 1)` starts positions at `1`:

| Character | Position |  Reversed Value |       Product |
| --------- | -------: | --------------: | ------------: |
| `a`       |        1 | `123 - 97 = 26` | `26 × 1 = 26` |
| `b`       |        2 | `123 - 98 = 25` | `25 × 2 = 50` |
| `c`       |        3 | `123 - 99 = 24` | `24 × 3 = 72` |

Total:

$$
26 + 50 + 72 = 148
$$

So the answer is:

```text
148
```


## Code

```python
class Solution:
    def reverseDegree(self, s: str) -> int:
        total = 0

        for pos, ch in enumerate(s, 1):
            total += (123 - ord(ch)) * pos

        return total
```

### Important Trick

The most interesting part of the solution is:

```python
123 - ord(ch)
```

Since:

```text
ord('a') = 97
ord('z') = 122
```

we use:

```text
97 + 26 = 123
```

Therefore:

```text
123 - ord('a') = 26
123 - ord('b') = 25
...
123 - ord('z') = 1
```

Also, using:

```python
enumerate(s, 1)
```

lets us directly get the required **1-indexed position**, avoiding `pos + 1`.


## Complexity

**Time Complexity**

$$
O(n)
$$

We visit every character exactly once.

**Space Complexity**

$$
O(1)
$$

Only the variables `total`, `pos`, and `ch` are used.


## Edge Cases

### 1. Single character

```text
s = "a"
```

Calculation:

```text
26 × 1 = 26
```

Answer:

```text
26
```

### 2. Character `z`

```text
s = "z"
```

Calculation:

```text
123 - ord('z')
= 123 - 122
= 1
```

Answer:

```text
1
```

### 3. Repeated characters

```text
s = "zaza"
```

Calculations:

```text
z → 1 × 1 = 1
a → 26 × 2 = 52
z → 1 × 3 = 3
a → 26 × 4 = 104
```

Total:

$$
1 + 52 + 3 + 104 = 160
$$


## Lessons

* `ord()` can be used to convert characters into numerical positions.
* A character mapping does not always require a dictionary or array.
* `123 - ord(ch)` directly gives the reversed alphabet value for lowercase English letters.
* `enumerate(s, 1)` is useful when a problem uses **1-based indexing**.
* This problem can be solved with a simple **single-pass traversal**.
