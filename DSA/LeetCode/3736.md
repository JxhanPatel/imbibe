## 3736. Minimum Moves to Equal Array Elements III 🟢

**Topics:** Array, Math, Greedy


### Intuition

Imagine you are leveling up the heights of several building floors in a city. You can only add floors to buildings, never demolish them. To make all buildings the exact same height, you must raise every single building until it matches the tallest building currently in the city. Any target height lower than the maximum would be impossible to reach because you cannot decrease any building's height. Thus, the target height must be the maximum value in the array. Every move you make adds $1$ to a building, so the total moves needed is the sum of the height differences between the tallest building and each individual building.


### Approach

1. Find the maximum element in the array `nums`. Let this be `peak`.
2. Iterate through each element in `nums` and calculate how many increments are needed to reach `peak`, which is `peak - x`.
3. Sum up all these differences and return the total sum.


### Example Walkthrough

Let us trace `nums = [2, 1, 3]`:

* Find the maximum value: `max(nums) = 3`.
* Iterate through each element:
* For `2`: `3 - 2 = 1` move needed.
* For `1`: `3 - 1 = 2` moves needed.
* For `3`: `3 - 3 = 0` moves needed.


* Total moves: $1 + 2 + 0 = 3$.
* Output: `3`.


### Code

```python
class Solution:
    def minMoves(self, nums: List[int]) -> int:
        peak = max(nums)
        return sum(peak-x for x in nums)

```


### Complexity

* **Time Complexity:** $O(n)$, where $n$ is the number of elements in `nums`. We traverse the array once to find the maximum value and once more to sum the differences.
* **Space Complexity:** $O(1)$, as we only use a few variables for tracking calculations.


### Edge Cases

* **All elements already equal (e.g., `[5, 5, 5]`):** The maximum is `5`, and all differences are `0`, resulting in `0` moves.
* **Array with a single element (e.g., `[7]`):** The maximum is `7`, difference is `0`, resulting in `0` moves.
* **Consecutive numbers (e.g., `[1, 2, 3]`):** Maximum is `3`. Moves are $(3 - 1) + (3 - 2) + (3 - 3) = 2 + 1 + 0 = 3$.


### Lessons

* When operations are restricted to increments only, the target state is bound by the maximum element in the dataset.
* Greedy approaches that establish the optimal target value first simplify cumulative cost calculations into straightforward linear passes.
