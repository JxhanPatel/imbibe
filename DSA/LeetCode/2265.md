# 2265. Count Nodes Equal to Average of Subtree 🟡

**Topics:** Tree, Depth-First Search, Binary Tree

## Intuition

Imagine every node in the tree is managing a small team.

For each node, we want to know the **average value of everyone in its team**, including itself.

To calculate that average, we need two things:

* The total sum of values in the subtree.
* The number of nodes in the subtree.

A node's subtree includes all of its descendants, so the easiest way to get this information is to start from the bottom.

We first calculate the sum and count for the left and right subtrees. Then we add the current node.

Once we know the total sum and count, we can check:

```text
node value == sum // count
```

If true, we found one valid node.

This naturally leads to **postorder DFS**, because a node needs information from both children before it can calculate its own result.

## Approach

We use **Depth-First Search (DFS)** with postorder traversal.

For every node:

1. Recursively calculate the sum and count of its left subtree.
2. Recursively calculate the sum and count of its right subtree.
3. Add the current node's value to the total sum.
4. Add `1` to the total node count.
5. Calculate the floor average using:

   ```python
   total_sum // total_count
   ```
6. If the average equals the current node's value, increment the answer.
7. Return the subtree's total sum and node count to the parent.

For a `None` node, we return:

```text
sum = 0
count = 0
```

The important idea is that **each node returns information about its entire subtree**, allowing its parent to use that information immediately.

## Example Walkthrough

**Input**

```text
root = [4,8,5,0,1,null,6]
```

The tree looks like:

```text
        4
       / \
      8   5
     / \   \
    0   1   6
```

We start from the leaves.

### Node 0

```text
sum = 0
count = 1

average = 0 // 1 = 0
```

`0 == 0`, so count = `1`.

### Node 1

```text
sum = 1
count = 1

average = 1 // 1 = 1
```

`1 == 1`, so count = `2`.

### Node 8

Its subtree contains:

```text
8, 0, 1
```

So:

```text
sum = 8 + 0 + 1 = 9
count = 3
average = 9 // 3 = 3
```

`8 != 3`, so the answer remains `2`.

### Node 6

```text
sum = 6
count = 1
average = 6
```

`6 == 6`, so count = `3`.

### Node 5

Its subtree contains:

```text
5, 6
```

```text
sum = 11
count = 2
average = 11 // 2 = 5
```

`5 == 5`, so count = `4`.

### Node 4

Its subtree contains:

```text
4, 8, 5, 0, 1, 6
```

```text
sum = 24
count = 6
average = 24 // 6 = 4
```

`4 == 4`, so count = `5`.

Therefore:

```text
Output = 5
```

## Code

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def averageOfSubtree(self, root: TreeNode) -> int:

        cnt=0

        def helper(node):
            nonlocal cnt
            
            if node is None:
                return 0, 0

            lsum, lcnt = helper(node.left)
            rsum, rcnt = helper(node.right)

            subtree_sum = lsum + rsum + node.val
            subtree_cnt = lcnt + rcnt+1
            avg = subtree_sum // subtree_cnt

            if avg == node.val:
                cnt += 1

            return subtree_sum, subtree_cnt

        helper(root)
        return cnt
```

## Complexity

Let $n$ be the number of nodes in the tree.

**Time Complexity**

$$
O(n)
$$

Every node is visited exactly once.

**Space Complexity**

$$
O(h)
$$

where $h$ is the height of the tree, because of the recursive call stack.

For a balanced tree:

$$
O(\log n)
$$

For a completely skewed tree:

$$
O(n)
$$

## Edge Cases

### 1. Single node

```text
root = [1]
```

The subtree contains only `1`.

```text
average = 1 // 1 = 1
```

Output:

```text
1
```

### 2. All nodes have the same value

```text
root = [5,5,5]
```

Every subtree has an average of `5`.

Output:

```text
3
```

### 3. Average requires rounding down

Consider a subtree containing:

```text
5, 6
```

The average is:

```text
11 / 2 = 5.5
```

The problem requires rounding down:

```text
11 // 2 = 5
```

So the node with value `5` qualifies.

## Lessons

* When a tree node depends on information from its children, **postorder DFS** is often the natural choice.
* A recursive function can return multiple pieces of information, such as `(sum, count)`.
* Returning subtree information lets the parent solve its own subtree without traversing the same nodes again.
* For integer averages with floor division, use:

  ```python
  total_sum // total_count
  ```
* A useful tree pattern is:

```text
Solve left
Solve right
Combine both with current node
Return the result upward
```

This pattern appears frequently in tree problems involving **subtree sums, counts, heights, and other aggregate values**.
