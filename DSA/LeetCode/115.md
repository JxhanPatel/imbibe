# 115. Distinct Subsequences 🔴

**Topics:** String, Dynamic Programming

## Intuition

Imagine `s` is a long string of letters and `t` is the word you want to build.

You are allowed to:

* Pick a character from `s`.
* Skip a character from `s`.
* Never change the order of characters.

For example:

```text
s = "babgbag"
t = "bag"
```

There are multiple ways to pick `b`, then `a`, then `g`.

The key question is:

> How many different ways can we form `t` using characters from `s` while keeping their order?

At every character of `s`, we have a simple decision:

* **Skip** the character.
* **Use** the character if it matches the character we currently need from `t`.

This "use or skip" decision is what makes Dynamic Programming a natural fit.

## Approach

We use a **2D Dynamic Programming table**.

Let:

```python
dp[i][j]
```

represent:

> The number of ways to form the first `j` characters of `t` using the first `i` characters of `s`.

So:

```text
dp[i][j]
```

means we are considering:

```text
s[:i]
t[:j]
```

### Base Case

An empty `t` can always be formed.

There is exactly one way to form an empty string:

```text
Choose nothing.
```

Therefore:

```python
dp[i][0] = 1
```

for every `i`.

This is why the code starts with:

```python
for i in range(slen + 1):
    dp[i][0] = 1
```

## DP Transition

Now consider:

```python
si = s[i - 1]
```

This is the current character from `s`.

We first assume that we **skip** this character:

```python
ways = dp[i - 1][j]
```

Why?

If we don't use `s[i - 1]`, then we are simply asking:

> How many ways could we already form `t[:j]` using the previous characters of `s`?

That is:

```text
dp[i - 1][j]
```

### When Characters Match

Now check:

```python
if si == t[j - 1]:
```

If the current characters match, we have another option.

We can **use** `s[i - 1]` to match `t[j - 1]`.

After using both characters, we need to form:

```text
t[:j-1]
```

using:

```text
s[:i-1]
```

That is:

```python
dp[i - 1][j - 1]
```

So we add those possibilities:

```python
ways += dp[i - 1][j - 1]
```

Therefore, when the characters match:

```text
ways = skip + use
```

or:

```text
dp[i][j] = dp[i-1][j] + dp[i-1][j-1]
```

### When Characters Do Not Match

If:

```python
si != t[j - 1]
```

then we cannot use `s[i - 1]`.

So the only option is to skip it:

```python
dp[i][j] = dp[i - 1][j]
```

This is exactly what your code does by initializing:

```python
ways = dp[i - 1][j]
```

and only adding another value when the characters match.

## Example Walkthrough

Consider:

```text
s = "bab"
t = "ba"
```

We want to form:

```text
ba
```

from:

```text
bab
```

### Initial DP State

The first column is always `1`:

```text
        ""   b   a
""       1   0   0
"b"      1
"ba"     1
"bab"    1
```

The `1`s mean:

> There is exactly one way to form an empty string.

### Process `s[0] = 'b'`

We compare it with `t[0] = 'b'`.

They match.

So we can use this `b` to form the first character of `t`.

```text
dp[1][1] = dp[0][1] + dp[0][0]
         = 0 + 1
         = 1
```

Now:

```text
        ""   b
""       1   0
"b"      1   1
```

There is one way to form `"b"`.

### Process `s[1] = 'a'`

Now we want to form `"ba"`.

The current character is:

```text
s[1] = 'a'
```

and:

```text
t[1] = 'a'
```

They match.

So we can use this `a`:

```text
dp[2][2] = dp[1][2] + dp[1][1]
```

The first value is `0`, because we cannot form `"ba"` from only `"b"`.

The second value is `1`, because there is one way to form `"b"`.

Therefore:

```text
dp[2][2] = 0 + 1
         = 1
```

So there is one way to form `"ba"`:

```text
b a
```

## Code

```python
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        slen=len(s)
        tlen=len(t)

        if tlen > slen:
            return 0


        dp = [[0] * (tlen+1) for _ in range(slen+1)]
        for i in range(slen+1):
            dp[i][0] = 1


        for i in range(1, slen+1):
            si = s[i-1]

            for j in range(1, tlen+1):
                ways = dp[i-1][j]

                if si == t[j-1]:
                    ways += dp[i-1][j-1]

                dp[i][j] = ways

        return dp[slen][tlen]
```

## Understanding the Important Part

The most important part of the solution is:

```python
ways = dp[i - 1][j]

if si == t[j - 1]:
    ways += dp[i - 1][j - 1]
```

Think of it as:

```text
                 Current characters
                       match?
                      /      \
                    Yes       No
                    /          \
             Skip + Use       Skip
```

### Skip

```python
dp[i - 1][j]
```

We don't use the current character from `s`.

### Use

```python
dp[i - 1][j - 1]
```

We use the current character from `s` to match the current character from `t`.

This gives the core rule:

```text
If characters match:

    ways = skip + use

Otherwise:

    ways = skip
```

## Why `i - 1` and `j - 1`?

This is one of the most important details to understand.

The DP table uses lengths:

```python
dp[i][j]
```

But Python strings use zero-based indexes.

Therefore:

```python
s[i - 1]
```

is the `i`th character of `s`.

Similarly:

```python
t[j - 1]
```

is the `j`th character of `t`.

For example:

```text
s = "abc"

i = 2

s[i - 1]
s[1]
'b'
```

So:

```python
si = s[i - 1]
```

correctly gives the current character.

## Example: `"rabbbit"` → `"rabbit"`

```text
s = "rabbbit"
t = "rabbit"
```

The interesting part is:

```text
s = r a b b b i t
        ^ ^ ^
```

There are three `b`s in `s`, but `t` needs only two.

We can choose:

```text
first b + second b
```

or:

```text
first b + third b
```

or:

```text
second b + third b
```

Therefore there are:

```text
3
```

different ways.

The DP table counts these possibilities through repeated `skip` and `use` decisions.

Final result:

```text
3
```

## Early Return

Your code contains:

```python
if tlen > slen:
    return 0
```

This is an optimization and also an obvious impossibility check.

If `t` is longer than `s`, there is no way to create `t` as a subsequence.

For example:

```text
s = "abc"
t = "abcd"
```

There are only three characters available, but we need four.

So:

```text
0
```

## Complexity

Let:

```text
n = len(s)
m = len(t)
```

We create an `(n + 1) × (m + 1)` DP table.

The nested loops process every DP state once.

### Time Complexity

$$
O(nm)
$$

### Space Complexity

$$
O(nm)
$$

For the maximum constraint:

```text
n, m <= 1000
```

there can be around one million DP states.

## Edge Cases

### 1. `t` is longer than `s`

```text
s = "abc"
t = "abcd"
```

Impossible.

```text
Output: 0
```

### 2. `t` is empty

Conceptually:

```text
s = "abc"
t = ""
```

There is exactly one way to form an empty string:

```text
Choose nothing.
```

So:

```text
Output: 1
```

This is represented by:

```python
dp[i][0] = 1
```

### 3. No characters match

```text
s = "abc"
t = "ddd"
```

There is no way to form `t`.

```text
Output: 0
```

### 4. `s` and `t` are identical

```text
s = "abc"
t = "abc"
```

There is only one possible subsequence.

```text
Output: 1
```

## Lessons

### 1. Recognize the "Use or Skip" Pattern

For subsequence problems, ask:

> What happens if I use this character, and what happens if I skip it?

This often leads directly to a DP recurrence.

### 2. Matching Characters Create Two Choices

When:

```python
s[i - 1] == t[j - 1]
```

we can:

```text
Skip it
+
Use it
```

Therefore:

$$
dp[i][j] = dp[i-1][j] + dp[i-1][j-1]
$$

### 3. Non-Matching Characters Can Only Be Skipped

When:

```python
s[i - 1] != t[j - 1]
```

we have:

$$
dp[i][j] = dp[i-1][j]
$$

### 4. Empty Target Has One Way

This is a very common DP base case.

There is exactly one way to create an empty string:

```text
Choose nothing.
```

Therefore:

```python
dp[i][0] = 1
```

### 5. Define the DP State Clearly

The most important thing to remember is not the code.

Remember what this means:

```python
dp[i][j]
```

> Number of ways to form the first `j` characters of `t` using the first `i` characters of `s`.

Once this state is clear, the entire transition follows naturally.
