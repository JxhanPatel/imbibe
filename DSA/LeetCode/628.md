# 628. Maximum Product of Three Numbers 🟢

**Topics:** Array, Sorting, Math

## Intuition

Imagine you are choosing **three teammates** to maximize the team's overall strength.

At first, it seems obvious to simply pick the three strongest players. This works when every number is positive.

However, negative numbers change the situation.

Think of two negative numbers as two mistakes that cancel each other out. Multiplying two negative numbers gives a positive number. So if we have two very small (most negative) numbers and one very large positive number, their product can actually be larger than using the three largest numbers.

So there are only two possibilities worth checking:

1. The product of the **three largest numbers**.
2. The product of the **two smallest numbers** (most negative) and the **largest number**.

The larger of these two is the answer.

## Approach

We first sort the array in ascending order.

After sorting:

- The last three elements are the three largest numbers.
- The first two elements are the two smallest (possibly negative) numbers.
- The last element is the largest number.

Compute both candidate products:

```text
largest_three = nums[-1] * nums[-2] * nums[-3]

two_smallest = nums[0] * nums[1] * nums[-1]
```

Return the maximum of these two values.

Sorting makes it easy to access exactly the numbers we need.

## Example Walkthrough

**Input**

```text
nums = [-10, -10, 5, 2]
```

### Step 1: Sort

```text
[-10, -10, 2, 5]
```

### Step 2: Compute both products

Three largest:

```text
5 × 2 × (-10) = -100
```

Two smallest and largest:

```text
(-10) × (-10) × 5 = 500
```

### Step 3: Take the maximum

```text
max(-100, 500) = 500
```

**Output**

```text
500
```

## Code

```python
class Solution:
    def maximumProduct(self, nums: List[int]) -> int:
        
        nums.sort()
        n = len(nums)

        top3 = nums[n-1] * nums[n-2] * nums[n-3]
        two_neg_and_max = nums[0] * nums[1] * nums[n-1]


        best = top3 if top3 > two_neg_and_max else two_neg_and_max
        return best
```

## Complexity

**Time Complexity**

Sorting dominates the runtime.

$$
O(n \log n)
$$

**Space Complexity**

Ignoring Python's sorting implementation,

$$
O(1)
$$

## Edge Cases

1. **All positive numbers**

```text
nums = [1,2,3,4]
```

Answer:

```text
24
```

2. **Two large negative numbers**

```text
nums = [-10,-10,5,2]
```

Answer:

```text
500
```

3. **All negative numbers**

```text
nums = [-5,-4,-3]
```

Answer:

```text
-60
```

The product of all three numbers is the only possible answer.

4. **Contains zeros**

```text
nums = [-5,-4,0,2]
```

The algorithm correctly compares both possibilities and returns the maximum product.

## Lessons

- Do not assume the largest numbers always produce the largest product.
- Two negative numbers can create a larger positive product than three large positive numbers.
- Sorting often simplifies problems by making extreme values easy to access.
- Whenever multiplication and negative numbers are involved, consider how sign changes affect the final result.
