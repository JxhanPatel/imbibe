# 921. Minimum Add to Make Parentheses Valid 🟡

**Topics:** Stack, Greedy, String

## Intuition

Imagine parentheses as people entering and leaving a room.

* `(` means someone enters the room.
* `)` means someone leaves the room.

A person cannot leave if nobody is currently inside. So whenever we see `)` without a matching `(`, we need to **add an opening parenthesis**.

After processing the whole string, if some people are still inside, we need to **add closing parentheses** for them.

We only need to keep track of how many unmatched opening parentheses are currently available. This gives us a simple one-pass solution.

## Approach

We maintain two variables:

* `open`: number of unmatched `(` currently available.
* `add`: number of parentheses we need to insert.

For every character:

1. If it is `(`, increase `open`.
2. If it is `)`:

   * If there is an unmatched `(`, use it by decreasing `open`.
   * Otherwise, there is nothing to match this `)`, so we need to add an `(`. Increase `add`.
3. After processing the entire string, every remaining unmatched `(` needs a `)`.

   * Therefore, the answer is `add + open`.

This works because every unmatched parenthesis requires exactly one insertion.

## Example Walkthrough

**Input:**

```text
s = "())"
```

Start:

```text
open = 0
add = 0
```

### Step 1: `(`

We have an opening parenthesis.

```text
open = 1
add = 0
```

### Step 2: `)`

It can match the existing `(`.

```text
open = 0
add = 0
```

### Step 3: `)`

There is no `(` available to match it.

So we need to insert one `(`.

```text
open = 0
add = 1
```

The string effectively becomes:

```text
()()
```

So the answer is:

```text
1
```

## Code

```python
class Solution:
    def minAddToMakeValid(self, s: str) -> int:
        open=0
        add=0

        for ch in s:
            if ch == '(':
                open += 1
            
            else:
                if open == 0:
                    add += 1
                else:
                    open -= 1

        return add + open
```

## Complexity

We scan the string once.

**Time Complexity:**

$$
O(n)
$$

**Space Complexity:**

$$
O(1)
$$

## Edge Cases

### 1. All opening parentheses

```text
s = "((("
```

There are three unmatched `(`:

```text
open = 3
add = 0
```

We need three `)`.

```text
Answer = 3
```

### 2. All closing parentheses

```text
s = ")))"
```

Every `)` has no matching `(`.

```text
add = 3
```

We need three `(`.

```text
Answer = 3
```

### 3. Already valid

```text
s = "()()"
```

Every parenthesis gets a match.

```text
open = 0
add = 0
```

```text
Answer = 0
```

## Lessons

* Track **unmatched parentheses** instead of explicitly building the valid string.
* An unmatched `)` must be fixed immediately by adding `(`.
* Unmatched `(` can be fixed at the end by adding `)`.
* This is a common **greedy counting** pattern: fix problems as soon as they become unavoidable.
* The key invariant is that `open` never represents a negative number.
