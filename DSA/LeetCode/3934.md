## 3934. Smallest Unique Subarray 🔴

**Topics:** Array, Binary Search, NumPy, Prefix Doubling (Suffix Array Style), Hash Table

## Intuition

Think of a long ribbon of beads where you want to find the shortest snippet that appears only once along the entire ribbon.

Instead of hashing strings with modular arithmetic, this solution uses **prefix doubling** (the same doubling trick behind suffix arrays). You first assign each single bead a short rank tag. Then you combine two adjacent rank-1 tags into a pair and give that pair a new rank tag for blocks of size 2. Repeating that doubling step gives you rank tags for blocks of size 1, 2, 4, 8, and so on.

Because any window of length `L` can be represented by its leading and trailing power-of-two blocks of size `2**k` (where `2**k <= L < 2**(k+1)`), pairing those two already-ranked blocks tells you which subarrays of length `L` are identical without ever colliding. And since having a unique subarray of length `L` guarantees one exists for any larger length, binary search finds the shortest valid length quickly.

## Approach

1. **Rank Compression for Power-of-Two Blocks (`tags`):**
* `n = len(nums)` gives the length of the input array.
* `tags[0]` assigns integer ranks from `0` upward to each distinct value in `nums` using `np.unique(..., return_inverse=True)[1]`.
* In each doubling `step`, `jump = 1 << step` represents the current block size ($2^{\text{step}}$).
* If any rank in `tags[step]` has count `1` (checked via `np.bincount`), a unique block of size `jump` already exists, so we stop building larger power-of-two tables.
* Otherwise, we pair each block starting at `i` with the block starting at `i + jump` using `combos = tags[step][:-jump] * n + tags[step][jump:]`. Since each tag is strictly less than `n`, multiplying by `n` and adding encodes the pair into a single unique integer, which `np.unique(..., return_inverse=True)[1]` re-ranks cleanly.


2. **Checking Any Window Length (`works(win_len)`):**
* For a candidate `win_len`, `tier = win_len.bit_length() - 1` finds the largest power of two `span = 1 << tier` that is at most `win_len`.
* Every subarray of length `win_len` starting at index `i` is uniquely determined by its first `span` elements (tagged by `tags[tier][i]`) and its last `span` elements (tagged by `tags[tier][i + win_len - span]`).
* Slicing `tags[tier][:n - win_len + 1]` against `tags[tier][win_len - span:]` pairs those two anchors for every window of length `win_len`.
* `np.unique(..., return_counts=True)[1]` counts how often each combined pair appears, and `works` returns `True` if any count equals `1`.


3. **Binary Search for the Minimum Length:**
* The search range `range(1, upper)` tests candidate lengths where `upper = min(1 << len(tags), n)`.
* `bisect_left(..., True, key=works)` finds the first index in the range where `works(length)` is `True` (note that `range(1, upper)` is 0-indexed, so index `idx` corresponds to length `idx + 1`).
* If the loop finished without finding a unique block at the last `tags` level, `1 << len(tags)` can exceed `n`, so `min(..., n)` keeps the upper bound within valid array lengths.



## Example Walkthrough

Let's trace `nums = [1, 1, 2, 2, 1]` (`n = 5`):

* **Initial ranks (`tags[0]`):** `[1, 1, 2, 2, 1]` maps to ranks `[0, 0, 1, 1, 0]`. Counts are `{0: 3, 1: 2}`, so no count is `1`.
* **Step 0 (`jump = 1`):**
* Left halves: `tags[0][:-1]` = `[0, 0, 1, 1]`
* Right halves: `tags[0][1:]` = `[0, 1, 1, 0]`
* `combos` (multiplying by `5`): `[0*5+0, 0*5+1, 1*5+1, 1*5+0]` = `[0, 1, 6, 5]`
* Re-ranked into `tags[1]`: `[0, 1, 3, 2]`. Counts are all `1`, so the loop breaks here. `len(tags)` is `2`.


* **Binary Search (`upper = min(4, 5) = 4`, candidates `1, 2, 3`):**
* `win_len = 1` (`tier = 0`, `span = 1`): pairs from `tags[0]` have counts `[3, 2]`, so `works(1)` is `False`.
* `win_len = 2` (`tier = 1`, `span = 2`): `tags[1][:4]` = `[0, 1, 3, 2]` and `tags[1][0:]` = `[0, 1, 3, 2]`, giving combos `[0, 6, 18, 12]`. Every count is `1`, so `works(2)` is `True`.
* `bisect_left` returns index `1`, and `1 + 1 = 2` is returned.



## Code & Comments

```python
import numpy as np


class Solution:
    def smallestUniqueSubarray(self, nums: list[int]) -> int:
        n = len(nums)

        tags = [np.unique(nums, return_inverse=True)[1]]

        for step in range(n.bit_length() - 1):
            if 1 in np.bincount(tags[step]):
                break
                
            jump = 1 << step
            combos = tags[step][:-jump] * n + tags[step][jump:]
            tags.append(np.unique(combos, return_inverse=True)[1])

        def works(win_len):
            tier = win_len.bit_length() - 1
            span = 1 << tier
            combos = tags[tier][:n - win_len + 1] * n + tags[tier][win_len - span:]
            return 1 in np.unique(combos, return_counts=True)[1]

        upper = min(1 << len(tags), n)
        return bisect_left(range(1, upper), True, key=works) + 1
```

## Complexity

* **Time Complexity:** $O(n \log^2 n)$. Building `tags` takes up to $O(\log n)$ doubling steps, and each `np.unique` call on an array of size up to $n$ takes $O(n \log n)$ time. Binary search runs $O(\log n)$ checks, each calling `np.unique` in $O(n \log n)$ time.
* **Space Complexity:** $O(n \log n)$. We store up to $O(\log n)$ rank arrays of length up to $n$ in `tags`, along with temporary NumPy arrays during sorting and counting.

## Edge Cases

* **Single element (`nums = [7]`):** `n = 1`, `tags` has one element `[0]`, `upper = min(2, 1) = 1`, `range(1, 1)` is empty, `bisect_left` returns `0`, and `0 + 1 = 1` is returned.
* **All identical elements (`nums = [3, 3, 3]`):** Lengths `1` and `2` have repeated subarrays (`works(1)` and `works(2)` are `False`), while length `3` has `[3, 3, 3]` once, returning `3`.
* **All distinct elements (`nums = [4, 1, 9, 2]`):** Every element in `tags[0]` is unique, so `works(1)` is `True` on the first check and the function returns `1`.

## Lessons

* **Prefix doubling avoids hash collisions:** Pairing rank tags of size $2^k$ and re-indexing them gives exact equivalence classes without needing prime moduli or worrying about accidental hash collisions.
* **Two overlapping blocks cover a window:** Any subarray of length $L$ is uniquely identified by its prefix and suffix of length $2^{\lfloor \log_2 L \rfloor}$, even when $L$ is not a power of two.
* **Vectorized array operations keep checks concise:** Expressing window shifts and frequency checks with NumPy slices and `np.unique` avoids explicit Python loops over each window.
