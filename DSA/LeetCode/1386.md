# 1386. Cinema Seat Allocation 🟡

**Topics:** Array, Hash Table, Set

## Intuition

Think of each cinema row as having three possible blocks for a four-person family:

```text
Block 0: seats 2, 3, 4, 5
Block 1: seats 4, 5, 6, 7
Block 2: seats 6, 7, 8, 9
```

An empty row can always fit two families:

```text
[2,3,4,5]   [6,7,8,9]
```

So instead of calculating the answer from scratch, we begin by assuming every row is empty:

$$
total = 2n
$$

Then we look at the reserved seats and determine which of the three possible blocks are blocked.

For each affected row, we store:

* `0` if the left block is blocked
* `1` if the middle block is blocked
* `2` if the right block is blocked

The number of blocked blocks tells us how many families we need to remove from our initial answer.

## Approach

### Step 1: Assume every row can fit two families

```python
total = 2 * n
```

Since the left and right blocks do not overlap, every completely available row can seat two groups.

### Step 2: Track blocked blocks for each row

We use:

```python
rows_blocked = defaultdict(set)
```

The key is the row number, and the set stores which family blocks are unavailable.

For every reserved seat:

```python
if col in (2, 3, 4, 5):
    rows_blocked[row].add(0)
```

This marks the left block as blocked.

Similarly:

```python
if col in (4, 5, 6, 7):
    rows_blocked[row].add(1)
```

marks the middle block, and:

```python
if col in (6, 7, 8, 9):
    rows_blocked[row].add(2)
```

marks the right block.

A seat such as `4` or `5` can block more than one possible block, which is why we use separate `if` statements instead of `elif`.

### Step 3: Adjust the total

Initially, every affected row was counted as having two families.

If all three blocks are blocked:

```python
if len(blocked) == 3:
    total -= 2
```

The row cannot fit any family, so we remove both groups.

Otherwise:

```python
total -= 1
```

The row can fit exactly one family.

For example, if the middle block is blocked but the left and right blocks are available, the row can still fit two families. However, in this implementation, that situation cannot occur with a single reservation pattern that blocks only the middle block because seats `4, 5` also block the left block and seats `6, 7` also block the right block.

So if fewer than three blocks are blocked, at least one valid group placement remains.

## Example Walkthrough

Consider:

```text
n = 2
reservedSeats = [[1,4],[2,6]]
```

Initially:

```text
total = 2 × 2 = 4
```

### Row 1: Seat 4 is reserved

Seat `4` belongs to:

```text
Left block:   2,3,4,5
Middle block: 4,5,6,7
```

So:

```text
rows_blocked[1] = {0, 1}
```

Only the right block is available:

```text
6,7,8,9
```

Row `1` can fit one family.

Therefore:

```text
total -= 1
```

Current total:

```text
3
```

### Row 2: Seat 6 is reserved

Seat `6` belongs to:

```text
Middle block: 4,5,6,7
Right block:  6,7,8,9
```

So:

```text
rows_blocked[2] = {1, 2}
```

Only the left block is available:

```text
2,3,4,5
```

Row `2` can fit one family.

Again:

```text
total -= 1
```

Final answer:

```text
2
```

## Code

```python
class Solution:
    def maxNumberOfFamilies(self, n: int, reservedSeats: List[List[int]]) -> int:

        total = 2*n
        rows_blocked = defaultdict(set)

        for row, col in reservedSeats:
            if col in (2, 3, 4, 5):
                rows_blocked[row].add(0)

            if col in (4, 5, 6, 7):
                rows_blocked[row].add(1)

            if col in (6, 7, 8, 9):
                rows_blocked[row].add(2)

        for row, blocked in rows_blocked.items():
            if len(blocked)==3:
                total -= 2
            else:
                total -= 1

        return total
```

## Complexity

Let $r$ be the number of reserved seats.

**Time Complexity:**

$$
O(r)
$$

Each reserved seat is checked against three fixed-size seat groups, which takes constant time.

**Space Complexity:**

$$
O(r)
$$

In the worst case, we store blocked information for each row appearing in `reservedSeats`.

## Edge Cases

### 1. No relevant reserved seats

If all reservations are only in seats `1` and `10`:

```text
n = 3
reservedSeats = [[1,1],[2,10]]
```

Neither seat affects any valid four-seat block.

So all rows can still fit two families:

$$
3 \times 2 = 6
$$

### 2. All three blocks are blocked

For example:

```text
reservedSeats = [[1,4],[1,8]]
```

Seat `4` blocks the left and middle blocks.

Seat `8` blocks the right block.

So:

```text
blocked = {0, 1, 2}
```

No family can be seated in that row.

We subtract `2`.

### 3. Only one valid block remains

For example:

```text
reservedSeats = [[1,4]]
```

Seat `4` blocks:

```text
Left
Middle
```

The right block remains available:

```text
6,7,8,9
```

So one family can still be seated.

### 4. Very large number of rows

The value of $n$ can be as large as $10^9$.

We never iterate through all rows.

Instead, we start with:

$$
2n
$$

and process only rows that contain reservations.

## Lessons

* Start with the answer for the ideal case and adjust only the affected cases.
* A `defaultdict(set)` is useful when one item can affect multiple categories.
* Use a set to avoid counting the same blocked section multiple times.
* When the number of possible states is small and fixed, assigning each state an identifier such as `0`, `1`, and `2` can simplify the solution.
* For huge constraints, avoid iterating over the full range when the input only affects a small number of elements.
