# 1021. Remove Outermost Parentheses 🟢

**Topics:** String, Stack, Counting

## Intuition

Think of each primitive parentheses string as a package wrapped with one outer layer.

For example:

```text
(()())
```

The first `(` and the last `)` are the outer wrapper. We want to remove only those:

```text
()()
```

The key is to track the **parentheses depth**.

* When depth is `0`, we are outside a primitive group.
* The first `(` of a primitive increases depth from `0` to `1`, so we skip it.
* The last `)` decreases depth from `1` to `0`, so we skip it.
* Everything while depth is between `1` and `0` belongs to the inside and should be kept.

This follows the requested teaching structure and concise style from the provided instructions. 

## Approach

Use a single variable `depth`:

1. Start with `depth = 0`.
2. For every character:

   * If it is `(`:

     * If `depth > 0`, keep it.
     * Then increase `depth`.
   * If it is `)`:

     * Decrease `depth` first.
     * If `depth > 0`, keep it.
3. Return the collected characters.

The important detail is **when** we update `depth`.

For `(`, check before increasing.

For `)`, decrease first and then check.

That naturally removes the outermost pair of every primitive.

## Example Walkthrough

Input:

```text
s = "(()())(())"
```

Process the first primitive:

```text
( ( ) ( ) )
^         ^
outer     outer
```

Its inside is:

```text
()()
```

Then process:

```text
(())
```

Its inside is:

```text
()
```

So the final result is:

```text
()() + () = "()()()"
```

### Depth trace

For the first primitive:

| Character | Depth before | Action         | Depth after |
| --------- | -----------: | -------------- | ----------: |
| `(`       |            0 | Skip outer `(` |           1 |
| `(`       |            1 | Keep           |           2 |
| `)`       |            2 | Keep           |           1 |
| `(`       |            1 | Keep           |           2 |
| `)`       |            2 | Keep           |           1 |
| `)`       |            1 | Skip outer `)` |           0 |

The same process automatically works for consecutive primitive strings.

## Code

```python
class Solution:
    def removeOuterParentheses(self, s: str) -> str:
        result=[]
        depth=0

        for ch in s:
            if ch == '(':
                if depth > 0:
                    result.append(ch)
                depth += 1

            else:
                depth -= 1

                if depth>0:
                    result.append(ch)

        return ''.join(result)
```

## Complexity

We visit every character exactly once.

**Time Complexity:**

$$
O(n)
$$

**Space Complexity:**

$$
O(n)
$$

The result itself can contain up to $n$ characters.

## Edge Cases

### 1. Single primitive pair

```text
Input:  "()"
Output: ""
```

The entire string is the outermost pair, so nothing remains.

### 2. Multiple simple primitives

```text
Input:  "()()"
Output: ""
```

Each `()` is a separate primitive, and both pairs are removed.

### 3. Nested parentheses

```text
Input:  "((()))"
Output: "(())"
```

Only the first `(` and final `)` are removed.

### 4. Multiple nested primitives

```text
Input:  "(()())(())"
Output: "()()()"
```

Each primitive is handled independently.

## Lessons

* **Depth counting** is a powerful way to understand nested parentheses.
* The outermost `(` is identified when `depth == 0`.
* The outermost `)` is identified when decreasing `depth` makes it `0`.
* You do not actually need a stack because we only care about the current nesting level.
* This is a useful pattern for problems involving **balanced parentheses and nested structures**.

The depth-based approach is especially useful to remember: **check before increasing for `(`, decrease before checking for `)`**.
