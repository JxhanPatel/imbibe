# 3471. Find the Largest Almost Missing Integer 🟢

**Topics:** Array, Hash Table, Sliding Window

## Intuition

Imagine every subarray of size `k` as a separate room.

A number is considered almost missing if it appears in exactly one room.

So, we examine every window of size `k` and record which numbers appear inside it. If a number appears multiple times within the same window, it should still count as appearing in only one subarray.

That is why we use a `set`.

For example:

```text
[5,5,2]
```

If `k = 3`, there is only one subarray. Although `5` appears twice, it still appears in just one subarray.

After counting how many windows contain each number, we simply find the largest number whose count is exactly `1`.


## Approach

We use a dictionary called `window_count`.

### Step 1: Check every window

There are:

$$
n-k+1
$$

subarrays of size `k`.

For each starting position:

```python
for start in range(n - k + 1):
```

we take the current window:

```python
nums[start:start + k]
```

### Step 2: Remove duplicates within the window

We convert the window into a set:

```python
seen_in_window = set(nums[start:start + k])
```

This ensures each number contributes only once to the current subarray.

### Step 3: Count windows containing each number

For every unique number in the current window:

```python
for num in seen_in_window:
    window_count[num] += 1
```

Now `window_count[num]` represents the number of size-`k` subarrays containing `num`.

### Step 4: Find the largest valid number

A number is almost missing only when:

```python
cnt == 1
```

We check all counted numbers and keep the largest valid one.

If no number appears in exactly one subarray, `best` remains `-1`.


## Example Walkthrough

**Input**

```text
nums = [3,9,2,1,7]
k = 3
```

### Window 1

```text

{3,9,2}
```

Count:


## Code

```python
from typing import List
from collections import defaultdict
class Solution:
    def largestInteger(self, nums: List[int], k: int) -> int:
        window_count = defaultdict(int)
        n = len(nums)

        for start in range(n-k+1):

            seen_in_window = set(nums[start:start + k])
            for num in seen_in_window:
                window_count[num] += 1

        best = -1
        
        for num, cnt in window_count.items():
            if cnt != 1:
                continue

            if num > best:
                best = num

        return best
```


## Complexity

Let $n$ be the length of `nums`.

There are $n-k+1$ windows, and processing each window takes up to $O(k)$ time.

**Time Complexity**

$$
O(nk)
$$

In the worst case, since $k \leq n$:

$$
O(n^2)
$$

Given the constraint $n \leq 50$, this is easily efficient enough.

**Space Complexity**

$$
O(n)
$$

The dictionary stores counts for the distinct numbers.


## Edge Cases

### 1. All values appear in multiple windows

```text
nums = [0,0]
k = 1
```

There are two windows:

```text
[0]
[0]
```

So `0` appears in two subarrays.

Output:

```text
-1
```


### 2. `k` equals the array length

```text
nums = [4,2,9]
k = 3
```

There is only one window:

```text
[4,2,9]
```

Every distinct number appears in exactly one subarray.

The largest is:

```text
9
```


### 3. Duplicate values inside one window

```text
nums = [5,5,2]
k = 3
```

There is only one window:

```text
[5,5,2]
```

Using a set gives:

```text
{5,2}
```

Both numbers appear in exactly one subarray, so the answer is:

```text
5
```


### 4. Multiple valid answers

```text
nums = [1,8,3]
k = 2
```

Windows:

```text
[1,8]
[8,3]
```

Counts:

```text
1 -> 1
8 -> 2
3 -> 1
```

Both `1` and `3` are almost missing.

Return the largest:

```text
3
```


## Lessons

* A `set` is useful when duplicates should count only once within a group or window.
* Always distinguish between counting an element's occurrences and counting how many subarrays contain that element.
* Fixed-size sliding windows can be processed directly when constraints are small.
* A dictionary is a simple way to accumulate information across multiple windows.
* When the problem asks for the largest valid value, maintain a running maximum while checking candidates.
