# 1401. Circle and Rectangle Overlapping 🟡

**Topics:** Geometry, Math

## Intuition

Imagine a circle and a rectangle on a coordinate plane.

Instead of checking every point of the rectangle, we can find the **closest point inside the rectangle to the center of the circle**.

If that point is inside the circle, the circle and rectangle overlap.

The key idea is to **clamp** the circle's center to the rectangle's boundaries.

For example, if the circle's center is:

```text
xCenter = 0
```

and the rectangle starts at:

```text
x1 = 1
```

then the closest possible `x` coordinate inside the rectangle is `1`.

If the circle's center is already inside the rectangle's range, we simply keep its coordinate.


## Approach

We find the closest point `(px, py)` on the rectangle to the circle's center.

### Step 1: Find the closest X coordinate

```python
px = min(max(xCenter, x1), x2)
```

This keeps `px` inside the range:

```text
[x1, x2]
```

There are three cases:

* If `xCenter < x1`, `px` becomes `x1`.
* If `xCenter > x2`, `px` becomes `x2`.
* Otherwise, `px` remains `xCenter`.

### Step 2: Find the closest Y coordinate

```python
py = min(max(yCenter, y1), y2)
```

This does the same thing for the vertical range:

```text
[y1, y2]
```

Now `(px, py)` is the closest point in the rectangle to the circle's center.

### Step 3: Calculate the squared distance

```python
dx, dy = xCenter - px, yCenter - py
```

The squared distance is:

$$
dx^2 + dy^2
$$

We compare it with the squared radius:

$$
r^2
$$

So the circle and rectangle overlap when:

$$
dx^2 + dy^2 \le r^2
$$

We use squared distance instead of the actual distance to avoid using a square root.


## Example Walkthrough

**Input**

```text
radius = 1
xCenter = 0
yCenter = 0
x1 = 1
y1 = -1
x2 = 3
y2 = 1
```

### Step 1: Find `px`

```python
px = min(max(0, 1), 3)
```

First:

```text
max(0, 1) = 1
```

Then:

```text
min(1, 3) = 1
```

So:

```text
px = 1
```

### Step 2: Find `py`

```python
py = min(max(0, -1), 1)
```

Since `0` is already inside `[-1, 1]`:

```text
py = 0
```

The closest point is:

```text
(1, 0)
```

### Step 3: Calculate distance

```text
dx = 0 - 1 = -1
dy = 0 - 0 = 0
```

Therefore:

$$
dx^2 + dy^2
= (-1)^2 + 0^2
= 1
$$

Radius squared:

$$
1^2 = 1
$$

Since:

$$
1 \le 1
$$

the circle and rectangle overlap.

**Output**

```text
True
```


## Code

```python
class Solution:
    def checkOverlap(self, radius: int, xCenter: int, yCenter: int, x1: int, y1: int, x2: int, y2: int) -> bool:
        px = min(max(xCenter, x1), x2)
        py = min(max(yCenter, y1), y2)

        dx, dy = xCenter - px, yCenter - py
        return dx*dx + dy*dy <= radius * radius
```


## Complexity

**Time Complexity**

$$
O(1)
$$

Only a fixed number of calculations are performed.

**Space Complexity**

$$
O(1)
$$

Only a few variables are used.


## Edge Cases

### 1. Circle touches the rectangle

If the closest point is exactly on the circle:

$$
dx^2 + dy^2 = r^2
$$

The condition uses `<=`, so touching counts as overlap.

```text
True
```


### 2. Circle center is inside the rectangle

If the circle's center is already inside the rectangle:

```text
px = xCenter
py = yCenter
```

Therefore:

```text
dx = 0
dy = 0
```

The distance is `0`, so the shapes definitely overlap.

```text
True
```


### 3. Rectangle is outside the circle

If the closest point of the rectangle is farther from the circle's center than the radius:

$$
dx^2 + dy^2 > r^2
$$

then there is no shared point.

```text
False
```


## Lessons

* **Clamping** is useful when restricting a value to a fixed range.
* The pattern:

```python
min(max(value, low), high)
```

keeps `value` inside `[low, high]`.

* For circle geometry, comparing **squared distances** avoids unnecessary square roots.
* To check whether two shapes overlap, finding the **closest point** can reduce the problem to a simple distance comparison.
* Boundary cases matter. Since touching counts as overlap, use:

```python
<=
```

instead of:

```python
<
```
