# 3536. Maximum Product of Two Digits 🟢

**Topics:** Math, Greedy

## Intuition

Imagine you are selecting two players for a team, where the team's score is the product of their strengths.

To get the highest possible score, you would naturally choose the two strongest players. Sorting all the players would work, but it is unnecessary when you only need the top two.

This problem follows the same idea. As we scan through the digits of the number, we keep track of the largest and second largest digits seen so far. Once every digit has been processed, multiplying these two digits gives the maximum possible product.

## Approach

We process the digits of `n` one by one using `% 10` and `// 10`.

Maintain two variables:

* `top1` stores the largest digit found so far.
* `top2` stores the second largest digit.

For every digit:

1. Extract the last digit using `num % 10`.
2. Remove the last digit using `num //= 10`.
3. If the current digit is greater than or equal to `top1`:

   * Move the old `top1` into `top2`.
   * Update `top1` with the current digit.
4. Otherwise, if the digit is greater than `top2`, update `top2`.

Finally, return:

```python
top1 * top2
```

Using `>=` ensures duplicate largest digits are handled correctly. For example, if the number is `22`, both `top1` and `top2` become `2`.

## Example Walkthrough

**Input**

```text
n = 124
```

Initial state:

```text
top1 = 0
top2 = 0
```

Process each digit from right to left:

| Digit | top1 | top2 |
| ----: | ---: | ---: |
|     4 |    4 |    0 |
|     2 |    4 |    2 |
|     1 |    4 |    2 |

The two largest digits are `4` and `2`.

Maximum product:

```text
4 × 2 = 8
```

**Output**

```text
8
```

## Code

```python
class Solution:
    def maxProduct(self, n: int) -> int:
        
        top1=0
        top2=0
        num=n

        while num>0:
            d = num%10
            num = num//10

            if d >= top1:
                top2=top1
                top1=d

            elif d>top2:
                top2=d

        return top1*top2
```

## Complexity

**Time Complexity**

$$
O(d)
$$

where (d) is the number of digits in `n`. Since `n \le 10^9`, there are at most 10 digits.

**Space Complexity**

$$
O(1)
$$

Only a constant amount of extra space is used.

## Edge Cases

1. **Duplicate largest digits**

```text
n = 22
```

Largest digits are `2` and `2`.

Answer:

```text
4
```

2. **Number containing zero**

```text
n = 105
```

Largest digits are `5` and `1`.

Answer:

```text
5
```

3. **Exactly two digits**

```text
n = 31
```

There is only one possible pair.

Answer:

```text
3
```

## Lessons

* You do not always need to sort an entire collection when only the top few elements are required.
* Keeping track of the largest and second largest values during a single traversal is a common optimization pattern.
* Digits of an integer can be processed efficiently using `% 10` and `// 10`.
* Using `>=` instead of `>` correctly handles repeated maximum digits without any extra logic.
