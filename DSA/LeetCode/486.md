# 486. Predict the Winner 🟡

**Topics:** Dynamic Programming, Recursion, Memoization, Game Theory

## Intuition

Imagine two people are taking turns picking gifts from either end of a row.

Every time you pick a gift, you are not only choosing what **you gain**, but also deciding **what choices remain for your opponent**.

Since both players play perfectly, each player always tries to maximize their own advantage while minimizing the other's.

Instead of tracking each player's score separately, think about the **score difference** between the current player and the opponent.

If the current player can always finish with a score difference of **0 or more**, then they can guarantee at least a tie, which means Player 1 wins.

## Approach

We use **Dynamic Programming with Memoization**.

Define:

```text
dp(left, right)
```

as the **maximum score difference** the current player can achieve over the opponent using the subarray `nums[left:right+1]`.

At every step, the player has two choices:

1. Pick the left number.
2. Pick the right number.

If we pick the left number:

```text
nums[left] - dp(left + 1, right)
```

Why subtract?

Because after our move, the opponent becomes the current player on the remaining array. Their advantage is exactly `dp(left + 1, right)`, so we subtract it from our gain.

Similarly, picking the right number gives:

```text
nums[right] - dp(left, right - 1)
```

We choose whichever option gives the larger score difference.

Finally:

* If `dp(0, n-1) >= 0`, Player 1 can guarantee at least a tie.
* Otherwise, Player 2 wins.

## Example Walkthrough

**Input**

```text
nums = [1,5,2]
```

Start with:

```text
dp(0,2)
```

Player 1 has two choices.

### Pick `1`

Score difference becomes:

```text
1 - dp(1,2)
```

### Pick `2`

Score difference becomes:

```text
2 - dp(0,1)
```

The recursive calls compute the best possible responses for Player 2.

Eventually,

```text
dp(0,2) = -2
```

Since the score difference is negative, Player 1 cannot avoid losing.

**Output**

```text
false
```

## Code

```python
from functools import lru_cache

class Solution:
    def PredictTheWinner(self, nums: List[int]) -> bool:
        n = len(nums)

        @lru_cache(maxsize=None)
        def best_diff(lo, hi):
            if lo == hi:
                return nums[lo]

            grab_left = nums[lo] - best_diff(lo+1, hi)
            grab_right = nums[hi] - best_diff(lo, hi-1)

            return grab_left if grab_left > grab_right else grab_right

        result = best_diff(0, n-1)
        return result >= 0
```

## Complexity

**Time Complexity**

There are (O(n^2)) unique subarrays, and each is computed once.

$$
O(n^2)
$$

**Space Complexity**

The memoization table stores one value for every subarray.

$$
O(n^2)
$$

## Edge Cases

1. **Single element**

```text
nums = [7]
```

Player 1 picks the only number.

Answer:

```text
true
```

2. **Two equal numbers**

```text
nums = [5,5]
```

Both players score the same.

Answer:

```text
true
```

3. **Strictly increasing array**

```text
nums = [1,2,3,4]
```

The optimal choice is not always the largest immediate number. Dynamic programming evaluates future consequences before making a decision.

## Lessons

* In two-player optimal games, tracking the **score difference** is often simpler than tracking both scores separately.
* When both players play optimally, recursion naturally alternates between maximizing your advantage and minimizing your opponent's.
* Memoization avoids recomputing the same subarrays, reducing the complexity from exponential to quadratic.
* Whenever players repeatedly choose from the ends of an array, interval DP is a pattern worth considering.
