# 2472. Maximum Number of Non-overlapping Palindrome Substrings 🔴

**Topics:** Dynamic Programming, String, Palindrome

## Intuition

Imagine you have a long strip of letters and want to place as many **non-overlapping palindrome stickers** on it as possible.

Each sticker must:

* be a palindrome
* have length at least `k`
* not overlap with another sticker

The main question is:

> "By the time I reach position `end`, what is the maximum number of valid palindromes I could have placed?"

We can store that answer in a DP array called `best`.

For every ending position, we try to find a palindrome that ends there. If we find one starting at `start`, everything before it has already been solved by `best[start]`.

So:

```python
best[start] + 1
```

means:

> Best answer before this palindrome + this new palindrome.

This is the key DP idea.


## Approach

We use **dynamic programming** combined with a palindrome checker.

### 1. Define the DP array

```python
best[i]
```

means:

> The maximum number of valid non-overlapping palindromes we can select from `s[0:i]`.

So `best[n]` is the final answer.


### 2. Carry forward the previous answer

For every `end`:

```python
best[end] = best[end - 1]
```

This means we can always choose to **not use a palindrome ending at `end - 1`**.

For example:

```text
s = "ababa"

best[4]
```

can simply inherit:

```text
best[3]
```

if there is no useful palindrome ending at position `3`.


### 3. Find possible starting positions

A palindrome must have length at least `k`.

Therefore, for a substring ending at `end - 1`, the earliest starting position we initially consider is:

```python
start = end - k
```

Then we move `start` backwards:

```python
while start >= 0:
```

This lets us check longer and longer palindromes.


### 4. Check whether the substring is a palindrome

The helper function uses two pointers:

```python
def isPal(lo, hi):
    while lo < hi:
        if s[lo] != s[hi]:
            return False

        lo += 1
        hi -= 1

    return True
```

It compares characters from both ends and moves toward the center.

For example:

```text
s = "racecar"

r a c e c a r
↑           ↑

  a c e c a
  ↑       ↑

    c e c
    ↑   ↑
```

If every pair matches, the substring is a palindrome.


### 5. Update the DP answer

Suppose:

```text
s = "abacaba"
```

and we find a palindrome:

```text
s[start:end]
```

Then everything before `start` is independent from this palindrome.

So:

```python
cand = best[start] + 1
```

If this is better:

```python
if cand > best[end]:
    best[end] = cand
```

we update the answer.

The `break` is important in this particular implementation:

```python
break
```

Once we find a palindrome while moving `start` backwards, we stop looking for shorter alternatives ending at the same position.


## Example Walkthrough

Consider:

```text
s = "ababa"
k = 2
```

Valid palindromes include:

```text
"aba"
"bab"
"ababa"
```

We want the maximum number of **non-overlapping** palindromes.

### `end = 1`

Substring length is less than `k`.

```text
best[1] = best[0] = 0
```


### `end = 2`

Start with:

```python
start = 2 - 2 = 0
```

Check:

```text
s[0:2] = "ab"
```

Not a palindrome.

So:

```text
best[2] = 0
```


### `end = 3`

```python
start = 3 - 2 = 1
```

Check:

```text
s[1:3] = "ba"
```

Not a palindrome.

Move backward:

```python
start = 0
```

Check:

```text
s[0:3] = "aba"
```

Palindrome.

Therefore:

```python
cand = best[0] + 1
      = 0 + 1
      = 1
```

So:

```text
best[3] = 1
```


### `end = 5`

Eventually we can find:

```text
s[2:5] = "aba"
```

This is another palindrome.

Everything before it is:

```text
s[0:2] = "ab"
```

and:

```text
best[2] = 0
```

So this gives:

```text
best[2] + 1 = 1
```

But we can also have other configurations depending on the string.

The important idea is that every palindrome uses:

```text
best[start]
```

for the part before it, guaranteeing that selected palindromes don't overlap.


## Code

```python
class Solution:
    def maxPalindromes(self, s: str, k: int) -> int:
        n = len(s)

        if n < k:
            return 0

        best = [0] * (n+1)

        def isPal(lo, hi):
            while lo < hi:
                if s[lo] != s[hi]:
                    return False
                
                lo += 1
                hi -= 1
            return True

        for end in range(1, n+1):
            best[end] = best[end-1]

            start = end - k
            
            while start >= 0:
                if isPal(start, end-1):
                    cand = best[start] + 1

                    if cand > best[end]:
                        best[end] = cand
                    break

                start -= 1

        return best[n]
```

## Complexity

There are up to $O(n)$ possible `end` positions.

For each `end`, we can try up to $O(n)$ starting positions.

Each `isPal()` check can itself take up to $O(n)$ time.

Therefore, the worst-case time complexity of **this implementation** is:

$$
O(n^3)
$$

The DP array uses:

$$
O(n)
$$

space.

So:

**Time:** $O(n^3)$
**Space:** $O(n)$


## Edge Cases

### 1. String shorter than `k`

```text
s = "abc"
k = 5
```

No substring can be long enough.

```text
answer = 0
```

The early return handles this:

```python
if n < k:
    return 0
```


### 2. Entire string is a palindrome

```text
s = "ababa"
k = 5
```

The entire string can be selected.

```text
answer = 1
```


### 3. Multiple non-overlapping palindromes

```text
s = "abccbaabccba"
k = 6
```

We can select:

```text
"abccba"
"abccba"
```

They do not overlap, so the answer is:

```text
2
```


## Lessons

* **DP can represent the best answer for a prefix.**
* `best[i]` means we have already solved everything before position `i`.
* When selecting a substring `[start, end)`, use `best[start]` to guarantee that previous selections do not overlap.
* For palindrome problems, the **two-pointer technique** is a simple way to check whether a substring reads the same forwards and backwards.
* A useful DP pattern is:

```python
best[end] = best[end - 1]
```

followed by trying to use an object that ends at `end`.

* Always distinguish between the complexity of the **idea** and the complexity of the **specific implementation**. Here, repeatedly checking palindromes makes this version $O(n^3)$.
