# 1111. Maximum Nesting Depth of Two Valid Parentheses Strings 🟡

**Topics:** String, Greedy, Stack, Depth

## Intuition

Imagine two people are handling a stack of nested boxes.

Whenever we see `(`, we enter one more level of nesting. Whenever we see `)`, we leave a level.

The goal is to split the parentheses between two people so that neither person gets too deeply nested.

A simple way to balance the depth is to **alternate between the two groups based on the current nesting depth**.

For example:

```text
seq = (()())
```

As we scan the string, the nesting depth changes:

```text
(  (  )  (  )  )
1  2  1  2  1  0
```

We can assign parentheses at different depths to different groups:

```text
depth:  1 2 1 2 1 0
answer: 0 1 1 1 1 0
```

This keeps the maximum depth of each group smaller.

## Approach

We use the **current nesting depth** to decide which group gets each parenthesis.

Maintain a variable `depth`:

1. When we see `(`, increase `depth`.
2. Assign the parenthesis to `depth % 2`.
3. When we see `)`, assign it using the current depth, then decrease `depth`.

The important idea is that consecutive nesting levels alternate between groups.

So:

```text
depth 1 -> group 1
depth 2 -> group 0
depth 3 -> group 1
depth 4 -> group 0
```

This distributes the nesting depth between the two subsequences.

The approach follows the same idea of using the current state while scanning the sequence once, rather than constructing the two strings explicitly.

## Example Walkthrough

Consider:

```text
seq = "(()())"
```

Start with:

```text
depth = 0
```

Character:


Increase depth:


Assign:

```text

```

### Step 2

Character:

```text

```

Increase depth:

```text

```

Assign:


Answer:

```text

```

### Step 3

Character:

```text
)
```

Current depth is `2`, so assign:

```text
2 % 2 = 0
```

Then decrease:

```text
depth = 1
```

Answer:

```text
[1, 0, 0]
```

Continuing this process gives a valid split.

The exact assignment can differ from the example in the problem because multiple valid optimal answers are possible.

## Code

```python
class Solution:
    def maxDepthAfterSplit(self, seq: str) -> List[int]:
        answer = []
        depth=0

        for ch in seq:
            if ch == '(':
                depth += 1

            answer.append(depth%2)

            if ch==')':
                depth -= 1

        return answer
```

### Why does this work?

For every parenthesis, we use the **current nesting level** to choose the group.

The two groups effectively take alternating levels:

```text
Odd depth  -> group 1
Even depth -> group 0
```

Therefore, if the original sequence has maximum depth `D`, the two groups have depths roughly:

```text
ceil(D / 2)
floor(D / 2)
```

So the maximum depth is minimized.

## Complexity

We scan the string exactly once.

**Time Complexity:**

$$
O(n)
$$

**Space Complexity:**

$$
O(n)
$$

The output array itself contains `n` elements.

## Edge Cases

### 1. No nesting

```text
seq = "()()()"
```

The depth never exceeds `1`, so the parentheses can all belong to the same group.

### 2. Deeply nested parentheses

```text
seq = "((()))"
```

The depths are:

```text
1 2 3 2 1 0
```

The alternating assignment distributes these levels between the two groups.

### 3. Maximum constraint

```text
n = 10000
```

The algorithm still works efficiently because it only makes one pass through the string.

## Lessons

* Track the **current nesting depth** when processing parentheses.
* Alternating based on depth is a useful greedy technique for balancing nested structures.
* You do not need to actually build the two subsequences.
* For problems asking to minimize the maximum depth across two groups, try **splitting alternating depth levels**.
* A single left-to-right traversal is enough here.

The key trick to remember is:

```python
answer.append(depth % 2)
```

Use the nesting depth as the signal for which group receives the current parenthesis.
