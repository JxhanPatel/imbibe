# 2913. Subarrays Distinct Element Sum of Squares I 🟢

Topics: Array, Hash Set, Enumeration

## Intuition

Imagine you are looking at every possible continuous section of a row of books. For each section, you want to count how many different book titles appear, square that count, and add it to your total.

For example, consider `nums = [1, 2, 1]`.

- `[1]` contains 1 distinct value, so its contribution is $1^2 = 1$.
- `[1, 2]` contains 2 distinct values, so its contribution is $2^2 = 4$.
- `[1, 2, 1]` still contains only 2 distinct values, so its contribution is $2^2 = 4$.

The important observation is that a subarray can contain repeated elements, but each value counts only once toward its distinct count.

Since the array has at most 100 elements, we can generate every subarray and count its distinct elements using a set.

## Approach

We will use nested loops and a set.

1. Initialize `total = 0` to store the final answer.
2. Use the outer loop to choose the starting index of a subarray.
3. For each starting index, create an empty set called `seen`.
4. Use the inner loop to extend the subarray one element at a time.
5. Add each element to `seen`. Sets automatically ignore duplicate values.
6. Calculate the square of the set's size and add it to `total`.
7. Return `total` after processing every subarray.

The key optimization is that we do not need to recount the entire subarray each time. We maintain the set as the subarray grows.

## Example Walkthrough

Input:

```
nums = [1, 2, 1]
```

We enumerate all possible subarrays:

| Starting index | Subarray    | Distinct count | Square |
| -------------- | ----------- | -------------- | ------ |
| 0              | `[1]`       | 1              | 1      |
| 0              | `[1, 2]`    | 2              | 4      |
| 0              | `[1, 2, 1]` | 2              | 4      |
| 1              | `[2]`       | 1              | 1      |
| 1              | `[2, 1]`    | 2              | 4      |
| 2              | `[1]`       | 1              | 1      |

Now add all the squared distinct counts:

$$ 1+4+4+1+4+1=15 $$

Output:

```
15
```

Notice that adding the final `1` to `[1, 2]` does not increase the distinct count because `1` is already present in the set.

## Code

```python

class Solution:
    def sumCounts(self, nums: List[int]) -> int:
        total=0
        n = len(nums)

        for i in range(n):
            seen = set()

            for j in range(i,n):
                seen.add(nums[j])
                total += len(seen) ** 2

        return total

```

## Complexity

Let $n$ be the length of the array.

Time complexity:

$$ O(n^2) $$

There are $O(n^2)$ possible subarrays. Each set insertion takes $O(1)$ average time, and calculating the set's size takes $O(1)$.

Space complexity:

$$ O(n) $$

In the worst case, the set stores up to $n$ distinct elements.

## Edge Cases

### 1. All elements are identical

```
nums = [1, 1, 1]
```

Every subarray has exactly one distinct value. There are six non-empty subarrays, so the answer is:

$$ 6 \times 1^2 = 6 $$

### 2. All elements are distinct

```
nums = [1, 2, 3]
```

The contributions are:

$$ 1+1+1+4+4+4+9=24 $$

The full array contributes $3^2=9$.

### 3. A single element

```
nums = [5]
```

There is only one subarray, with one distinct value.

Output: `1`

## Lessons

- Enumerate subarrays: Use nested loops to explore every possible starting and ending index.
- Use a set for uniqueness: It automatically handles repeated values.
- Maintain state incrementally: Extend the current subarray and update the set instead of rebuilding it.
- Apply the required operation immediately: After extending a subarray, add the square of its current distinct count.
- Choose a solution based on constraints: With $n \leq 100$, an $O(n^2)$ solution is simple and efficient enough.

The main pattern to remember is: fix a starting index, grow the subarray, maintain the information you need, and update the answer at every step.
