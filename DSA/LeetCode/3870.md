# 3870. Count Commas in Range 🟢

**Topics:** Math, Counting

## Intuition

Imagine writing every number from `1` to `n` on paper using standard number formatting.

A comma appears whenever a number has **at least 4 digits**:

```text
1,000
1,001
1,002
...
```

For this problem, we do not actually need to format every number.

Since `n <= 10^5`, we can simply check every number from `1` to `n` and count how many commas its formatted representation contains.

A number can have:

* `1` to `3` digits → `0` commas
* `4` to `6` digits → `1` comma

Because the constraint is only up to `100000`, every number can contain at most **1 comma**.

So the problem reduces to:

> Count how many numbers from `1` to `n` are at least `1000`.

## Approach

We can loop through all numbers from `1` to `n`.

For each number:

1. If the number is less than `1000`, it has no comma.
2. Otherwise, it has exactly one comma.
3. Add `1` to our answer.

An even simpler observation is that if `n >= 1000`, then every number from `1000` through `n` contributes exactly one comma.

Therefore, the answer is:

$$
\max(0, n - 999)
$$

For example, if:

```text
n = 1002
```

The numbers containing commas are:

```text
1000
1001
1002
```

There are:

$$
1002 - 999 = 3
$$

commas in total.

## Example Walkthrough

**Input**

```text
n = 1002
```

Numbers below `1000` have no commas:

```text
1, 2, 3, ..., 999
```

Starting from `1000`, each number has one comma:

```text
1000 → 1 comma
1001 → 1 comma
1002 → 1 comma
```

So:

$$
3 \times 1 = 3
$$

**Output**

```text
3
```

For:

```text
n = 998
```

there are no numbers with four or more digits.

**Output**

```text
0
```

## Code

```python
class Solution:
    def countCommas(self, n: int) -> int:
        return max(0, n - 999)
```

## Complexity

**Time Complexity**

$$
O(1)
$$

We use a constant number of operations.

**Space Complexity**

$$
O(1)
$$

No extra space is required.

## Edge Cases

1. **`n < 1000`**

```text
n = 998
```

No number contains a comma.

Answer:

```text
0
```

2. **`n = 1000`**

```text
1000 → 1 comma
```

Answer:

```text
1
```

3. **Maximum constraint**

```text
n = 100000
```

Every number from `1000` to `100000` contributes one comma:

$$
100000 - 999 = 99001
$$

Answer:

```text
99001
```

## Lessons

* Look for a **threshold** where the required property first becomes true.
* If every number after that threshold contributes the same amount, counting can replace simulation.
* Here, the important threshold is `1000`.
* Instead of formatting every number, we can directly count:

$$
\boxed{\max(0, n - 999)}
$$

This turns an otherwise iterative problem into a simple $O(1)$ math solution.
